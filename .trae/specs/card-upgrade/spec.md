# 卡片样式与布局升级 - 产品需求文档

## Overview
- **Summary**: 本项目旨在升级 CHD (Card-based Hybrid Document) 系统的卡片样式和布局能力，引入多种卡片形态和布局策略，提升系统的视觉表现力和布局灵活性。
- **Purpose**: 解决当前 CHD 系统以矩形为主、视觉表现力单调的问题，实现更接近艺术化排版或 PPT 风格的自由度。
- **Target Users**: 内容创作者、设计师和开发人员，需要创建具有丰富视觉效果的文档和页面。

## Goals
- 引入多种卡片形态（矩形系、切角系、圆形系、箭头系），丰富视觉表达力
- 实现多种布局策略（自由画布、时间轴、中心辐射等），提升布局灵活性
- 确保新功能与现有业务流程兼容，不破坏现有功能
- 提供可扩展的架构，支持未来样式和布局的扩展
- 确保在不同设备和浏览器上的良好适配性

## Non-Goals (Out of Scope)
- 完全重写现有卡片组件，保持向后兼容
- 实现有机系（不规则流体形状）卡片样式，此功能将在后续版本考虑
- 实现复杂的 3D 效果和动画，仅提供基础的 3D 环形轮播
- 支持所有浏览器的所有版本，仅保证主流浏览器的兼容性

## Background & Context
- 当前 CHD 系统以矩形卡片为主，视觉表现力有限
- 已有卡片形态革新原型 (`card_shape_prototype_v1.html`) 展示了多种卡片样式和布局的可能性
- 布局升级功能已在架构上预留了扩展点 (`ILayoutStrategy`)
- 本项目是卡片样式升级的第一阶段，后续将视需求引入更多高级布局功能

## Functional Requirements
- **FR-1**: 实现卡片样式原子化，支持矩形系、切角系、圆形系、箭头系四种基础样式
- **FR-2**: 更新 Card 组件，支持通过属性设置卡片形状
- **FR-3**: 实现 Markdown 扩展语法，支持在 Markdown 中指定卡片形状
- **FR-4**: 实现组合布局，包括破格悬浮、动态环形总分、动态箭头环形
- **FR-5**: 实现时间轴布局，支持自定义节点样式和连接线样式
- **FR-6**: 实现 3D 环形轮播布局，支持鼠标拖动和按钮控制
- **FR-7**: 实现聚焦布局，支持左侧主内容区和右侧辅助区的配置
- **FR-8**: 提供样式和布局的使用文档，包括示例代码和最佳实践

## Non-Functional Requirements
- **NFR-1**: 性能要求 - 卡片样式和布局的渲染性能应与现有系统相当，无明显卡顿
- **NFR-2**: 兼容性要求 - 支持主流浏览器（Chrome、Firefox、Safari、Edge）的最新版本
- **NFR-3**: 响应式要求 - 样式和布局应在不同屏幕尺寸下表现合理
- **NFR-4**: 可扩展性要求 - 架构应支持未来添加新的卡片样式和布局策略
- **NFR-5**: 可维护性要求 - 代码应模块化、清晰，便于后续维护和扩展

## Constraints
- **Technical**: 使用现有的技术栈，不引入新的依赖库
- **Business**: 保持与现有业务流程的兼容性，不破坏现有功能
- **Dependencies**: 依赖现有的 Card 组件和渲染引擎

## Assumptions
- 现有 Card 组件的结构和 API 可以修改以支持新的样式属性
- 现有的 Markdown 解析器可以扩展以支持新的语法
- 现有的布局系统可以通过插件或扩展的方式支持新的布局策略

## Acceptance Criteria

### AC-1: 卡片样式原子化
- **Given**: 开发人员创建卡片元素
- **When**: 应用样式类到卡片元素
- **Then**: 卡片应显示为对应的形状（矩形、切角、圆形、箭头）
- **Verification**: `human-judgment`

### AC-2: Card 组件升级
- **Given**: 开发人员使用 Card 组件
- **When**: 设置 shape 属性为不同的值
- **Then**: 卡片应显示为对应的形状
- **Verification**: `programmatic`

### AC-3: Markdown 扩展语法
- **Given**: 用户在 Markdown 中使用 `::card shape="matrix"::` 语法
- **When**: 解析和渲染 Markdown
- **Then**: 应渲染为对应的卡片形状
- **Verification**: `programmatic`

### AC-4: 组合布局实现
- **Given**: 开发人员使用组合布局组件
- **When**: 配置布局参数
- **Then**: 布局应正确渲染，支持交互
- **Verification**: `human-judgment`

### AC-5: 时间轴布局实现
- **Given**: 开发人员使用时间轴布局组件
- **When**: 配置时间节点和样式
- **Then**: 时间轴应正确渲染，支持动态添加和删除节点
- **Verification**: `human-judgment`

### AC-6: 3D 环形轮播实现
- **Given**: 开发人员使用 3D 环形轮播组件
- **When**: 配置轮播项和控制选项
- **Then**: 轮播应正确渲染，支持鼠标拖动和按钮控制
- **Verification**: `human-judgment`

### AC-7: 聚焦布局实现
- **Given**: 开发人员使用聚焦布局组件
- **When**: 配置左右区域的内容和比例
- **Then**: 布局应正确渲染，在不同屏幕尺寸下表现合理
- **Verification**: `human-judgment`

### AC-8: 样式和布局文档
- **Given**: 用户查阅样式和布局文档
- **When**: 按照文档示例使用样式和布局
- **Then**: 应能正确实现对应的效果
- **Verification**: `human-judgment`

### AC-9: 兼容性和性能
- **Given**: 在不同浏览器和设备上测试
- **When**: 访问包含新样式和布局的页面
- **Then**: 页面应正常显示，无明显卡顿
- **Verification**: `programmatic`
