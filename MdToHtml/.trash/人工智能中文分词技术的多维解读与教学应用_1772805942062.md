### 研究背景 {card-style="normal" icon="file-text"}
教材智能问答系统依赖预设问题库与用户提问的精准匹配。用户提问表述多样化（如“空调机功能”的多种询问形式），导致传统匹配方法效率低下，亟需技术突破。

## 技术方法与突破 {layout="grid" columns=3 section-color="chart-2"}

### 中文分词挑战 {card-style="normal" icon="alert-circle"}
中文分词面临三大核心难题：
- **无显式分隔符**：词语边界不明确
- **歧义性**：同一句子可多种切分
- **开放性构词**：新词不断涌现

传统方法依赖规则与统计模型，深度学习技术显著提升了分词的准确性与适应性。

### 结巴分词技术内核 {card-style="highlight" icon="cpu"}
结巴分词支持三种模式：
- **精确模式**：最精确切分
- **全模式**：扫描所有可能词语
- **搜索引擎模式**：长词再切分

技术内核基于前缀词典构建有向无环图，结合动态规划选取最大概率切分路径，利用隐马尔可夫模型与Viterbi算法识别未登录词。

### Jaccard相似度算法 {card-style="highlight" icon="git-compare"}
**定义**：衡量两个集合A、B的相似度
$$
J(A,B) = \frac{|A \cap B|}{|A \cup B|} = \frac{|A \cap B|}{|A| + |B| - |A \cap B|}
$$

**应用**：量化用户提问(TA)与预设答案(TB)的词汇集合匹配程度，值域[0,1]，越高表示语义越接近。

## 实验过程与结果 {layout="grid" columns=3 section-color="chart-3"}

### 初始代码实现 {card-style="normal"}
```python
def jaccard(a,b):
    c=[val for val in a if val in b]
    return float(len(c)/(len(a)+len(b)-len(c)))

a=["空调机","有","什么","功能","？"]
b=["空调机","的","功能","有","哪些","？"]
print(jaccard(a,b))  # 结果：0.571
```
**问题**：分词逻辑未明确，依赖预设词汇集合。

### 结巴分词集成 {card-style="normal"}
```python
import jieba
ta = str(input())  # 用户提问
tb = str(input())  # 预设答案
a = list(jieba.cut(ta, cut_all=False))
b = list(jieba.cut(tb, cut_all=False))
print(jaccard(a,b))
```
**初始运行**：
- TA：“洗衣机的功能”
- TB：“我想知道我家的洗衣机有什么功能”
- 分词结果：`["洗衣机","的","功能"]` vs `["我","想","知道","我家","的","洗衣机","有","什么","功能"]`
- **相似度：0.333** ⬇️

### 动态优化效果 {card-style="highlight" icon="trending-up"}
**优化策略**：动态扩展TB词汇覆盖范围，增加同义词与语境相关词

**改进后运行**：
- TA：“我的洗衣机有哪些功能？我的洗衣机的功能？”
- TB：“我想知道我家的洗衣机有什么功能”
- 分词结果词汇覆盖显著提升
- **相似度：0.833** ⬆️

**关键发现**：数据表征质量直接影响算法效率。
