# 开发记录

## 2026-02-25
- **功能优化**:
  - **全局布局控制**: 将分区列数和间距控制迁移至底部工具栏的「主题」页，实现了对所有分区的统一控制。
  - **分割线优化**: 修复了分割线显示逻辑，现在可以通过全局开关控制分区底部分割线的显示与隐藏，且分割线与卡片的间距更加对称 (mt-4 mb-4)。
  - **视觉稳定性**: 移除了分区选中时的布局抖动问题，采用绝对定位的透明覆盖层来实现选中效果。
  - **列数选项调整**: 移除了「6列」选项，避免在移动端或窄屏下内容过于拥挤。
- **Bug修复**:
  - 修复了点击分区透明区域无法传递参数到编辑器的问题。
  - 修复了分割线点击切换无效的问题（增加了类型转换 String(boolean)）。
  - 修复了全局设置更新后UI不即时刷新的问题（增加了乐观UI更新）。
