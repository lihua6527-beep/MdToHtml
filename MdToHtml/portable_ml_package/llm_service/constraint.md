# 智能语义适配约束 (Intelligent Semantic Adaptation Constraints)

## 1. 核心决策逻辑 (Core Decision Logic)
**必须严格遵循以下判断流程处理输入文本：**

### 步骤一：原子性检测 (Atomicity Check)
- **判断标准**: 文本长度 < 50 字 **且** 仅包含 1 个核心观点。
- **动作**: 保持原样 (Keep)，仅进行格式规范化和关键词高亮。
- **目标**: 避免过度拆分破坏短句的完整性。

### 步骤二：直接拆分 (Direct Splitting)
- **触发条件**: 文本长度 > 50 字 **且** 包含明确的并列结构 (如 "第一...第二...", "1. 2.", ";")。
- **动作**: 按原有逻辑结构拆分为 2-4 个独立片段 (Segments)。
- **目标**: 将复杂长句物理拆解为 CHD 卡片。

### 步骤三：概括后拆分 (Summarize & Split)
- **触发条件**: 文本长度 > 100 字 **且** 语义缠绕、叙事性强、无法直接物理拆分。
- **动作**: 
    1. **提炼**: 先将长文本提炼为 3 个关键要点 (Key Takeaways)。
    2. **生成**: 基于这 3 个要点生成新的片段，而非直接截断原文。
- **目标**: 对非结构化长文进行"语义降维"，适配原子化标准。

## 2. 产出物规范 (Output Standards)
- **字数约束**: 最终输出的每个片段 (Segment) 长度应控制在 **20-40 字** (原子化区间)。
- **标题格式**: 为每个片段生成 "主题+结论" 格式的标题 (≤15字)。
- **关键词**: 识别核心词汇用 `<strong>` 包裹 (长词加 `style="font-size:1.1em"`)。

## 3. 业务红线 (Business Hard Constraints)
- **禁止广告**: 严禁出现任何形式的营销、推广、广告词汇。
- **保留引用**: 必须保留原文中的引用标注 (如 [1], (Smith, 2023))。
- **GFM 兼容**: 输出必须符合标准 Markdown 语法。
