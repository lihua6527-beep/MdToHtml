# 卡片图标使用指南

## 概述

本文档介绍了卡片图标的使用方法和注意事项，帮助用户正确使用卡片图标功能。

## 使用方法

在 Markdown 卡片标题中添加 `{icon="图标名称"}` 属性，例如：

```markdown
### Qwen3.5 小模型开源 {icon="zap"}
千问团队开源 Qwen3.5 系列四款小模型，涵盖 0.8B 至 9B 尺寸，家族矩阵扩充至 8 款，采用 Apache 2.0 协议。

### 架构与长文本突破 {icon="cpu"}
模型融合 Gated Delta 与稀疏 MoE 架构，原生支持 262,144 tokens 上下文，可扩展至 1,010,000 tokens。
```

## 注意事项

### 1. 图标使用限制
- 图标只能在标准的矩形框卡片中使用（形状为 `rect`）
- 在非矩形卡片中，图标属性会被忽略

### 2. 成套使用
- 同一二级标题下的所有卡片，要么都使用图标，要么都不使用图标
- 如果使用不一致，系统会显示警告信息

### 3. 图标颜色
- 图标的背景颜色会根据卡片颜色自动调整
- 当卡片使用默认颜色时，图标背景为浅灰色，图标为蓝色
- 当卡片使用主题颜色时，图标背景为卡片颜色，图标为白色

### 4. 标题间距
- 当卡片使用图标时，标题会自动向右偏移，避免被图标遮挡
- 系统会为有图标的卡片添加左侧 padding

## 最佳实践

1. **一致性**：在同一 section 下，要么所有卡片都使用图标，要么都不使用
2. **相关性**：选择与卡片内容相关的图标，增强视觉效果
3. **简洁性**：不要在所有卡片中都使用图标，只在需要突出显示的卡片中使用
4. **可读性**：确保图标不会影响标题的可读性

## 常见问题

### Q: 为什么我的图标不显示？
A: 请检查以下几点：
1. 图标名称是否正确
2. 卡片形状是否为 `rect`
3. 图标属性是否正确格式化为 `{icon="图标名称"}`

### Q: 为什么系统显示图标使用不一致的警告？
A: 同一 section 下的卡片要么都使用图标，要么都不使用图标。请确保所有卡片的图标使用一致。

### Q: 我可以使用自定义图标吗？
A: 目前只支持系统预定义的图标，不支持自定义图标。
