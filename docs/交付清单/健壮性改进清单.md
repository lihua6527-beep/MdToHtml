## 2. 测试策略 (Testing Strategy)

### 2.1 单元测试 (Unit Testing)
*   **目标**: 核心工具库覆盖率 > 90%
*   **重点覆盖**:
    *   `src/lib/chdParser.ts`: 测试边界条件（空行、嵌套、特殊字符）。
    *   `src/lib/validator.ts`: 测试各种非法输入的校验逻辑。

### 2.2 集成测试 (Integration Testing)
*   **场景**: 编辑器输入 -> 解析 -> 渲染 -> 滚动同步的全链路验证。
*   **工具**: Playwright / Cypress (建议)

### 2.3 混沌工程 (Chaos Engineering) (模拟)
*   **模拟场景**:
    *   快速随机输入字符。
    *   断网环境下加载资源。
    *   本地存储损坏。

## 3. 监控与告警 (Monitoring)
*   **前端监控**: 接入 Sentry (建议) 捕获运行时 JS 错误。
*   **性能监控**: 监控 Core Web Vitals (LCP, CLS, FID)。
