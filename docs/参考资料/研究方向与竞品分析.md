## 1. 竞品分析：PowerPoint Template System vs DocMind

### 1.1 核心差异
| 维度 | PowerPoint Template System | DocMind (本项目) |
| :--- | :--- | :--- |
| **最终产物** | .pptx 文件 | 动态网页 |
| **目标用户** | 需编程生成PPT的后端开发 | 希望优雅展示文档的写作者 |
| **核心逻辑** | 服务端填空 -> 静态模板 | 浏览器端 Markdown 解析 -> 动态组件 |
| **创新焦点** | 办公自动化 | 人机交互、文档工程范式、智能渲染 |

### 1.2 借鉴点
*   **布局命名**: 参考 `TitleSlide`, `SectionHeader` 等命名规范。
*   **组件参数**: 学习 `TwoColumnLayout` 的参数设计（如左右内容比例）。
*   **设计模式**: 拆解复杂布局为可组合模块。

### 1.3 原创性保证
*   **CHD范式**: 独创的“三级卡片式层级文档”。
*   **AI协同**: “约束”降低AI难度，“小模型”增强智能。
*   **Markdown工作流**: 坚守通用、纯净的文本格式。
