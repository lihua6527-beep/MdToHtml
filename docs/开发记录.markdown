### 3. Git 故障修复 (Git Troubleshooting)
- **问题描述**: 在使用 `trae-sandbox` 环境提交时遭遇 "Ghost Commit" (提交成功但无记录)，导致分支无法切换且无法合并 (Unrelated Histories)。
- **解决方案**: 采用 "Soft Reset 嫁接法" (Checkout -> Reset Soft Master -> Commit -> Merge)，成功将 `feat/cleanup` 分支的 AI 支持代码合并回 `master` 主分支。
- **文档输出**: 新增 `docs/技术规范/Git工作流与故障修复手册.markdown` 记录该解决方案。
