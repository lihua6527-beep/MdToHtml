# 开发记录 (Development Log)

## 2026-02-04: 编辑器 v1.1 核心升级

### 1. 概览
本次更新重点解决了编辑器的易用性与交互效率问题，实现了从“文本框”到“文件编辑器”的跨越。

### 2. 核心功能更新
*   **拖拽支持 (Drag & Drop)**: 
    *   实现了 `.md` 文件的浏览器内拖拽加载。
    *   增加了安全校验（文件类型白名单 + 二进制检测）。
    *   添加了拖拽时的全屏视觉反馈（Drop Zone）。
*   **文件 I/O (File System)**:
    *   新增 `/api/save` (POST) 和 `/api/read` (GET) 接口。
    *   前端实现了路径输入、加载、保存按钮。
    *   后端增加了路径安全检查（限制在项目根目录下）。
*   **UI/UX 优化**:
    *   **布局调整**: 左侧组件库宽度缩减至 12.5% (1/8)，释放更多编辑空间。
    *   **汉化**: 组件库标签全面中文化（如 "H1" -> "一级标题"）。
    *   **状态反馈**: 增加了 "Live Sync" 实时同步指示器和保存/加载的状态提示。

### 3. 技术改进
*   **Next.js 配置**: 启用了 `trailingSlash: true`，确保静态导出结构为文件夹索引模式 (`page/index.html`)。
*   **解析器修复**: 修复了 Markdown Frontmatter 解析的鲁棒性，增加了 try-catch 容错，防止输入过程中的瞬时崩溃。
*   **构建脚本**: 升级 `build_site.py`，集成了 `SimpleHTTPRequestHandler` 的扩展子类以支持 API 请求。

### 4. 下一步计划
*   **智能导引**: 实施《编辑器智能导引优化方案》，引入语法检查与自动修复。
*   **组件丰富**: 增加更多可视化图表组件的快捷插入。
