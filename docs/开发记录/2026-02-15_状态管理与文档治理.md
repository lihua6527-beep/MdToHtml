## 1. 核心变更：状态管理闭环

### 1.1 需求背景
用户反馈需要恢复“未修改/修改中/已完成”的三态管理，并解决状态切换的自动化与实时性问题。

### 1.2 技术实现
修改了 `src/components/InteractivePost.tsx`：
1.  **UI 文本还原**: 将状态按钮文本从“待修改/已修改”恢复为“未修改/修改中/已完成”，对应 `pending/modified/done`。
2.  **自动状态流转**: 在 `saveFile` 函数中增加逻辑，当保存 `pending` 状态的文档时，自动将其标记为 `modified` 并更新 Frontmatter。
3.  **即时反馈优化**: 重构 `handleStatusChange`，点击状态按钮时立即更新 React State (`setDocStatus`, `setContent`)，并在后台异步触发保存，消除了 UI 延迟。
