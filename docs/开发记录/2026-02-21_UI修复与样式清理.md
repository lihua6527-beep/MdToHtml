# UI 修复与样式清理 (UI Polish & Style Cleanup)

**日期**: 2026-02-21  
**分支**: fix/ui-polish  
**作者**: Trae AI

## 1. 变更摘要

本次更新主要针对两个 UI 细节进行了优化，并作为后续卡片封装重构的稳定节点。

### 1.1 修复打分系统提示框显示问题
- **问题**: 打分系统按钮位于导航栏左侧，但其提示框使用了 `right-0`（右对齐），导致提示框向左延伸并超出屏幕左边界，造成内容显示不全。
- **修复**: 将 `InteractivePost.tsx` 中的提示框定位从 `right-0` 改为 `left-0`，使其从按钮左侧开始向右延伸，确保所有内容完整显示。

### 1.2 移除废弃的 Warning 样式
- **背景**: `warning` 卡片样式在现有设计系统中已被废弃，且无实际使用场景。
- **变更**:
  - 从 `Card.tsx` 中移除了 `warning` 样式变体及类型定义。
  - 从 `scorer.ts` 的校验逻辑中移除了 `warning` 为合法样式的判断。
  - 从 `VisualEditor.tsx` 的下拉菜单中移除了 `Warning` 选项。
  - 更新了 `docs/CHD协议规范_v1.3.md` 和 `input/组件展示.md`，移除了相关文档说明。
