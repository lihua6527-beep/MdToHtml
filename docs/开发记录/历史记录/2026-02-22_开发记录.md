# 2026-02-22 开发记录

## 核心进展：桌面端打包 (Electron Packaging)

### 1. 架构重构 (Architecture)
- **路径管理模块 (`PathManager`)**: 
  - 实现了 `PathManager` 单例模式，统一管理应用根路径、输入/输出路径、数据路径。
  - 采用 **"便携优先 > 配置覆盖 > 文档兜底"** 的三级策略，确保在不同环境（开发、生产、便携版、安装版）下的路径正确性。
  - 解决了 Windows 环境下安装目录（Program Files）只读权限导致的写入失败问题，增加了回退到 `Documents/MdToHtml` 的逻辑。

- **后端服务迁移**:
  - 将 Next.js API Routes 逻辑完全迁移至 Electron 主进程启动的 Express 服务 (`electron/server.js`)。
  - 解决了 Next.js Static Export 模式下无法使用服务端 API 的限制。
  - 适配了文件上传 (`multer`)、保存 (`fs`)、Session 记录等核心功能。

### 2. 桌面端集成 (Electron Integration)
- **混合架构**: 采用 `Next.js Static Export` (前端) + `Electron Main Process` (后端) 的架构。
- **服务启动优化**: 
  - 解决了 `get-port` (ESM) 在 CommonJS 环境下的引用问题，采用 Dynamic Import。
  - 实现了主进程等待 Express 服务启动完成后再加载窗口的逻辑，避免白屏。
  - 开启 `ready-to-show` 事件监听，优化启动体验。

### 3. 构建与部署 (Build & Deployment)
- **依赖配置**:
  - 创建 `.npmrc` 配置国内镜像源，解决了 Electron 二进制包下载失败的问题。
- **打包配置 (`package.json`)**:
  - 配置 `electron-builder`，指定 `output` 目录为 `release_v2`。
  - 暂时关闭 `asar` (`asar: false`) 并输出为文件夹 (`dir`)，以便于初期调试与热修复。
  - 补充了 `description` 和 `author` 元数据。
- **产物输出**:
  - 成功生成可执行文件: `release_v2/win-unpacked/MdToHtml Pro.exe`。
  - 成功验证核心功能（启动、配置读取、本地服务加载）。

### 4. 问题解决 (Troubleshooting)
- **PowerShell 兼容性**: 修正了 npm scripts 中使用 `&&` 连接符导致的问题。
- **文件锁定**: 解决了 `electron-builder` 在 Windows 下因文件锁定或权限不足导致的构建失败问题（通过清理进程和更换输出目录）。
- **文档沉淀**: 输出了 `docs/技术规范/Electron打包避坑指南.md`，总结了本次打包过程中的关键经验。
