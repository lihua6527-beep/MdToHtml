# 2026-02-24 底部工具栏与布局策略重构

## 1. 核心变更 (Core Changes)
- **交互重构**: 将编辑器交互从悬浮式 Dock (Floating Dock) 彻底迁移至底部固定工具栏 (Fixed Bottom Toolbar)。
- **布局引擎升级**: 引入策略模式 (Strategy Pattern) 重构布局渲染逻辑，解耦 `Section.tsx`。
- **视觉对齐**: 实现 `cut` (缺角), `arrow` (箭头), `floating` (琥珀色徽章) 等卡片样式，对齐原型设计。

## 2. 详细改动 (Detailed Modifications)

### 2.1 底部工具栏 (BottomToolbar)
- **文件**: `src/components/CHD/BottomToolbar.tsx`
- **功能**:
  - 实现了 Theme/Layout/Card 三段式 Tab 结构。
  - 实现了基于选区的自动 Tab 切换逻辑 (选中 Section -> Layout Tab, 选中 Card -> Card Tab)。
  - 集成了 `useMarkdownInteraction` 钩子，直接操作 Markdown 源码。

### 2.2 布局策略 (Layout Strategies)
- **文件**: `src/components/CHD/LayoutStrategies.tsx`
- **新增布局**:
  - **Hub (环绕)**: 核心卡片居中，卫星卡片环绕，强制圆形样式。
  - **Ring (环形)**: SVG 分段环形图，支持点击交互与文本覆盖。
  - **Carousel (3D轮播)**: 基于 CSS 3D Transform 的旋转木马效果，支持拖拽旋转。
  - **Timeline (时间轴)**: 左右交替分布的时间轴视图。
- **架构优势**: 新增布局无需修改 `Section` 组件逻辑，只需注册新策略。

### 2.3 卡片样式 (Card Styles)
- **文件**: `src/components/CHD/Card.tsx`, `src/lib/shapes.ts`
- **实现**:
  - 使用 CSS `clip-path` 实现多边形裁剪。
  - 移除了旧版悬浮编辑菜单代码 (约 300 行)，消除技术债。
  - 修复了 GBK/UTF-8 混杂导致的中文乱码问题。

## 3. 验证结果 (Verification)
- **功能**: 底部工具栏正确响应点击，Markdown 源码实时更新。
- **视觉**: 环形、轮播等复杂布局渲染正常，无错位。
- **代码**: 移除了冗余代码，消除了控制台关于 `key` 和 `nesting` 的警告。

## 4. 意义与反思 (Significance & Reflection) [2026-02-25 补充]
- **大一统的前奏**: 今天的重构为后续的「编辑器大一统」奠定了坚实基础。通过将交互下沉到底部，我们成功释放了内容区域的空间。
- **平台化**: 引入策略模式不仅仅是为了支持更多布局，更是为了构建一个可扩展的「插件平台」。未来的开发者（或 AI）只需关注具体的渲染策略，而无需关心状态同步和数据流转。
