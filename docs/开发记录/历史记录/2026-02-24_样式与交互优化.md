# 2026-02-24 样式与交互优化

## 变更摘要
- **卡片样式**: 简化为 Normal, Highlight, Quote, Code 四种核心样式。
- **底部工具栏**: 统一文字大小 (14px/12px)，优化布局分组 (Theme/Layout/Card)，修复交互问题。
- **智能交互**: 实现 5 秒防抖自动保存，修复标题后缀解析问题。
- **顶部栏**: 精简按钮，引入 FloatingUndoRedo。

## 详细改动
1.  **Card.tsx**:
    - 移除了 Data, Summary, Emphasis 样式。
    - 统一使用 `shapeVariants` 管理样式变体。
2.  **BottomToolbar.tsx**:
    - 调整了标签页和按钮的文字大小。
    - 移除了重复的控件。
    - 添加了 `stopPropagation` 防止点击穿透。
3.  **InteractivePost.tsx**:
    - 引入了 `useHistory` 和 `useMarkdownInteraction` 实现状态同步。
    - 添加了 `useEffect` 实现自动保存。
    - 优化了属性解析逻辑。
4.  **attributeParser.ts**:
    - 更新正则表达式以支持未闭合属性。
