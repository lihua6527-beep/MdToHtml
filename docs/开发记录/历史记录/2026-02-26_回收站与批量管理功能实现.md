# 2026-02-26 回收站与批量管理功能实现

## 1. 概述
响应用户需求，增强了文件管理的安全性与便捷性。新增了回收站机制，防止误删文档；实现了批量删除功能，提升了管理效率；并在设置面板中直观展示回收站路径。

## 2. 核心变更 (Core Changes)

### 2.1 回收站机制 (Recycle Bin)
- **路径管理**: 扩展 `PathManager` 类，引入 `recycleDir`。默认路径为项目根目录下的 `recycle/` 文件夹，支持通过 `config.json` 自定义。
- **安全删除**: 删除 Markdown 源文件时，不再直接物理删除，而是移动至回收站文件夹。
- **缓存同步**: 删除操作同步更新 `MetadataCache`，确保列表状态即时刷新。

### 2.2 批量管理功能 (Batch Management)
- **API 升级**: `/api/delete` 接口升级支持 `slugs` 数组参数，实现原子化的批量处理。
- **交互设计**:
  - 文档列表头部新增“批量选择”模式切换按钮。
  - 支持多选、全选/反选操作。
  - 提供“仅删除源文件”与“删除源文件及 HTML”两种批量操作选项。
- **状态反馈**: 批量操作完成后自动刷新列表并退出选择模式。

### 2.3 设置面板增强 (Settings Panel)
- **路径可视化**: 在“文件路径”设置面板中新增红色高亮的“回收站路径”显示卡片，明确告知用户删除文件的去向。

## 3. 技术细节
- **原子性**: 批量删除操作在服务端串行处理，确保文件系统操作的稳定性。
- **兼容性**: API 保持对旧版单文件删除请求的兼容。
- **前端状态**: 使用 `Set` 数据结构管理选中项，优化渲染性能。
