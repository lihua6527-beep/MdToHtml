# 2026-02-26 开发记录 - 文档列表视图与排序增强

## 核心变更
1. **文档列表排序 (Sorting)**
   - 移除顶部排序切换按钮。
   - 在设置菜单中新增三种排序方式：
     - **按导入时间 (Import Time)**: 默认，基于 `birthtime`。
     - **按修改时间 (Modified Time)**: 基于 `mtime`。
     - **按最近访问 (Last Visited)**: 基于浏览记录。

2. **文档列表宽屏模式 (Wide View)**
   - 新增列表顶部 **展开/收起** 按钮 (`Maximize2`/`Minimize2`)。
   - **宽屏逻辑**: 
     - 展开后宽度从 `w-64` (256px) 扩展至 `w-[50vw]` (半屏)。
     - 布局自动切换为 **双列网格 (Grid Columns 2)**。
     - 排列顺序遵循标准流 (从左到右，从上到下)。
   - 移除了全屏预览相关的旧逻辑与 UI (Eye Icon)。

3. **代码清理**
   - 移除了 `previewSlug` 相关状态与 API 调用。
   - 修复了 `HomeClient` 与 `DocumentList` 的布局联动。
