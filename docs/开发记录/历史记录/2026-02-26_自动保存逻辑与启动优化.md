# 2026-02-26 自动保存逻辑与启动优化

## 变更摘要
本次更新主要修复了编辑器保存逻辑与启动体验问题，确保符合用户预期与操作习惯。

### 1. 编辑器保存逻辑优化
- **痛点**: 自动保存 (Auto-save) 触发时会意外关闭编辑器，导致用户输入中断。
- **修复**: 重构 `InteractivePost.tsx` 中的保存逻辑。
  - **手动保存**: 点击保存按钮时，显式传递 `shouldCloseEditor=true`，保存后退出编辑模式。
  - **自动保存**: 无论是定时器触发还是状态变更触发，传递 `shouldCloseEditor=false`，仅执行静默保存，保持编辑器开启。
- **涉及文件**: `src/components/InteractivePost.tsx`

### 2. 启动体验优化
- **痛点**: `start.bat` 启动后会打开两个浏览器窗口，且有时无法正确唤起。
- **修复**: 优化 `scripts/setup-port.js`。
  - **防止多开**: 移除冗余的打开逻辑，使用平台特定的稳健命令（Windows 下使用 `start "" "url"`）。
  - **单一实例**: 确保服务就绪后只唤起一个浏览器窗口。
- **涉及文件**: `scripts/setup-port.js`

### 3. UI 细节修复
- **痛点**: 底部工具栏 (BottomToolbar) 分割线显示为双线（border-r + border-l）。
- **修复**: 移除“全局微调”区域的左边框，仅保留内边距，确保分割线视觉统一。
- **涉及文件**: `src/components/CHD/BottomToolbar.tsx`

### 4. 文档更新
- **数据采集计划**: 移除关键版本快照，明确小模型“基于协议优化”的定位。
- **性能优化建议书**: 增加原子化操作步骤与风险分析。
