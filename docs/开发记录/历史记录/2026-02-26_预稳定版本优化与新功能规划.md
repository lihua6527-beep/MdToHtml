# 2026-02-26 预稳定版本优化与新功能规划

## 1. 概述
本次更新主要集中在 UI/UX 的细节打磨、文档状态管理的逻辑修复以及未来核心功能的规划。通过引入防抖机制和强制刷新策略，彻底解决了状态切换不持久化的问题。同时，清理了项目结构，规划了路径管理和缓存系统，为后续的稳定版本奠定基础。

## 2. 核心变更 (Core Changes)

### 2.1 状态持久化与防抖 (Status Persistence & Debounce)
- **问题**: 用户反馈点击“已完成”后立即退出，状态未保存；频繁点击导致 I/O 压力。
- **解决方案**:
  - **后端**: 修正 `/api/save` 文件名处理逻辑（支持空格/括号），防止生成重复文件。
  - **前端**: 在 `InteractivePost.tsx` 中引入 `0.5s` 防抖 (Debounce) 机制。
  - **交互**: 点击返回按钮时，若处于保存中，强制等待保存完成再跳转。
  - **同步**: `HomeClient.tsx` 增加 `window.onfocus` 监听，从文档页返回主页时自动刷新列表，确保状态图标即时更新。

### 2.2 UI/UX 优化 (Interface Polish)
- **导航优化**:
  - 文档详情页左上角新增“返回主页”按钮。
  - 移除了主页的“进入编辑器”入口（强制从文档列表进入）。
- **设置面板**:
  - 主页右上角设置齿轮移至左下角，改为上拉菜单形式。
  - 预留了“更改路径”的入口位置。
- **布局调整**:
  - 优化了左侧切换栏的上下空间利用率。
  - 在切换按钮间增加了分割线。

### 2.3 文档与规划 (Documentation & Planning)
- **功能池迁移**: 将 `待扩展功能池.md` 移动至 `docs/计划书/`，并清洗了已完成条目。
- **新方案制定**:
  - **[系统配置与路径管理方案.md](../../计划书/系统配置与路径管理方案.md)** (`SYS-01`): 规划 `config.json` 与标准文件选择器。
  - **[元数据缓存与性能分析方案.md](../../计划书/元数据缓存与性能分析方案.md)** (`SYS-02`): 规划 `.metadata_cache.json` 以提升列表加载性能。
  - **[Markdown编辑器革新计划.md](../../计划书/Markdown编辑器革新计划.md)** (`ED-07`): 规划所见即所得编辑器。

## 3. 技术细节
- **API**: `/api/files` 增加 `export const dynamic = 'force-dynamic'` 禁止缓存。
- **Ref**: 使用 `useRef` 追踪 `content` 最新状态，解决 React 闭包导致的状态覆盖问题。
