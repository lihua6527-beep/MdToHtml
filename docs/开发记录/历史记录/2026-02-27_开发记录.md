# 2026-02-27 开发记录

## 核心变更
1. **路径配置系统重构**
   - 修复 `PathSettingsPanel` 渲染异常问题。
   - 增强 `PathSelector` 组件，集成“新建文件夹”功能。
   - 实现路径配置的动态加载与持久化存储（`config.json`）。
   - 优化路径修改入口可见性，增加明确的“修改”按钮与图标。

2. **核心管理器升级**
   - `PathManager`: 支持动态路径解析，实现配置变更后的即时生效。
   - `MetadataCacheManager`: 
     - 增加 `reload()` 方法响应路径变更。
     - 优化文件扫描逻辑，**仅索引 Markdown 文件**，递归遍历子目录但忽略文件夹本身，解决文件列表混乱问题。
   - `TrashManager`: 增加 `reload()` 方法，支持回收站路径动态切换。

3. **API 增强**
   - `POST /api/fs/list`: 新增文件夹创建接口，支持安全路径校验。
   - `POST /api/config`: 统一配置更新入口，自动触发各管理器重载。

4. **交互体验优化**
   - 实现全局 `app-paths-updated` 事件机制。
   - 路径变更后自动刷新 `DocumentList` 和 `RecycleBin`，无需手动刷新页面。
   - 修复回收站与文件列表的数据同步问题。

## 追加变更：静态资产对接 (HTML + JSON)
1. **导出产物增加 JSON 元信息（可选）**
   - 对齐 `静态网页资产交付与对接规范`：交付物由“HTML + 元信息 JSON”成对组成。
   - 新增配置项 `exportOptions.emitJson`，默认 `false`（不生成 JSON）。
   - 导出 HTML 同步写入 output 目录时，若开启则额外生成同名 `<slug>.json`。

2. **设置面板增加输出配置开关**
   - 在“环境配置与路径”侧边面板新增“输出配置”区域。
   - 提供“同时生成 JSON 元信息文件：否/是”选项，默认“否”。

3. **JSON 字段约定（当前默认）**
   - `id`: 取 HTML 基名（不含扩展名）
   - `type`: 默认 `project`
   - `title`: 优先取 HTML `<title>`，缺失则回退为文件名
   - `brief`: 从正文文本提取前 100 字
   - `date`: 当天日期 `YYYY-MM-DD`
   - `tags`: 默认空数组
   - `chdVersion`: `2.4`
   - `htmlFile`: 对应的 HTML 文件名
