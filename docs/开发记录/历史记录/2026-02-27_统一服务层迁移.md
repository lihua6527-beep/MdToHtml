# 2026-02-27 统一服务层迁移开发记录

## 1. 概览
- **目标**: 设计并渐进迁移 Unified Service 层，解耦 API 调用与 React Hooks。
- **变更**: 新增 `src/services` 目录，重构 `useFileSystem.ts`。

## 2. 详细变更
### 2.1 Service 层架构
- **Core**: `src/services/core/ApiClient.ts`
  - 封装 `fetch`，统一处理 `ApiResponse` 结构与错误。
  - 修复 `TrashService.deleteFiles` 返回非标准 `success` (number) 导致的误判问题。
- **Modules**:
  - `FileService.ts`: 文件列表获取、删除 (支持批量)。
  - `TrashService.ts`: 回收站列表、还原、永久删除、清空。
  - `ConfigService.ts`: 容量配置获取与更新。

### 2.2 Hooks 重构
- 重构 `src/hooks/useFileSystem.ts`:
  - 移除内部 `fetcher` 实现。
  - `useFiles`, `useCapacity`, `useTrash` 改为调用 Service 层静态方法。
  - 保持 `useSWR` 缓存策略 (`keepPreviousData: true`)。
- 移除重复类型定义，统一引用 `@/types/file-system`。

### 2.3 组件适配
- `CapacityProgressBar.tsx`: 移除内部定义的 `CapacityStats`，统一使用全局类型。

## 3. 验证
- **类型检查**: `npx tsc --noEmit` 通过。
- **Lint**: `npm run lint` 无相关错误。
- **逻辑验证**:
  - `ApiClient` 正确处理 `success: boolean` 与非标准响应。
  - `TrashService` 适配后端 `BatchOperationResult` 返回结构。

## 4. 文档与环境修复
- **文档位置修复**: 将文档从错误的 `MdToHtml/docs` 移动至项目根目录 `docs/`。
- **语言本地化**: 将英文版迁移计划书翻译为中文 `docs/计划书/2026-02-27_统一服务层迁移计划.md`。

## 5. 下一步计划
