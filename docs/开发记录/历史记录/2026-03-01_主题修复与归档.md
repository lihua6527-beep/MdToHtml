## 任务描述
修复风格样式库中主题实现的问题，确保所有主题都能正常工作。

## 问题分析
- 发现 `globals.css` 中的主题 ID 与 `themes.ts` 中定义的不匹配
- 导致部分主题无法正常加载
- 具体问题：
  - `globals.css` 使用了 `violet`、`sunset`、`slate` 等主题 ID
  - 但 `themes.ts` 中定义的是 `lavender`、`earth`、`caramel` 等主题 ID

## 解决方案
1. 修改 `globals.css` 文件，将主题 ID 改为正确的名称：
   - 将 `[data-theme="violet"]` 改为 `[data-theme="lavender"]`
   - 将 `[data-theme="sunset"]` 改为 `[data-theme="earth"]`
   - 将 `[data-theme="slate"]` 改为 `[data-theme="caramel"]`

2. 更新主题的配色配置，确保与文档中描述的主题一致：
   - Lavender Dream (薰衣草梦境版)：优雅梦幻 | 紫罗兰
   - Earth Organic (大地有机版)：温暖有机 | 翡翠绿
   - Caramel Vintage (焦糖复古版)：复古优雅 | 焦糖棕
