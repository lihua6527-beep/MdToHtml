  - `date`: 日期
  - `tags`: 标签数组
  - `category`: 分类
  - `chdVersion`: CHD协议版本
  - `htmlFile`: HTML文件路径

## 3. 导出文件分类子文件夹功能

### 3.1 功能需求

用户希望在导出时自动创建4个分类子文件夹（documents、projects、articles、others），便于文件管理和复制。

### 3.2 实现方案

- 在导出时自动创建4个分类子文件夹
- 根据文件的metadata.type或metadata.category自动分类
- 更新JSON元数据中的htmlFile路径，包含分类文件夹路径

### 3.3 分类规则

| 类型值 | 分类文件夹 |
|--------|-----------|
| document, doc | documents |
| project, proj | projects |
| article, blog, post | articles |
| 其他 | others |

## 5. 技术要点

### 5.1 双后端支持

由于项目同时支持Electron和Next.js开发服务器，所有后端功能都需要在两个环境中实现：
- Electron: `electron/server.js`
- Next.js: `src/app/api/` 下的路由文件

### 5.2 路径管理

统一使用 `PathManager` 管理路径，确保在不同环境下路径解析正确。

### 5.3 递归文件操作

清除缓存功能使用递归函数遍历所有子文件夹，确保彻底清理。
