## 一、更新摘要

本次更新为系统新增了完整的 **AI 智能转换层**，实现了从"用户输入任意文档 → AI 自动识别 → 生成 CHD Markdown → 渲染 HTML"的完整闭环。

### 主要功能

- 首页右侧集成 AI 功能区，支持文件上传（.txt / .md / .docx）
- 调用 DeepSeek V4 API（Flash / Pro 双模型）自动生成 CHD 格式文档
- 多版本并列管理、预览、下载、持久化保存到左侧文档列表
- 两组 Prompt 风格切换（默认稳定版 / 学术风格）
- 退出确认弹窗

## 五、关键 Bug 修复

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | 保存"失败"弹窗 | `FileService.saveFile` 中 `result.success` 判断错误（ApiClient已自动解包） | 改为 `result !== null` |
| 2 | 预览空白 | 存储 key 不匹配 + JSON.parse 失败 | 统一使用 `ai_preview_content` 纯文本 key |
| 3 | 无法预览新模块文件 | `AITempFileList` 从错误路径导入 TempFileItem 类型 | 统一从 `@/services/ai/TempFileManager` 导入 |
