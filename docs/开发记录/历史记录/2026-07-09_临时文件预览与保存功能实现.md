# 2026-07-09 开发记录：临时文件预览与保存功能实现

## 概述
实现了 AI 生成文档的在线预览和保存功能，构建了完整的临时文件管理体系，彻底解决预览404问题。

## 变更内容

### 1. 临时文件服务层
- **新增** `src/lib/temp-file-manager.ts` — 服务端临时文件管理器
  - 在 `temp/` 目录下管理临时 .md 文件
  - 自动命名规则：`{slug}_temp_{timestamp}.md`
  - 提供 `saveTemp` / `loadTemp` / `loadTempByFileName` / `confirmSave`（转正）/ `clearAll` 方法
  - `confirmSave` 支持自定义 slug 重命名

### 2. 新增 API 路由
- **`POST /api/save-temp`** — 保存内容到临时目录，返回 fileName
- **`POST /api/load-temp`** — 根据 fileName 加载临时文件内容
- **`POST /api/confirm-save`** — 将临时文件转正为正式文件（写入 input/ 目录并删除临时文件）

### 3. 预览页面
- **新增** `preview/[slug]/page.tsx` — 带 slug 的预览页面
  - `__temp__{fileName}` 前缀 → 从临时目录加载
  - `{slug}` → 从正式目录加载
- **新增** `preview/[slug]/PreviewClient.tsx` — 预览客户端组件
  - 临时文件模式：显示「保存为正式文档」按钮
  - 正式文件模式：显示「在编辑器中打开」按钮
  - 独立导航栏，含主题切换器
- **修改** `preview/page.tsx` — 兼容旧版 localStorage 方式

### 4. 改造预览触发逻辑
- **修改** `AIArea.tsx` — 预览按钮调用 `/api/save-temp` 保存到服务端
- **修改** `editor/page.tsx` — "新窗口预览"先保存临时文件再打开预览页
- 保留 localStorage 回退机制

### 5. 文档归档
- 将 `plans/图标规划/` 移入 `docs/归档/图标规划_20260709/`（因收益/维护性价比决定放弃）

## 技术要点
- 临时文件与正式文件共享同一套预览组件，通过 `isTempFile` prop 区分
- ApiClient 自动解包 `ApiResponse`，前端直接获取 data 字段
- 转正流程：临时文件 → confirmSave → input/ 正式目录 → 自动清理临时文件
- 构造函数验证通过，所有路由正常编译
