## 二、核心变更：三层优化逐步消灭白屏

### 2.1 第一层：Suspense fallback 修复

**问题**：`page.tsx` 中 `<Suspense fallback={null}>` 导致 async 组件加载期间渲染空白区域。

**修复**：将 `fallback={null}` 替换为 `<PageLoading />` 旋转动画组件，与 `loading.tsx` 风格统一。

### 2.2 第二层：SVG `<animateTransform>` 替代 CSS `@keyframes`（关键突破）

**问题**：浏览器首次渲染（First Paint）被**外部 CSS 文件阻塞**。即使加载器写在 HTML 中，浏览器也要等 `globals.css`、`katex.min.css` 下载并构建 CSSOM 后，才能处理 `animation` 属性，这造成了 2-3 秒白屏。

**关键认知**：浏览器的 CSS 动画引擎和 SVG 动画引擎是**两个独立子系统**。CSS 动画依赖 CSSOM（需等待外部 CSS 下载），SVG `<animateTransform>` 在 HTML 解析阶段即可运行。

**修复**：将 `layout.tsx` 中的 CSS 动画加载器替换为纯 SVG：
```html
<svg>
  <circle>
    <animateTransform attributeName="transform" type="rotate"
      from="0 24 24" to="360 24 24" dur="0.8s" repeatCount="indefinite" />
  </circle>
</svg>
```

同时在 `<head>` 中内联 `body { background: #f0f5ff; margin: 0; }`，确保即使极端情况下页面也有背景色。

配合 `InitialLoader.tsx` 客户端组件，React 水合完成后以 0.3s 淡出动画移除加载器，实现无缝过渡。

### 2.3 第三层：惰性编译预热

**问题**：`next dev` 模式使用惰性编译（lazy compilation），服务器就绪 `/api/files` 返回 200 时，首页 `/` 的 `page.tsx` 及其依赖树尚未被 Webpack 编译。浏览器打开后请求 `/`，服务器需要实时编译（0.5-1.5s），这段时间没有任何 HTML 输出，造成约 1 秒白屏。

**修复**：在 `setup-port.js` 中增加主页预热步骤——先向服务器请求 `/` 等待编译完成返回 200，再打开浏览器。将编译等待从用户感知的临界路径移到启动脚本后台。

```javascript
// 优化前：API 就绪即打开浏览器（等待 1s 无响应）
await waitForApiReady();
openBrowser(url);

// 优化后：先预热编译，再打开浏览器
await waitForApiReady();
await httpGet(url);  // 预热主页，后台完成编译
openBrowser(url);    // 浏览器打开时 HTML 即刻流式输出
```

## 三、优化后加载时间线

```
[服务器启动]
    │
    ▼
[API 就绪]  ← 检测 /api/files 返回 200
    │
    ▼
[预热主页 /]  ← HTTP GET 触发 Next.js 惰性编译（约 1s，用户无感知）
    │
    ▼
[打开浏览器]
    │
    ▼  HTML 已预编译，瞬间流式输出
[浏览器请求 /]
    │
    ▼  SVG <animateTransform> 零延迟旋转 🌀
[SVG 旋转动画启动]  ← 不等 CSS，HTML 解析到标签即开始
    │
    ▼
[外部 CSS 下载中（2-3s）]  ← 旋转动画持续运行，用户感知"系统正在加载"
    │
    ▼
[React 水合完成] → InitialLoader 淡出 → 内容就绪
```

**从浏览器窗口弹出到看到旋转动画：零白屏。**

## 五、技术沉淀

本次优化沉淀了以下可迁移的工程经验，已整理为面试资源文档：

1. **分层诊断方法**：从表层代码 → 浏览器渲染机制 → 框架编译机制，逐层深入
2. **浏览器双动画引擎认知**：CSS 动画依赖 CSSOM（被外部 CSS 阻塞），SVG 动画在 HTML 解析阶段即刻生效
3. **惰性编译预热模式**：开发模式中"服务器就绪"≠"页面就绪"，主动预热关键页面
4. **产品思维**：加载动画的心理学意义——用户不介意等待，但介意空白等待
