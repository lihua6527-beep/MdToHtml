## 三、下午：AI 服务层配置与容错增强

实施自 `plans/06_AI服务层配置与容错增强计划_20260710.md`（已归档到 `docs/归档/`）。

### 3.1 API Key 配置增强

| 组件 | 改进 |
|:----|:-----|
| `AIArea.tsx` | 新增「API Key 未配置」琥珀色引导提示条 + 👉 前往设置按钮 |
| `HomeClient.tsx` | 监听 `open-settings` 自定义事件，支持从引导条跳转到 AI 设置面板 |
| `env-hot-loader.ts` | 修复持久化机制：`sessionStorage` → `localStorage` + 新增 `ensureLocalStorageRestored()` 初始化恢复 |

**持久化三路保障**：
```
保存 Key → 内存（即时）→ localStorage（关闭重开不丢失）→ .env.local（重启不丢失）
读取 Key → 内存 > localStorage > process.env
```

### 3.2 错误码友好提示

`AIService.ts` 新增 `parseError()` 结构化映射：

| 状态码 | 中文提示 |
|:------|:---------|
| 401 | "API Key 无效，请检查设置面板中的 Key 是否正确" |
| 403 | "账户余额不足或权限受限，请检查 DeepSeek 账户" |
| 429 | "请求过于频繁，请稍后重试" |
| 500+ | "AI 服务暂时不可用，请稍后重试" |
| 网络超时 | "网络连接超时，请检查网络后重试" |
