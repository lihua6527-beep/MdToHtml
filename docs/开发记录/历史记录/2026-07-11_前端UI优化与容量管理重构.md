## 🔥 晚间第二波：启动时序优化与首页体验重设计

### 背景
用户反馈启动后黑 CMD 等待过久（~2.8s 才打开浏览器），且浏览器打开后加载动画"形同虚设"（因 React hydration 过早隐藏）。此外首页欢迎页内容空泛，功能引导不足。

---

### 八、启动时序优化（setup-port.js 重构）

| 文件 | 变更内容 |
|------|---------|
| `scripts/setup-port.js` | 完全重写启动逻辑 |

**删除**：
- 阻塞式 `/api/files` 轮询（`for + await sleep(1s) × 60`）
- 阻塞式主页预热（`httpGet(url, 30000)`，浪费 ~1.1s）
- `httpGet()` 函数不再需要

**新增**：
- `server.stdout.on('data', ...)` 监听 Next.js 输出，检测到 `✓ Ready in` 后**立即**打开浏览器
- 后台并行 `warmHomepageInBackground()` 预热主页（不 await，不阻塞）
- 30 秒后备超时保护

**修复**：
- `stdio: 'inherit'` → `['inherit', 'pipe', 'inherit']`（原配置导致 `server.stdout === null`，调用 `.on('data')` 抛错闪退）

**效果**：
- 优化前：黑 CMD 等 **2.8s** → 打开浏览器
- 优化后：**1.3s** 看到浏览器弹出加载动画 → 1.1s 后台编译主页

### 十、加载动画根治（拆除 InitialLoader）

| 文件 | 变更内容 |
|------|---------|
| `src/app/layout.tsx` | 移除 InitialLoader 组件，改为内联 `<script>` 控制隐藏时机 |

**问题分析**：
- 旧逻辑：React 水合完成 → `InitialLoader` 立即隐藏（第 0.3s）→ `Suspense` 弹出 `PageLoading`（第 1.5s+）
- 用户感知：**白屏（等 HTML 流）→ 闪烁 #initial-loader → 蓝色 loading → 最终内容**
- 动画毫无意义，白屏时间才是真实等待

**根治方案**：
- 移除 `InitialLoader` 组件（不再依赖 React 生命周期）
- 在 `<body>` 中维护 `#initial-loader` DOM，隐藏时机由内联 `<script>` 控制：

```js
window.addEventListener('load', () => {
  setTimeout(hideLoader, 800);  // 等所有资源加载完毕再延迟隐藏
});
setTimeout(hideLoader, 3000);   // 3 秒后备兜底
```

**效果**：加载动画从 HTML 解析即刻显示（零 CSS 依赖的 SVG animateTransform），到 `window.onload` + 800ms 后才逐渐淡出，覆盖了整个 JS 下载/解析/渲染周期，**不再白屏消失**。
