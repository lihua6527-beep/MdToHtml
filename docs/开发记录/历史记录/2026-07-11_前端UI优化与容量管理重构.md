## 二、修复AI模式返回逻辑

### 问题
API Key 配置好后返回的是"经典模式"（欢迎页），而用户希望直接使用 AI 转换功能。

### 修改

| 文件 | 变更 |
|------|------|
| `src/components/AI/AIArea.tsx` | "📄 经典模式"按钮 → "🏠 返回首页"（功能保留，语义改为清晰返回）→ 后又改为 "📂 导入本地文件" |
| `src/components/AI/AIArea.tsx` | 修复"前往设置"按钮：不再先 `onClose()` 关闭 AI 区域再打开设置，而是直接触发 `open-settings` 事件，用户配置完 API Key 后仍处于 AI 页面 |

### 效果
- 用户配置 API Key 后不会跳转到欢迎页，继续位于 AI 转换界面
- 无需手动再次进入 AI 模式

## 三、存储容量管理重构

### 背景
存储容量条原来占据文档列表一栏的空间，用户希望释放该区域用于文档列表展示。

### 修改方案

| 文件 | 变更 |
|------|------|
| `src/components/ui/ListHeader.tsx` | 在搜索图标**左侧**新增 `<Database>` 容量图标按钮，接收 `onCapacityClick` 回调 |
| `src/components/DocumentList.tsx` | 传递 `onCapacityClick` 给 ListHeader；移除外联 `<CapacityProgressBar />` 组件；新增右侧弹出面板（点击容量图标触发）|

### 容量管理面板内容
点击容量图标弹出右侧面板，包含：
1. **当前使用状态** — 完整的 CapacityProgressBar + 已用/上限统计
2. **容量上限调整** — 6 档预设按钮（20/50/100/200/300/500）
3. **自动清理策略说明**

## 四、文档列表收缩文字隐藏

### 修改
`src/components/ui/ListHeader.tsx`：当侧边栏收缩时（`isExpanded=false`）：

## 五、AI界面连接状态指示
