## 后续归档记录 (21:31)

**改动摘要**: 启动时序优化——实现独立加载窗口方案（port+1 HTTP 服务器 + /status 端点 + stdout 联动）

- **背景**: 经过三层优化（Suspense fallback、SVG 动画、主页预热）后，白屏仍存在约 1 秒 TTFB。核心原因是 Next.js dev 模式惰性编译 `/` 路由期间 HTTP 无响应。
- **试错**: 尝试 file:// 加载页（被 Chrome CORS 拦截）→ 尝试 Image 检测（语义模糊，无法区分连接状态）→ 最终采用 port+1 加载服务器
- **最终方案**: 在 port+1 启动极简 Node.js HTTP 服务器，提供加载页 + `/status` 端点。`setup-port.js` 通过 stdout 监听 `✓ Compiled /` 后设置 `statusReady`，加载页轮询 `/status` 收到 'ready' 后立刻跳转
