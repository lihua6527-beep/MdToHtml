# CHD协议文档路径管理功能实现计划

## 1. 项目概述

本计划旨在实现CHD协议文档路径管理功能，允许用户自定义CHD协议文档的存储路径，同时保证文档名固定为"CHD协议.md"。此外，还将在设置界面中添加CHD协议预览功能，方便用户查看和复制协议内容。

## 3. 技术实现要点

1. **配置管理扩展**:
   - 在`PathConfig`接口中添加`chdProtocol`字段
   - 更新`ConfigManager`类，支持CHD协议文档路径的配置
   - 更新`PathManager`类，添加CHD协议文档路径的解析和获取方法

2. **API端点更新**:
   - 更新`/api/app-info`端点，使其返回CHD协议文档路径
   - 更新`/api/app-info/chd-protocol`端点，使其首先使用配置的CHD协议文档路径

3. **设置面板更新**:
   - 在设置面板中添加CHD协议文档路径配置选项
   - 允许用户修改CHD协议文档路径
   - 确保路径修改后能正确保存和应用

4. **CHD协议预览功能**:
   - 确保设置界面中的CHD协议预览功能能正确显示协议内容
   - 确保一键复制功能正常工作

## 4. 预期成果

1. 用户可以在设置界面中配置CHD协议文档的存储路径
2. 系统会自动使用配置的路径读取CHD协议文档
3. 如果配置的路径不存在，系统会尝试使用默认路径
4. 用户可以在设置界面中预览CHD协议内容并一键复制

## 5. 风险评估

1. **文件路径问题**: CHD协议文档路径可能因环境不同而变化，需要使用配置管理
2. **兼容性问题**: 需要确保向后兼容，当没有配置CHD协议文档路径时使用默认路径
3. **权限问题**: 需要确保系统有足够的权限读取和写入CHD协议文档路径
