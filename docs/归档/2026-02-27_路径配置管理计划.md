# 2026-02-27 路径配置管理计划

## 1. 目标与背景 (Objectives)
解除当前系统对 `input/output` 文件夹的硬编码限制，允许用户自定义输入输出路径。同时，提供一个类似 Windows 资源管理器的 Web 界面，方便用户选择路径。系统首次启动时，应自动初始化默认文件夹结构。

## 2. 核心功能 (Core Features)

### 2.1 混合路径配置 (Hybrid Path Configuration)
- **默认策略**: 如果未配置，默认在项目根目录下创建 `input`, `output`, `data`, `.trash`。
- **自定义策略**: 用户可独立配置每个路径（例如：输入在 D 盘，输出在 E 盘）。
- **持久化**: 配置存储在根目录 `config.json`。

### 2.2 首次运行初始化 (First Run Initialization)
- 系统启动时检查 `config.json`。
- 如果不存在，创建默认配置并自动执行 `fs.mkdir` 创建必要文件夹。
- 如果存在但文件夹缺失，尝试自动创建。

### 2.3 系统级文件夹选择器 (System-like Folder Selector)
- **UI 风格**: 模仿 Windows 资源管理器（图二）。
  - **面包屑导航**: 显示当前路径，支持快速跳转父级。
  - **文件夹视图**: 网格/列表展示文件夹图标。
  - **交互**: 双击进入，单击选中，"选择此文件夹" 确认。
- **后端支持**: 提供文件系统遍历 API（仅限本地环境）。

## 3. 技术架构 (Technical Architecture)

### 3.1 配置文件结构 (`config.json`)
```json
{
  "paths": {
    "input": "C:\\Users\\User\\Desktop\\MdToHmtl\\input",
    "output": "C:\\Users\\User\\Desktop\\MdToHmtl\\output",
    "data": "C:\\Users\\User\\Desktop\\MdToHmtl\\data",
    "trash": "C:\\Users\\User\\Desktop\\MdToHmtl\\.trash"
  },
  "system": {
    "theme": "light",
    "language": "zh-CN"
  }
}
```

### 3.2 后端模块 (`lib/config-manager.ts`)
- **Singleton Pattern**: 确保配置全局唯一。
- **API**:
  - `loadConfig()`: 读取并缓存配置。
  - `updateConfig(key, value)`: 更新并写入磁盘。
  - `initializePaths()`: 启动时调用，确保文件夹存在。
- **API Routes**:
  - `GET /api/config`: 获取当前配置。
  - `POST /api/config`: 更新配置。
  - `GET /api/fs/list`: 参数 `path` (base64 encoded recommended)，返回 `{ parent, folders: [], current }`。

### 3.3 前端组件 (`components/settings/PathSelector.tsx`)
- **State**: `currentPath` (当前浏览路径), `selectedPath` (选中的路径)。
- **UI Components**:
  - `BreadcrumbBar`: 路径导航条。
  - `FolderGrid`: 显示文件夹列表 (Icon + Name)。
  - `ActionFooter`: "新建文件夹" (可选), "确定", "取消"。
