## 二、现有导出系统关键发现

经读取 `HtmlBundler.tsx`、`CssExtractor.ts`、`ExportButton.tsx`、`FileService.saveExport()`、`/api/save-export` 源码后：

| 发现 | 说明 |
|------|------|
| `HtmlBundler.bundle()` 在浏览器端可用 | 003 计划判断"不可用"是错误的。`ExportButton.tsx`（客户端组件）已成功调用。`renderToStaticMarkup` 被 Next.js 编译为客户端可执行代码 |
| CssExtractor 依赖 `document.styleSheets` | 仅在浏览器端可用，但在服务端 API Route 中不可用 |
| `/api/save-export` 只存 HTML 字符串 | 不接收 markdown，不做 HTML 渲染 |

**最终导出方案**: 直接复用现有流程 —— `HtmlBundler.bundle()` → `FileService.saveExport()` → 浏览器下载。与 `ExportButton.tsx` 完全一致，无需新增 API Route。
