# 解析健壮性增强计划

## 问题分析
当前系统在处理包含代码块的卡片时存在问题，代码块被识别为单独的块，导致卡片被分割，无法作为一个整体渲染。

## 任务列表

### [x] 任务1：修改CHD解析器逻辑，将代码块作为卡片内容的一部分
- **Priority**: P0
- **Depends On**: None
- **Description**:
  - 修改`chdParser.ts`中的解析逻辑，当在卡片内容中遇到代码块时，将其作为卡片内容的一部分，而不是单独的块
  - 确保代码块的开始和结束标记被正确处理
- **Success Criteria**:
  - 代码块被识别为卡片内容的一部分，而不是单独的块
  - 包含代码块的卡片能被正确解析为单个卡片
- **Test Requirements**:
  - `programmatic` TR-1.1: 解析包含代码块的卡片时，返回单个卡片对象
  - `human-judgement` TR-1.2: 包含代码块的卡片在渲染时显示为单个卡片，代码块内容正确显示
- **Notes**: 需要处理代码块的开始和结束标记，确保它们被正确包含在卡片内容中

### [x] 任务2：优化卡片内容解析，忽略无意义的格式符号
- **Priority**: P1
- **Depends On**: 任务1
- **Description**:
  - 优化卡片内容的解析逻辑，确保只保留代码段，忽略无意义的格式符号
  - 确保代码块的格式正确，没有多余的空白或格式符号
- **Success Criteria**:
  - 卡片内容中的代码块只包含代码本身，没有无意义的格式符号
  - 代码块在渲染时显示正确，没有多余的空白或格式符号
- **Test Requirements**:
  - `programmatic` TR-2.1: 解析包含代码块的卡片时，代码内容中不包含无意义的格式符号
  - `human-judgement` TR-2.2: 代码块在渲染时显示整洁，没有多余的空白或格式符号
- **Notes**: 需要处理代码块的前后空白，确保只保留代码本身

### [x] 任务3：测试和验证
- **Priority**: P2
- **Depends On**: 任务1, 任务2
- **Description**:
  - 测试各种包含代码块的卡片场景，确保解析和渲染正确
  - 验证边缘情况，如多个代码块、嵌套代码块等
- **Success Criteria**:
  - 所有测试场景都能正确解析和渲染
  - 边缘情况也能被正确处理
- **Test Requirements**:
  - `programmatic` TR-3.1: 测试包含单个代码块的卡片
  - `programmatic` TR-3.2: 测试包含多个代码块的卡片
  - `human-judgement` TR-3.3: 所有测试场景的渲染结果都符合预期
- **Notes**: 需要创建测试用例，覆盖各种代码块使用场景

## 实现思路
1. 修改`chdParser.ts`中的解析逻辑，当在卡片内容中遇到代码块时，将其作为卡片内容的一部分
2. 确保代码块的开始和结束标记被正确处理，不被视为块的分隔符
3. 优化卡片内容的解析，确保只保留代码段，忽略无意义的格式符号
4. 测试各种包含代码块的卡片场景，确保解析和渲染正确

## 预期结果
- 包含代码块的卡片能被正确解析为单个卡片
- 代码块内容能被正确保留，忽略无意义的格式符号
- 卡片渲染时显示为单个标准卡片，代码块内容正确显示
