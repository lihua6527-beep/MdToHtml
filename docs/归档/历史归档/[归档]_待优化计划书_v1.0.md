# 待优化计划书 (v1.0)

## 1. 离线构建适配 (Offline Build Adaptation) [P1] (已完成)
**目标**: 确保项目支持 Next.js 静态导出 (`output: 'export'`)，使其可部署于 GitHub Pages、Nginx 或任何静态文件服务器，摆脱对 Node.js 运行时的强依赖。

**执行步骤**:
1.  **配置调整**: 修改 `next.config.js`，启用 `output: 'export'` 模式 (仅在生产构建时生效，保留 Dev 模式 API 能力)。
2.  **图片优化**: 禁用 Next.js 默认的 Image Optimization API (已配置 `unoptimized: true`)。
3.  **路由适配**: 确保所有动态路由 (`[slug]`) 实现 `generateStaticParams` (已确认实现并支持中文编码)。
4.  **API 解耦**: 确认为前端纯静态构建，API 路由需剥离或仅用于开发环境 (已验证)。
5.  **构建验证**: 执行 `npm run build` 确保生成 `out/` 目录且无报错 (已验证，构建成功)。

## 2. 全站 UI 标准化 (UI Standardization) [P3]
**目标**: 统一全站交互组件，移除原生 HTML 控件，全面拥抱 `shadcn/ui` 设计体系。

**执行步骤**:
1.  **组件替换**: 将剩余的 `<dialog>`, `<input>`, `<select>` 等原生标签替换为 `Dialog`, `Input`, `Select` 等 `shadcn/ui` 组件。
2.  **样式统一**: 确保所有弹窗、表单、提示信息的圆角、阴影、配色符合莫兰迪色系规范。
3.  **交互微调**: 优化 Hover、Focus 状态的视觉反馈。

## 3. 自动化测试基座 (Test Infrastructure) [P1]
**目标**: 建立核心逻辑的自动化测试防线，保障解析器等关键模块的稳定性。

**执行步骤**:
1.  **环境搭建**: 安装 Jest 及相关 TypeScript 类型支持。
2.  **核心测试**: 针对 `chdParser.ts` (Markdown 解析器) 编写单元测试用例，覆盖标准语法与边缘情况。
3.  **CI 集成**: 配置测试脚本，建议在 Git 提交前通过 Husky 自动运行。
