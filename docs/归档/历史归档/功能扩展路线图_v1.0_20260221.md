# 功能扩展路线图 (Feature Expansion Roadmap)

**版本**: v1.0
**日期**: 2026-02-05
**依据**: 项目进度与可行性评估报告

## 1. 高价值功能清单 (Top 3 High-Value Features)

### Feature 1: 专业级编辑器内核升级 (Editor Kernel Upgrade)
*   **优先级**: P0
*   **痛点**: 原生 textarea 体验差，无高亮，无行号。
*   **方案**: 集成 CodeMirror 6。
*   **验收标准**:
    *   支持 Markdown 语法高亮。
    *   显示行号。
    *   保持原有的双向滚动同步功能。
    *   支持 Ctrl+Z / Ctrl+Y 撤销重做。

### Feature 2: 离线化构建与部署 (Offline Build & Deploy)
*   **优先级**: P1
*   **痛点**: `next build` 默认产物依赖 Server，且静态导出路径在本地 file:// 协议下失效。
*   **方案**: 优化 `next.config.js` 配置 `output: 'export'`，并编写脚本修正资源路径。
*   **验收标准**:
    *   `out/index.html` 可直接双击打开，无 JS/CSS 404 错误。
    *   所有图片资源正常加载。

### Feature 3: UI 组件系统标准化 (UI Standardization)
*   **优先级**: P2
*   **痛点**: 样式维护困难，缺乏一致性。
*   **方案**: 引入 shadcn/ui (Radix UI + Tailwind)。
*   **验收标准**:
    *   替换现有的 Button, Input, Modal 组件。
    *   建立统一的主题配置文件 (CSS Variables)。
