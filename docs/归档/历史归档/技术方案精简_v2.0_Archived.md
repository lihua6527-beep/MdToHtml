## 3. 整体架构 (Overall Architecture)

### 3.1 核心数据流 (Core Data Flow)

```mermaid
graph TD
    User[用户输入] -->|Progressive Guidance| Input{输入模式};
    Input -->|Form Mode| StructData[结构化数据];
    Input -->|Free Mode| RawText[纯文本流];
    RawText -->|Edge AI (50MB)| Distiller[任务特化蒸馏模型];
    Distiller -->|CHD Formatting| StructData;
    StructData -->|Validation| AST[DocMind AST];
    AST -->|Layout Engine| Render[React 渲染器];
    Render -->|Preview| UI[实时预览界面];
```

### 3.2 关键组件
- **CHD Parser**: 基于三级刚性约束的快速解析器，将文本流转换为 AST。
- **Distillation Model**: 运行在浏览器端的微型语言模型，专精于将自然语言“翻译”为 CHD 格式。
- **Layout Engine**: 负责解析 Section 的 `layout` 属性（如 `horizontal`, `wave`），并将 Cards 渲染为对应的 UI 组件。
