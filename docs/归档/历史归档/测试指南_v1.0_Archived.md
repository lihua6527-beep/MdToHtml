# 测试指南 (Testing Guide)

## 1. 测试概览
本项目采用 **Jest** + **React Testing Library** 作为单元测试框架，确保核心逻辑（验证器、工具函数）与关键组件的稳定性。

### 核心特性
- **非阻塞执行**: 测试运行在独立进程中，不影响开发服务器。
- **自动覆盖率报告**: 每次运行生成详细的覆盖率统计。
- **CI 集成**: 代码提交时自动触发测试流水线。

## 2. 运行测试

### 常用命令
| 命令 | 说明 |
| :--- | :--- |
| `npm test` | 运行所有单元测试一次 |
| `npm run test:watch` | 监视模式，文件变动时自动重新运行相关测试 |
| `npm run test:ci` | CI 模式，生成覆盖率报告并退出 |

### 目录结构
测试文件应与源文件同级（推荐）或置于 `__tests__` 目录下。文件名格式为 `*.test.ts` 或 `*.test.tsx`。

```text
src/
  lib/
    validator.ts
    validator.test.ts  <-- 单元测试
```

## 3. 测试覆盖范围
当前主要覆盖：
- `src/lib/validator.ts`: 核心 CHD 语法验证逻辑。
- 计划增加: `src/lib/utils.ts`, `src/components/CHD/*.tsx`。

## 4. 故障排查
如果测试出现 "Blocking" 或 "No Output"：
1. 检查 `jest.config.js` 配置是否正确。
2. 确保没有在测试文件中编写无限循环或未决议的 Promise。
3. 使用 `npm test -- --verbose` 查看详细输出。
