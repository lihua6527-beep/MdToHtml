# 版本更新与多格式输出 (Versioning & Multi-format Output)

## 1. 多格式输出规范 (Multi-format Specs)
利用核心渲染引擎的资产（CSS 变量、组件库），支持多种交付形态。

### 1.1 幻灯片模式 (Presentation Mode)
- **原理**：基于网页技术的幻灯片生成。
- **映射规则**：
  - 每个 `## 二级标题` 映射为一张幻灯片（Viewport Height 容器）。
  - 标题内的卡片组合映射为单页内的排版布局。
- **技术实现**：
  - **Reveal.js 适配器**：将 CHD 结构转换为 Reveal.js 兼容的 HTML 结构。
  - **样式复用**：直接引用项目的 Design Tokens，确保 PPT 与网页品牌一致。

### 1.2 PDF 文档生成
- **原理**：高保真网页打印快照。
- **工具链**：
  - **Gotenberg** (Docker 容器)：用于服务端生成，适合批量任务。
  - **Puppeteer** (Node.js)：用于客户端/本地生成，支持精细控制。
- **关键配置**：
  - 打印样式表 (`@media print`)：隐藏交互元素，优化分页断点，添加页眉页脚。

## 2. 交互数据与版本迭代
- **数据驱动更新**：
  - 用户的每一次“调整”操作（如修改布局、更换样式）都被记录为数据集。
  - **Session 结构**：`{ input_md, user_actions, final_output }`。
- **RAG 协议优化**：
  - 定期使用 RAG 系统检索最新的 `FORMAT_SPEC.md` 和组件文档。
  - 测试通用大模型（GPT-4/Claude）对协议的理解偏差。
  - 根据偏差反向更新协议文档（如增加更明确的约束或示例）。

## 3. 路线图 (Roadmap)
- **v1.0 (当前)**：
  - 核心规则引擎稳定。
  - 支持基础博客渲染。
  - 初步的 CHD 协议定义。
- **v1.5 (近期)**：
  - 引入可视化调整界面（无工具栏设计）。
  - 实现“幻灯片模式”预览与导出。
- **v2.0 (远期)**：
  - 部署 RAG 测试框架，实现协议的自我进化。
  - 训练专属“交互经验小模型”，提供智能布局建议。
