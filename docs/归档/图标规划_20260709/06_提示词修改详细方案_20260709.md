## 一、概览

在 Prompt A（默认稳定版）和 Prompt B（备选学术版）中增加完整的图标使用指引。这是全链路容错架构的第一层——从上游减少 AI 生成错误。

## 二、步骤 4.1：Prompt A 图标指引增强（1h）

### 2.1 修改位置

**文件**: `MdToHtml/src/services/ai/PromptEngine.ts`

**具体位置**: `getPromptA()` 方法中，L2 Card 属性说明区域（约第89行）

### 2.2 需要替换的代码

**当前内容（第86-90行范围）：**

```
- icon（推荐填写）：图标名称，如 "book"、"star"、"brain"、"chart"、"lightbulb"、"code" 等
```

**替换为：**

```
- icon（推荐填写）：为卡片添加左上角圆形图标，增强视觉表现力。用法：{icon="标准图标名"}
  
  图标使用规则（请严格遵循）：
  (1) 成套使用：同一 Section 下的所有卡片，要么都有图标，要么都不用图标。绝不能出现部分有、部分没有的情况。
  (2) 仅限矩形：图标只能在标准矩形卡片（默认形状）中使用，不能用于圆形、浮动形等特殊形状。
  (3) 相关性：选择与卡片内容语义最匹配的图标，不相干的图标会干扰阅读。
  (4) 命名规范：必须使用下方列表中的标准图标名。图标名全小写，多词用连字符连接（如 bar-chart 而不是 barchart）。
  
  支持的图标列表（按场景分类，共12类约50个图标）：
  
  技术/性能类：zap, cpu, code, terminal, server, monitor
  数据/分析类：bar-chart, pie-chart, database, activity, chart
  知识/文档类：book, book-open, file-text, file-code, layers
  安全防护类：shield, lock, key, alert-circle, alert-triangle
  AI/智能类：brain, network, eye, lightbulb
  通信/连接类：message, message-square, send, share-2, wifi, globe
  成果/成就类：award, star, target, rocket, check-circle, trending-up
  时间/进度类：clock, calendar, timer, history
  创意/创新类：lightbulb, puzzle, pen-tool, zap
  工具/配置类：settings, filter, search, download, tool
  用户/管理类：user, users, user-plus, bell
  媒体/内容类：camera, image, music, video, file
```

### 2.3 自检清单更新

**位置**: 第143-144行附近（常见错误自检清单末尾）

在当前10项后追加3项：

13. ☐ 图标是否只在标准矩形卡片中使用？
```

|------|--------|--------|

1. **在 L2 Card 属性说明中加入图标规则（第323-328行附近）**：

当前内容：
```
     - **Icons**:
         - **Optional**: You may add icons to cards using `{icon="icon-name"}`.
         - **Icon List**: Refer to the icon library for available icon names.
         - **Consistency Rule**: If you use icons in a section, ALL cards in that section MUST have an icon. Do NOT mix cards with and without icons in the same section.
         - **Relevance**: Choose icons that are relevant to the card content.
         - **Moderation**: Use icons sparingly to avoid visual clutter.
```

更新为：

```
     - **Icons**:
         - **Optional but recommended**: Add icons to cards using `{icon="icon-name"}`.
         - **Naming Convention**: All lowercase, use hyphens for multi-word names (e.g., `bar-chart`, not `barchart`).
         - **Consistency Rule (STRICT)**: If you use icons in a section, ALL cards in that section MUST have an icon. Do NOT mix cards with and without icons in the same section.
         - **Shape Restriction**: Icons only work in standard rectangular cards (default shape). Do NOT use icons in circle/arrow/floating shapes.
         - **Relevance**: Choose icons that are semantically relevant to the card content.
         - **Icon List**: 
           Tech/Performance: zap, cpu, code, terminal, server
           Data/Analysis: bar-chart, pie-chart, database, chart
