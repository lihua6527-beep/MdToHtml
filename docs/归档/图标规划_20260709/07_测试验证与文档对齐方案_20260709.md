**第52-62行**（注意事项更新）：

```markdown
## 注意事项

### 1. 图标使用限制
- 图标只能在标准的矩形框卡片中使用（shape 为 `rect` 或默认）
- 在非矩形卡片（circle、arrow、floating）中，图标属性会被忽略

### 2. 成套使用（重要）
- 同一 Section 下的所有卡片，要么都使用图标，要么都不使用图标
- 如果使用不一致，系统会显示警告信息
- 系统会自动修正部分有图标、部分没有的情况

### 3. 命名规范
- 图标名称必须使用全小写字母
- 多词名称使用连字符连接（如 `bar-chart` 而不是 `barchart`）
- 参考上方的图标列表，不要使用列表外的名称

### 4. 图标颜色
- 图标的背景颜色会根据卡片颜色自动调整
- 当卡片使用默认颜色时，图标背景为浅色，图标为主色
- 当卡片使用主题颜色时，图标背景为卡片颜色，图标为白色
```

**第68-100行**（最佳实践更新）：

```markdown
## 最佳实践

1. **一致性**：在同一 section 下，要么所有卡片都使用图标，要么都不使用
2. **相关性**：选择与卡片内容相关的图标，增强视觉效果
3. **命名规范**：使用连字符命名，如 `bar-chart`、`file-text`、`pen-tool`
4. **适度使用**：核心观点/亮点类卡片优先使用，普通描述类卡片谨慎使用
5. **仅限矩形**：图标只用在标准矩形卡片上
```

**第103-115行**（常见问题更新）：

在常见问题中增加：

```markdown
### Q: 图标不成套使用会怎样？
A: 系统会自动检测并显示警告。同时后端修正引擎会自动补齐缺失的图标，保持视觉一致。

### Q: 为什么新的标准命名和以前不一样？
A: 为统一规范，所有图标名已统一为全小写+连字符格式。旧名称仍然兼容可用（向后兼容），但建议使用新标准名。

### Q: 怎么知道哪些图标名称是标准的？
A: 参考本文档前面的图标列表。所有标准名都使用连字符命名（如 `bar-chart`），不会出现驼峰或无分隔符的命名。
```

```typescript
import { autoFixIcons, SectionIconInfo } from '../IconAutoFixService';

// 模拟 iconExists
jest.mock('../../../lib/icon-manager', () => ({
  iconExists: (name: string) => {
    const validIcons = ['zap', 'cpu', 'brain', 'test', 'file-text'];
    return validIcons.includes(name);
  }
}));

describe('IconAutoFixService', () => {
  test('fills missing icons when section has partial icons', () => {
    const sections: SectionIconInfo[] = [{
      sectionTitle: 'Test Section',
      cards: [
        { blockIndex: 0, iconName: 'zap', isValid: false },
        { blockIndex: 1, iconName: 'cpu', isValid: false },
        { blockIndex: 2, iconName: null, isValid: false },
      ]
    }];
    
    const result = autoFixIcons(sections);
    
    expect(result.totalFixes).toBe(1);
    expect(result.fixedSections[0].cards[2].iconName).toBe('zap');
  });
  
  test('replaces invalid icon names with most used valid one', () => {
    const sections: SectionIconInfo[] = [{
      sectionTitle: 'Test Section',
      cards: [
        { blockIndex: 0, iconName: 'zap', isValid: false },
        { blockIndex: 1, iconName: 'INVALID_A', isValid: false },
        { blockIndex: 2, iconName: 'INVALID_B', isValid: false },
      ]
    }];
    
    const result = autoFixIcons(sections);
    
    expect(result.totalFixes).toBe(2);
    expect(result.fixedSections[0].cards[1].iconName).toBe('zap');
    expect(result.fixedSections[0].cards[2].iconName).toBe('zap');
  });
  
  test('keeps all-valid icons unchanged', () => {
    const sections: SectionIconInfo[] = [{
      sectionTitle: 'Test Section',
      cards: [
        { blockIndex: 0, iconName: 'zap', isValid: false },
        { blockIndex: 1, iconName: 'cpu', isValid: false },
      ]
    }];
    
    const result = autoFixIcons(sections);
    
    expect(result.totalFixes).toBe(0);
    expect(result.fixedSections[0].cards[0].iconName).toBe('zap');
    expect(result.fixedSections[0].cards[1].iconName).toBe('cpu');
  });
  
  test('clears all icons when all are invalid', () => {
    const sections: SectionIconInfo[] = [{
      sectionTitle: 'Test Section',
      cards: [
        { blockIndex: 0, iconName: 'INVALID_A', isValid: false },
        { blockIndex: 1, iconName: 'INVALID_B', isValid: false },
      ]
    }];
    
    const result = autoFixIcons(sections);
    
    expect(result.totalFixes).toBe(2);
    expect(result.fixedSections[0].cards[0].iconName).toBeNull();
    expect(result.fixedSections[0].cards[1].iconName).toBeNull();
  });
  
  test('handles empty sections gracefully', () => {
    const result = autoFixIcons([]);
    expect(result.totalFixes).toBe(0);
    expect(result.fixedSections).toEqual([]);
  });
});
```
