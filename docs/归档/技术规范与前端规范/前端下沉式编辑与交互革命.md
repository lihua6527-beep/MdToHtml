# 前端下沉式编辑与交互革命 (Immersive Editing & Interaction)

> **架构治理注脚 (2026-02-21)**:
> 本文档中提及的“模型训练”、“数据捕获”等智能化功能，在 Phase 2 阶段仅限于 **本地规则引擎 (Local Rule Engine)** 与 **无状态启发式算法**。
> **架构红线**: 严禁引入外部数据库或依赖云端算力，所有用户习惯数据仅允许以本地 JSON 配置文件形式存储。强调本地优先策略。

## 1. 核心理念：无工具栏的沉浸式体验
打破传统“顶部工具栏 + 内容编辑区”的割裂模式，采用 **上下文感知的智能交互**。
- **设计哲学**：系统不仅是编辑器，更是理解用户意图的设计伙伴。
- **交互流**：用户在预览界面直接操作，系统根据当前选中的元素（全局、卡片、文字）动态提供恰到好处的调整选项。

## 2. 三层交互体系
操作界面围绕系统的三层样式架构设计：

### 第一层：全局控制 (Global Control)
- **目标**：调整页面整体氛围与输出。
- **功能**：
  - **主题切换**：一键切换预设的设计令牌组合（深色/浅色/莫兰迪）。
  - **密度调节**：滑块调整全局间距（紧凑/舒适/宽松）。
  - **多格式输出**：导出为 静态网页、PDF文档、PPT幻灯片。

### 第二层：卡片微调 (Card Adjustment)
- **目标**：局部美化与强调。
- **功能**：
  - **样式变体**：点击卡片，弹出该类型的“变体库”（如代码块切换为“Mac窗口风格”或“极简风格”）。
  - **批量应用**：提供“应用到所有同类卡片”选项，快速统一视觉风格。
  - **焦点交互**：为卡片开启“悬停高亮”、“点击聚焦”等动态效果。

### 第三层：布局重组 (Layout Composition)
- **目标**：优化信息流与叙事结构。
- **功能**：
  - **策略切换**：为 `##` 章节切换排列逻辑（如 `主从布局`、`对称布局`、`叙事流布局`）。
  - **智能排序**：支持拖拽卡片，系统自动根据网格规则吸附对齐。

## 3. 智能反馈闭环 (The Feedback Loop)
用户的每一次调整，都是系统进化的燃料。
1. **数据捕获**：记录 `原始输入(CHD MD)` -> `用户调整操作` -> `最终输出` 的完整链路。
2. **模型训练**：利用积累的“调整数据”，训练一个轻量级的“交互经验模型”。
3. **主动建议**：未来，当用户输入类似内容时，系统能主动提示：“根据历史经验，这类内容通常采用‘主从布局’，是否应用？”

## 4. 视觉与体验规范
- **加载状态**：涉及渲染变动时，必须展示优雅的 Loading 动画，杜绝白屏。
- **所见即所得**：所有调整必须无刷新实时生效。
- **可逆性**：提供全局的时间轴撤销/重做功能。
