# 卡片图标资产库

## 概述

本文档提供了CHD协议中所有可用的卡片图标资源，可直接在卡片中使用。

## 使用方法

在卡片标题中使用 `icon` 属性指定图标：

```markdown
### 卡片标题 {icon="zap"}
卡片内容...
```

## 图标API

可以通过以下API获取图标资源列表：

```
GET /api/app-info/chd-protocol/icons
```

**查询参数：**
- `category`: 按分类筛选图标
- `search`: 搜索图标名称或描述

**响应格式：**
```json
{
  "total": 100,
  "categories": ["basic", "tech", "data", ...],
  "icons": [
    {
      "name": "zap",
      "component": "Zap",
      "category": "basic",
      "description": "创新、能量、快速、高效"
    },
    ...
  ]
}
```

可以访问以下页面查看所有图标的实际展示效果：

## 注意事项

1. 所有图标名称均为小写，使用连字符分隔单词
2. 图标名称必须与上述列表中的名称完全匹配
3. 如果使用了未定义的图标名称，将不会显示图标
4. 建议使用描述性的图标名称，以提高代码可读性
