# 样式与交互优化方案 (2026-02-24)

## 1. 背景与目标
本次优化的核心目标是**简化卡片样式体系**、**提升底部工具栏 (BottomToolbar) 的交互体验**，并**增强数据安全性**。通过标准化 UI 组件和引入自动保存机制，解决用户在使用过程中的样式混乱、操作不便和数据丢失风险。

## 2. 核心变更

### 2.1 卡片样式标准化
我们将原本繁杂的卡片样式体系精简为 4 种核心变体，移除了冗余和不常用的样式。

*   **保留样式**:
    *   **标准 (Normal)**: 默认样式，适用于普通文本。
    *   **高亮 (Highlight)**: 替代原本的数据/强调样式，用于突出显示关键信息。
    *   **引用 (Quote)**: 用于引用块或补充说明。
    *   **代码 (Code)**: 专用于代码块展示。
*   **移除样式**:
    *   Data (数据): 合并入 Highlight。
    *   Summary (摘要): 通过布局调整实现类似效果。
    *   Emphasis (强调): 合并入 Highlight。

### 2.2 底部工具栏 (BottomToolbar) 重构
针对底部工具栏的 UI 和交互进行了全面升级：
*   **UI 统一**:
    *   标签页文字统一调整为 `text-sm` (14px)。
    *   控制按钮文字统一调整为 `text-xs` (12px)。
    *   移除了 `{columns}` 等不必要的后缀显示。
*   **布局重组**:
    *   **主题 (Theme)**: 仅保留全局主题切换。
    *   **布局 (Layout)**: 集中管理分区属性（分栏、标题间距、分割线）。
    *   **卡片 (Card)**: 集中管理卡片属性（样式、形状、徽章）。
*   **交互优化**:
    *   修复了点击颜色切换时意外跳转的问题（添加 `stopPropagation`）。
    *   右侧留白集中，为未来扩展预留空间。

### 2.3 智能交互与数据安全
*   **自动保存 (Auto-Save)**: 实现了 5 秒防抖自动保存机制。无论是修改内容、属性还是布局，都会自动触发保存，确保数据安全。
*   **标题后缀修复**: 优化了 `attributeParser` 正则表达式，支持解析未闭合的属性（如 `Title {columns`），防止在输入过程中标题出现乱码。
*   **悬浮撤销/重做**: 移除了顶部栏的撤销/重做按钮，引入独立的悬浮组件 `FloatingUndoRedo`，操作更加便捷。

## 3. 技术实现细节

### 3.1 自动保存机制
在 `InteractivePost.tsx` 中引入了防抖逻辑：
```typescript
useEffect(() => {
    if (!isEditing || !content) return;
    const timer = setTimeout(() => {
        saveFile(true); // Silent save
    }, 5000);
    return () => clearTimeout(timer);
}, [content, isEditing]);
```

### 3.2 属性解析优化
在 `attributeParser.ts` 中更新了正则，支持行尾未闭合的大括号：
```typescript
// Support both closed {} and unclosed { at the end of line
const regex = /\{([^}]*)\}?$/;
```

### 3.3 状态同步
利用 `useHistory` 和 `useMarkdownInteraction` 钩子，确保了底部工具栏状态与文档内容的实时双向同步。

## 4. 验证结果
*   **样式切换**: 卡片样式切换流畅，无样式残留。
*   **布局微调**: 标题间距和分割线控制即时生效。
*   **数据安全**: 自动保存功能正常工作，刷新页面后数据未丢失。
*   **UI 体验**: 底部栏文字大小适中，操作区域清晰。
