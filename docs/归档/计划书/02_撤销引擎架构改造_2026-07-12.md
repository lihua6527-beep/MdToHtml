## 一、现状分析

### 1.1 当前 useHistory 接口

```
当前：
  past: string[]      ← 纯文本快照
  future: string[]    ← 纯文本快照
  pushState(content)  ← 压入快照
  undo() → string     ← 返回完整文档
  redo() → string     ← 返回完整文档
  
改造后：
  undoStack: Operation[]      ← 操作序列
  redoStack: Operation[]      ← 操作序列
  pushOperation(op)           ← 压入操作
  undo() → string | null      ← 执行逆操作 → 返回最新内容
  redo() → string | null      ← 重做 → 返回最新内容
```

### 1.2 改造前后对比

| 维度 | 当前设计 | 改造后 |
|------|---------|--------|
| 数据结构 | `past: string[]`、`future: string[]` | `undoStack: Operation[]`、`redoStack: Operation[]` |
| 压入方式 | `pushState(newContent)` → 快照方式 | `pushOperation(op)` → 操作方式 |
| 撤销逻辑 | 返回 `past.pop()` 即上一个快照 | 从 `undoStack.pop()` 取出 `op`，执行 `op.invert()` |
| 重做逻辑 | 返回 `future.pop()` 即未来快照 | 从 `redoStack.pop()` 取出 `op`，重新执行 |
| 颗粒度 | 整篇文档快照 | 单次操作级 |
| 操作元信息 | 无 | 每个 Operation 携带 type / display / payload |
| Token 记录 | 无 | AI 操作携带 `aiContext.tokensConsumed` |

## 二、核心改造设计

### 2.1 新的数据流

```
用户编辑 / AI 操作确认
        ↓
   pushOperation(op)
        ↓
  ┌─────────────────┐
  │  undoStack.push(op) │
  │  redoStack = []    │  ← 新操作清空重做栈
  └────────┬────────┘
           ↓
     🔄 执行操作（应用变更到编辑器）
           ↓
     🔄 触发持久化
```

### 2.2 UndoRedoEngine 核心算法

```typescript
// src/hooks/useHistory.ts 内部实现

class UndoRedoEngine {
  private undoStack: Operation[] = [];
  private redoStack: Operation[] = [];

  // 执行操作并记录到撤销栈
  execute(op: Operation): void {
    // ① 应用操作到编辑器
    this.applyOperation(op);
    // ② 推入撤销栈
    this.undoStack.push(op);
    // ③ 新操作清空重做栈
    this.redoStack = [];
    // ④ 触发持久化（若开启）
    this.persist();
  }

  // 撤销：弹出最后一个操作 → 生成逆操作 → 执行
  undo(): Operation | null {
    const op = this.undoStack.pop();
    if (!op) return null;

    const inverseOp = op.invert();  // 使用计划01的 invert()
    this.applyOperation(inverseOp);
    this.redoStack.push(op);       // 原操作推入重做栈
    this.persist();
    return op;                     // 返回被撤销的操作（用于 UI 展示）
  }

  // 重做：弹出最后一个撤销的操作 → 重新执行
  redo(): Operation | null {
    const op = this.redoStack.pop();
    if (!op) return null;

    this.applyOperation(op);
    this.undoStack.push(op);
    this.persist();
    return op;                     // 返回被重做的操作
  }

  // 应用操作到编辑器（内部适配器）
  private applyOperation(op: Operation): void {
    // 由具体实现决定如何将 Operation 映射为编辑器变更
    // 对于 CodeMirror 场景，需要将 Operation 转化为 editor.dispatch(...)
    // 详见后面的 CodeMirror 适配层
  }
}
```

```typescript
// 使旧的 pushState(content) 仍可使用：

function pushStateAdapter(oldContent: string, newContent: string): Operation {
  // 简易 diff 算法（仅处理纯文本替换场景）
  // 更精确的 diff 可引入 diff-match-patch 库
  if (newContent.startsWith(oldContent)) {

    return OperationBuilder.textInsert(
      oldContent.length,
      newContent.slice(oldContent.length)
    );
  } else if (oldContent.startsWith(newContent)) {
    // 尾部删除
    return {
      ...OperationBuilder.textInsert(0, ''),
      type: OperationType.DELETE_TEXT,
      position: { start: newContent.length, end: oldContent.length },
      payload: { before: oldContent.slice(newContent.length), after: '' },
    };
  } else {
    // 复杂变更 → 标记为全篇替换
    return OperationBuilder.textInsert(0, newContent);
  }
}
```

## 三、CodeMirror 适配层

### 3.1 Operation → CodeMirror 变更

需要将 Operation 翻译为 CodeMirror 的 `TransactionSpec`：

```typescript
// 将 Operation 转化为 CodeMirror 可执行的变更
function opToCodeMirrorChanges(
  op: Operation,
  state: EditorState
): { changes: ChangeSpec[]; annotation?: Annotation } {
  const changes: ChangeSpec[] = [];

  switch (op.type) {
    case OperationType.INSERT_TEXT:
      changes.push({
        from: op.position.start,
        to: op.position.start,
        insert: op.payload.after,
      });
      break;

    case OperationType.DELETE_TEXT:
      changes.push({
        from: op.position.start,
        to: op.position.end,
        insert: '',
      });
      break;

    case OperationType.REPLACE_TEXT:
    case OperationType.AI_POLISH:
    case OperationType.AI_EXPAND:
    case OperationType.AI_TO_CARD:
    case OperationType.AI_SUMMARIZE:
      changes.push({
        from: op.position.start,
        to: op.position.end,
        insert: op.payload.after,
      });
      break;

    // 卡片操作等需通过编辑器 API 另行处理
    case OperationType.CARD_ADD:
    case OperationType.CARD_DELETE:
    case OperationType.CARD_MOVE:
    case OperationType.CARD_STYLE_CHANGE:
      // 暂不在此层处理，通过编辑器高阶方法处理
      break;
  }

  return { changes };
}
```

### 3.2 编辑器变更 → Operation（反向适配）

监听 CodeMirror 的 `update` 事件，将文本变更转换为 Operation：

```typescript
// 在 CodeMirrorEditor 中监听
function onEditorUpdate(update: ViewUpdate): Operation | null {
  if (!update.docChanged) return null;

  // 只处理最后一次变更（防抖合并由 useHistory 处理）
  const tr = update.transactions[update.transactions.length - 1];
  const changes = tr.changes;

  if (changes.length === 0) return null;

  // 提取变更描述
  const changeDesc = changes.iterDesc();

  // 简化为一个 REPLACE 操作
  const oldContent = changeDesc.removed?.join('') || '';
  const newContent = changeDesc.inserted?.join('') || '';

  if (oldContent.length === 0 && newContent.length > 0) {
    return OperationBuilder.textInsert(changeDesc.fromA, newContent);
  } else if (oldContent.length > 0 && newContent.length === 0) {
    return {
      ...OperationBuilder.textInsert(0, ''),
      type: OperationType.DELETE_TEXT,
      position: { start: changeDesc.fromA, end: changeDesc.toA },
      payload: { before: oldContent, after: '' },
    };
  } else {
    return {
      ...OperationBuilder.textInsert(0, newContent),
      type: OperationType.REPLACE_TEXT,
      position: { start: changeDesc.fromA, end: changeDesc.toA },
      payload: { before: oldContent, after: newContent },
    };
  }
}
```

## 四、防抖合并与 BATCH 操作

### 4.1 防抖合并策略（复用计划03的 300ms 防抖）

当用户在 300ms 内连续编辑时，将多个小型 Operation 合并为一个 `BATCH` 操作：

```typescript
// 防抖合并器
class DebounceMerger {
  private batch: Operation[] = [];
  private lastTime = 0;
  private timer: NodeJS.Timeout | null = null;
  private readonly DEBOUNCE_MS = 300;

  // 推送操作到合并器
  push(op: Operation, onFlush: (batchOp: Operation) => void): void {
    const now = Date.now();

    if (now - this.lastTime < this.DEBOUNCE_MS) {
      // 仍在防抖窗口内 → 临时收集
      this.batch.push(op);
      this.resetTimer(onFlush);
    } else {
      // 超出防抖窗口 → 立即刷新
      this.flush(onFlush);
      this.batch = [op];
      this.lastTime = now;
      this.resetTimer(onFlush);
    }
  }

  private resetTimer(onFlush: (batchOp: Operation) => void): void {
    if (this.timer) clearTimeout(this.timer);
    this.timer = setTimeout(() => this.flush(onFlush), this.DEBOUNCE_MS);
  }

  private flush(onFlush: (batchOp: Operation) => void): void {
    if (this.batch.length === 0) return;

    if (this.batch.length === 1) {
      // 只有一个操作，不需要 BATCH 包装
      onFlush(this.batch[0]);
    } else {
      // 多个操作 → 包装为 BATCH
      const batchOp: Operation = {
        id: OperationBuilder.nextId(),
        type: OperationType.BATCH,
        timestamp: this.batch[0].timestamp,
        position: {
          start: Math.min(...this.batch.map(o => o.position.start)),
          end: Math.max(...this.batch.map(o => o.position.end)),
        },
        payload: {
          before: this.batch[0].payload.before,
          after: this.batch[this.batch.length - 1].payload.after,
        },
        display: {
          icon: '📦',
          label: `合并操作 (${this.batch.length} 步)`,
        },
      };
      onFlush(batchOp);
    }

    this.batch = [];
  }
}
```

### 4.2 BATCH 逆操作策略

`BATCH` 的逆操作由撤销引擎递归处理：

```typescript
// 在 UndoRedoEngine 中
function batchInvert(batchOp: Operation): Operation {
  // BATCH 的逆操作也是 BATCH，但子操作顺序反转且各自 invert
  // 由于 BATCH 的 payload 不直接存储子操作列表，
  // 撤销时模拟一次完整的内容替换
  return {
    ...batchOp,
    payload: {
      before: batchOp.payload.after,
      after: batchOp.payload.before,
    },
    display: { icon: '↩️', label: `撤销: ${batchOp.display.label}` },
  };
}
```

> **设计决策**：BATCH 的逆操作不拆分为子逆操作，而是作为一次整体内容替换。这是为了简化实现，同时保持防抖合并的意义（合并后的一次撤销 = 回到合并前的初始状态）。

### 5.1 旧数据迁移

```typescript
// 从 localStorage 读取旧格式时自动迁移
function migrateHistoryData(raw: string): Operation[] {
  const data = JSON.parse(raw);

  // 旧格式：string[]（如 "chd_editor_history" 存储的是纯文本数组）
  if (Array.isArray(data) && data.every(item => typeof item === 'string')) {
    console.log('[useHistory] 检测到旧版 string[] 格式，正在迁移...');
    return data.map((content, index) => ({
      id: `migrated-${index}`,
      type: OperationType.REPLACE_TEXT,
      timestamp: Date.now() - (data.length - index) * 1000,
      position: { start: 0, end: content.length },
      payload: { before: '', after: content },
      display: { icon: '📋', label: '历史记录（已迁移）' },
    }));
  }

  // 新格式：Operation[]（或者 PersistedOperationLog）
  if (data.version !== undefined && Array.isArray(data.ops)) {
    return data.ops;
  }

  if (Array.isArray(data)) {
    return data as Operation[];
  }

  return [];
}
```
