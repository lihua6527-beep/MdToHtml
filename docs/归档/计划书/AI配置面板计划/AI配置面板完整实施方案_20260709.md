## 一、设计原则

### 1.1 功能分离原则

```
❌ 当前：AI 配置是 SettingsPanel 的一个 Tab（settingsType='ai'），与其他配置混在一起
✅ 改造后：AI 配置拥有独立的面板，作为 SettingsPanel 的一个独立子面板
    ├── 左侧边栏「设置」→ 选择「AI 服务配置」
    └── 进入独立的全功能 AI 配置面板
```

### 1.2 全链路透明原则

用户在配置 AI 服务时，需要清楚知道每一步的**代价、风险、结果**：

```
配置链路透明化：
  ① 输入 Key → ② 知晓验证会消耗少量 token → ③ 确认验证 → ④ 验证结果展示 → ⑤ 保存生效
                    ↓                       ↓               ↓
              弹窗说明（1次）         用户主动确认      成功/失败明确提示
```

### 1.3 安全可见原则

用户不需要信任我们的代码——我们把安全措施**摆在明面上**：

```
🔒 安全可见性：
  ✅ 明确告知：Key 不会上传到任何第三方服务器（除了 DeepSeek 官方 API）
  ✅ 明确告知：Key 仅本地存储，不会发送到我们的任何后端
  ✅ 明确告知：每次验证会消耗约 0.001 元（极小 token 量）
  ✅ 明确告知：Key 不会出现在浏览器存储中
```

### 3.3 错误处理全链路

#### 错误类型与展示

| 错误场景 | 检测时机 | 用户看到的提示 | 建议操作 |
|:---------|:--------|:-------------|:--------|
| Key 格式错误（非 sk- 开头） | 输入时实时检测 | `⚠️ DeepSeek API Key 通常以 sk- 开头` | 检查复制内容 |
| Key 为空点击保存 | 点击保存时 | `❌ 请输入 API Key` | 输入 Key |
| 网络不可达 | 测试连接时 | `❌ 无法连接到 DeepSeek API，请检查网络` | 检查网络/代理 |
| 401 Unauthorized | 测试连接时 | `❌ 认证失败：API Key 无效或已吊销` | 检查 Key 是否正确/是否过期 |
| 403 Forbidden | 测试连接时 | `❌ 权限不足：该 Key 无调用权限` | 在 DeepSeek 平台检查权限 |
| 429 Rate Limit | 测试连接时 | `❌ 请求过于频繁，请稍后重试` | 等待 1 分钟后重试 |
| 500 Server Error | 测试连接时 | `❌ DeepSeek 服务暂时不可用，请稍后重试` | 检查 DeepSeek 状态页 |
| 文件写入失败 | 保存配置时 | `⚠️ 密钥已保存到内存，但文件写入失败` | 检查 .env.local 文件权限 |
| 余额不足 | 测试连接时（可选） | `⚠️ 账户余额可能不足，请在 DeepSeek 平台充值` | 检查账户余额 |

### 4.1 验证 API 设计

```typescript
// POST /api/ai/config/test-connection
// 请求体: { apiKey: string }
// 响应: 
//   { success: true, latency: 320, message: '连接成功' }
//   { success: false, code: '401', message: '认证失败：API Key 无效' }

export async function POST(req: Request) {
  const { apiKey } = await req.json();
  
  if (!apiKey || !apiKey.startsWith('sk-')) {
    return Response.json({
      success: false,
      code: 'FORMAT_ERROR',
      message: 'API Key 格式不正确，应以 sk- 开头'
    }, { status: 400 });
  }

  const start = Date.now();
  try {
    const res = await fetch('https://api.deepseek.com/v1/chat/completions', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${apiKey}`,
      },
      // 最小请求：仅消耗 10-50 tokens
      body: JSON.stringify({
        model: 'deepseek-chat',
        messages: [{ role: 'user', content: 'Hi' }],
        max_tokens: 1,
      }),
    });

    const latency = Date.now() - start;

    if (res.ok) {
      return Response.json({
        success: true,
        latency,
        message: `连接成功 (${latency}ms)`,
      });
    }

    const errorMap: Record<number, string> = {
      401: 'API Key 无效或已吊销，请在 DeepSeek 平台检查',
      403: '该 Key 无调用权限，请在 DeepSeek 平台检查',
      429: '请求过于频繁，请稍后重试',
    };

    return Response.json({
      success: false,
      code: String(res.status),
      message: errorMap[res.status] || `服务端错误 (${res.status})`,
    });

  } catch (err: any) {
    return Response.json({
      success: false,
      code: 'NETWORK_ERROR',
      message: `无法连接到 DeepSeek API: ${err.message || '网络不可达'}`,
    });
  }
}
```

### 4.5 余额自动监控 API

```typescript
// GET /api/ai/config/balance
// 请求头: Authorization: Bearer ${apiKey}
// 响应: 
//   { success: true, balance: 25.32, currency: 'CNY', message: '查询成功' }
//   { success: false, code: '401', message: 'API Key 无效' }

export async function GET(req: Request) {
  // 从请求头或服务端配置获取 API Key
  const apiKey = req.headers.get('Authorization')?.replace('Bearer ', '') 
                 || ApiKeyManager.get();

  if (!apiKey) {
    return Response.json({
      success: false,
      code: 'NO_KEY',
      message: '未配置 API Key'
    }, { status: 400 });
  }

  try {
    // DeepSeek 余额查询端点
    const res = await fetch('https://api.deepseek.com/v1/dashboard/billing/credit_grants', {
      headers: {
        'Authorization': `Bearer ${apiKey}`,
        'Accept': 'application/json',
      },
    });

    if (res.ok) {
      const data = await res.json();
      // { total_remaining: 25.32, total_granted: 100, ... }
      return Response.json({
        success: true,
        balance: data.total_remaining,
        currency: 'CNY',
        total_granted: data.total_granted,
        message: `余额 ¥${data.total_remaining}`,
      });
    }

    return Response.json({
      success: false,
      code: String(res.status),
      message: `余额查询失败 (${res.status})`,
    });

  } catch (err: any) {
    return Response.json({
      success: false,
      code: 'NETWORK_ERROR',
      message: `无法查询余额: ${err.message || '网络不可达'}`,
    });
  }
}
```

### 4.6 前端计数器与自动触发

```typescript
// 计数器实现（挂载在 AIService 或全局状态中）
// 使用 localStorage 持久化计数，避免刷新丢失

const BALANCE_CHECK_INTERVAL_KEY = 'ai_balance_check_interval'; // 每 N 次
const BALANCE_REQUEST_COUNT_KEY = 'ai_balance_request_count';   // 当前计数
const BALANCE_THRESHOLD_KEY = 'ai_balance_low_threshold';       // 余额阈值

interface BalanceMonitorConfig {
  enabled: boolean;
  interval: number;        // 每 N 次查询一次，默认 5
  lowBalanceThreshold: number;  // 低于此值弹窗提醒，默认 10
  lastBalance: number | null;
  lastCheckTime: number | null;
}

// 每次 AI 请求完成后调用
export async function onAIRequestComplete() {
  const config = getBalanceMonitorConfig();
  if (!config.enabled) return;

  // 读取并递增计数器
  let count = parseInt(localStorage.getItem(BALANCE_REQUEST_COUNT_KEY) || '0', 10);
  count++;
  localStorage.setItem(BALANCE_REQUEST_COUNT_KEY, String(count));

  // 达到间隔阈值，触发余额查询
  if (count >= config.interval) {
    // 重置计数器
    localStorage.setItem(BALANCE_REQUEST_COUNT_KEY, '0');
    await checkBalanceAndNotify(config);
  }
}

async function checkBalanceAndNotify(config: BalanceMonitorConfig) {
  try {
    const res = await fetch('/api/ai/config/balance');
    const data = await res.json();

    if (data.success) {
      // 缓存余额信息
      config.lastBalance = data.balance;
      config.lastCheckTime = Date.now();
      saveBalanceMonitorConfig(config);

      // 余额低于阈值 → 弹窗提醒
      if (data.balance < config.lowBalanceThreshold) {
        showBalanceWarning(data.balance, config.lowBalanceThreshold);
      }
    }
  } catch (e) {
    console.warn('余额查询失败（静默失败，不影响用户操作）', e);
  }
}

// 余额不足警告弹窗
function showBalanceWarning(currentBalance: number, threshold: number) {
  // 使用现有的 ConfirmDialog 组件
  showDialog({
    type: 'warning',
    title: '💰 账户余额不足',
    content: `
      当前余额: ¥${currentBalance.toFixed(2)}
      已低于提醒阈值: ¥${threshold}

      建议及时充值，以免影响 AI 功能使用。

      📌 提示：您可以在 AI 配置面板中关闭此提醒或调整阈值。
    `,
    confirmText: '前往充值',
    cancelText: '知道了',
    onConfirm: () => {
      window.open('https://platform.deepseek.com/topup', '_blank');
    },
  });
}

// 在 AIConfigPanel 中的配置 UI
const BalanceMonitorSection = () => {
```

```typescript
const handleSaveConfig = async () => {
  // 1. 前置校验
  if (!aiApiKey.trim()) {
    setValidationMessage('请输入 API Key');

  }

  const result = await ApiKeyManager.set(aiApiKey.trim());

    setAiConnected(null);
  } else {

    setValidationType('error');
  }
};
```
