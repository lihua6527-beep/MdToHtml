## 二、子任务 0.1：E2E 选择器修复

### 2.1 问题现状

E2E 测试文件位于 `MdToHtml/e2e/`，共 6 个测试，全部因选择器不匹配失败。

### 2.2 根因分析

根据集成测试文档 Plan 02 的分析：
- 在重构过程中，部分组件的 DOM 属性（`data-testid`、`aria-label`、class name）发生了变化
- Playwright 测试中使用的选择器与当前 DOM 不一致
- 估计只需修正 3 个位置的选择器即可全部通过

### 2.3 修复策略

| 问题类型 | 修复方式 | 预期工作量 |
|----------|----------|------------|
| CSS 选择器与更新后的 class 不匹配 | 更新 Playwright 选择器 | ~5 分钟/处 |
| data-testid 缺失 | 在组件中添加 data-testid | ~5 分钟/处 |
| 等待条件与异步加载时机不一致 | 增加 waitFor 策略 | ~5 分钟/处 |

### 2.4 验收标准

```bash

缓存管理器是项目的**P0 级缺陷**：

#### 4.2.1 OperationType 枚举

// src/types/operation.ts

/** 操作类型枚举 */
export enum OperationType {
  // ── 文本编辑操作 ──
  TEXT_INSERT = 'TEXT_INSERT',
  TEXT_DELETE = 'TEXT_DELETE',
  TEXT_REPLACE = 'TEXT_REPLACE',

  // ── 卡片操作 ──
  CARD_CREATE = 'CARD_CREATE',
  CARD_DELETE = 'CARD_DELETE',
  CARD_MOVE = 'CARD_MOVE',
  CARD_UPDATE = 'CARD_UPDATE',        // 属性变更（样式/配色/形状）

  // ── AI 辅助操作 ──
  AI_GENERATE = 'AI_GENERATE',
  AI_REPLACE = 'AI_REPLACE',          // AI 建议替换
  AI_REWRITE = 'AI_REWRITE',

  // ── 元操作 ──
  BATCH = 'BATCH',                    // 批量操作（防抖合并结果）
  CHECKPOINT = 'CHECKPOINT',          // 手动暂存点
  MARKER = 'MARKER',                  // 语义标记（用于 AI 上下文）
}
```

#### 4.2.2 Operation 接口

```typescript
/** 操作基接口 */
export interface Operation {
  /** 唯一标识（UUID v4） */
  id: string;
  
  /** 操作类型 */
  type: OperationType;
  
  /** 时间戳（毫秒） */
  timestamp: number;
  
  /** 操作生产者标识（'codemirror' | 'card' | 'ai' | 'drag' | 'checkpoint'） */
  producer: string;

  /** 操作描述（用于 UI 显示 "撤销：xxx"） */
  description: string;
}

/** 文本编辑操作 */
export interface TextOperation extends Operation {
  type:
    | OperationType.TEXT_INSERT
    | OperationType.TEXT_DELETE
    | OperationType.TEXT_REPLACE;
  
  /** 操作位置（CodeMirror position/ch） */
  position: number;
  
  /** 插入/删除/替换的文本内容 */
  text: string;
  
  /** 逆操作数据（用于撤销时反转） */
  inverse: {
    position: number;
    text: string;
    type: OperationType;
  };
}

/** 卡片操作 */
export interface CardOperation extends Operation {
  type:
    | OperationType.CARD_CREATE
    | OperationType.CARD_DELETE
    | OperationType.CARD_MOVE
    | OperationType.CARD_UPDATE;
  
  /** 卡片 ID */
  cardId: string;
  
  /** 变更前的状态（用于撤销恢复） */
  before: Record<string, unknown>;
  
  /** 变更后的状态（用于重做恢复） */
  after: Record<string, unknown>;
  
  /** 相关 Section ID（可选） */
  sectionId?: string;
}

/** AI 辅助操作 */
export interface AiOperation extends Operation {
  type:
    | OperationType.AI_GENERATE
    | OperationType.AI_REPLACE
    | OperationType.AI_REWRITE;
  
  /** AI 指令 */
  prompt: string;
  
  /** 消耗 tokens 数 */
  tokensUsed: number;

  /** 操作前后的文本对比 */
  diff: {
    before: string;
    after: string;
    /** 变更位置 */
    position: number;
  };
}

/** 元操作（批量/标记/暂存点） */
export interface MetaOperation extends Operation {
  type:
    | OperationType.BATCH
    | OperationType.CHECKPOINT
    | OperationType.MARKER;
  
  /** 子操作列表（BATCH 类型时） */
  children?: Operation[];
  
  /** 暂存点名称（CHECKPOINT 类型时） */
  label?: string;
  
  /** 标记用途（MARKER 类型时） */
  markerPurpose?: 'context_boundary' | 'validation_point';
}
```

| 决策 ID | 决策内容 | 理由 |
|---------|----------|------|
| ADR-001 | 不引入第三方依赖库生成 UUID | 使用 `crypto.randomUUID()` 减少依赖 |
| ADR-002 | Operation 接口使用联合类型而非继承 | 更利于 TypeScript 类型守卫与模式匹配 |
| ADR-003 | OperationBuilder 使用静态工厂而非类实例 | 减少对象创建开销，更接近函数式编程风格 |
| ADR-004 | 逆操作为独立计算函数而非 Operation 的方法 | 保持接口纯净，序列化时无函数丢失 |
