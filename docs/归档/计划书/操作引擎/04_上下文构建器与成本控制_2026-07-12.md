# Plan 04: 上下文构建器与成本控制

> **计划日期**：2026-07-12
> **计划目标**：设计分层上下文裁剪策略（ContextBuilder），在保证 AI 操作质量的前提下最小化 Token 消耗。实现缓存优化和渐进式加载策略，控制 AI 辅助编辑的运营成本。
> **前置依赖**：计划01（操作类型系统），使用 `OperationType.AI_*` 类型定义
> **对应总体计划**：Phase 3（叠加 AI 操作支持）

## 一、问题重述

### 1.1 核心矛盾

```
修改卡片文本 → 需要上下文理解
    ↓
如果只传卡片内容 → AI 缺乏上下文，容易"胡编"
如果传整篇文章 → Token 消耗大，缓存命中率低
    ↓
成本与质量的平衡
```

### 1.2 当前 AI 调用现状

| 维度 | 当前行为 | 问题 |
|------|---------|------|
| 上下文 | 无裁剪（全篇传入） | Token 浪费，成本高 |
| 缓存 | 无缓存策略 | 重复请求，成本翻倍 |
| 模型选择 | 实时模型"flash" | 无降级策略 |
| 成本追踪 | 无记录 | 无法审计 |

## 二、分层上下文策略

### 2.1 三层上下文设计

```
层级 1：最小上下文（~200-400 tokens）
       适用：润色、总结
       内容：选中文本 + 前后2句 + 当前Section标题

层级 2：中等上下文（~800-1500 tokens）
       适用：扩充、转卡片
       内容：层级1 + 当前Section全部 + 相邻Section标题+首句

层级 3：完整上下文（~2000-5000 tokens）
       适用：全篇重写、风格统一转换
       内容：整篇文章 + 元信息
```

### 2.2 ContextBuilder 核心实现

```typescript
// services/ai/ContextBuilder.ts

interface ContextLevel {
  type: 'minimal' | 'medium' | 'full';
  maxTokens: number;
  description: string;
}

const CONTEXT_LEVELS: Record<string, ContextLevel> = {
  minimal: { type: 'minimal', maxTokens: 400, description: '最小上下文' },
  medium: { type: 'medium', maxTokens: 1500, description: '中等上下文' },
  full: { type: 'full', maxTokens: 5000, description: '完整上下文' },
};

// 操作类型 → 推荐的上下文层级映射
const OPERATION_TO_CONTEXT_LEVEL: Record<string, string> = {
  AI_POLISH: 'minimal',
  AI_SUMMARIZE: 'minimal',
  AI_EXPAND: 'medium',
  AI_TO_CARD: 'medium',
  // 未来可扩展
};

class ContextBuilder {
  constructor(private document: string) {}

  /**
   * 根据操作类型和选中文本构建最佳上下文
   */
  build(
    operationType: string,
    selectedText: string,
    selectionRange: { start: number; end: number }
  ): { context: string; level: string; tokensEstimated: number } {
    // 确定上下文层级
    const level = OPERATION_TO_CONTEXT_LEVEL[operationType] || 'medium';

    // 构建对应层级的上下文
    let context: string;
    let tokensEstimated: number;

    switch (level) {
      case 'minimal':
        ({ context, tokensEstimated } = this.buildMinimal(selectedText, selectionRange));
        break;
      case 'medium':
        ({ context, tokensEstimated } = this.buildMedium(selectedText, selectionRange));
        break;
      case 'full':
      default:
        ({ context, tokensEstimated } = this.buildFull(selectedText, selectionRange));
        break;
    }

    return { context, level, tokensEstimated };
  }

  /**
   * 层级1：最小上下文
   * 选取选中文本所在段落及前后2句 + 当前Section标题
   */
  private buildMinimal(
    selectedText: string,
    range: { start: number; end: number }
  ): { context: string; tokensEstimated: number } {
    // 1. 解析文档结构，找到选中文本所在 Section
    const section = this.findSectionAt(range.start);

    // 2. 提取段落上下文（前后各2句）
    const paragraphContext = this.extractParagraphContext(range, 2);

    // 3. 获取当前 Section 标题
    const sectionTitle = section?.title || '';

    // 4. 组装上下文
    const context = [
      `[文档上下文 - 最小模式]`,
      sectionTitle ? `当前章节：${sectionTitle}` : '',
      ``,
      `选中文本周围内容：`,
      paragraphContext,
      ``,
      `========== 操作焦点 ==========`,
      `请对以下选中文本执行操作：`,
      selectedText,
      `============================`,
    ]
      .filter(Boolean)
      .join('\n');

    return {
      context,
      tokensEstimated: this.estimateTokens(context),
    };
  }

  /**
   * 层级2：中等上下文
   * 包含当前Section全部内容 + 相邻Section标题
   */
  private buildMedium(
    selectedText: string,
    range: { start: number; end: number }
  ): { context: string; tokensEstimated: number } {
    // 1. 获取最小上下文
    const minimal = this.buildMinimal(selectedText, range);

    // 2. 获取当前 Section 全部内容
    const section = this.findSectionAt(range.start);
    const sectionContent = section?.content || '';

    // 3. 获取相邻 Section 信息
    const adjacentSections = this.getAdjacentSections(range.start);
    const adjacentInfo = adjacentSections
      .map(s => `- ${s.title}：${s.firstSentence}`)
      .join('\n');

    // 4. 组装
    const context = [
      `[文档上下文 - 中等模式]`,
      ``,
      `当前章节完整内容：`,
      sectionContent,
      ``,
      `相邻章节：`,
      adjacentInfo || '（无相邻章节）',
      ``,
      minimal.context,
    ].join('\n');

    return {
      context,
      tokensEstimated: this.estimateTokens(context),
    };
  }

  /**
   * 层级3：完整上下文
   * 整篇文章全部内容
   */
  private buildFull(
    selectedText: string,
    range: { start: number; end: number }
  ): { context: string; tokensEstimated: number } {
    const context = [
      `[文档上下文 - 完整模式]`,
      ``,
      `完整文档内容：`,
      this.document,
      ``,
      `========== 操作焦点 ==========`,
      `请对以下选中文本执行操作：`,
      selectedText,
      `============================`,
    ].join('\n');

    return {
      context,
      tokensEstimated: this.estimateTokens(context),
    };
  }

  // ── 辅助方法 ──

  private findSectionAt(offset: number): { title: string; content: string } | null {
    // 解析 Markdown 标题（## 或 ###）
    // 实现：遍历文档，找到 offset 所在 Section
    const lines = this.document.split('\n');
    let currentSection: { title: string; content: string[] } | null = null;

    for (let i = 0; i < lines.length; i++) {
      const line = lines[i];

      // 检测标题行（## 或 ###）
      if (/^#{2,3}\s/.test(line)) {
        // 如果之前有正在收集的 Section，检查是否包含 offset
        if (currentSection) {
          const sectionEnd = lines.slice(0, i).join('\n').length;
          if (offset <= sectionEnd) {
            return {
              title: currentSection.title.replace(/^#{2,3}\s+/, ''),
              content: currentSection.content.join('\n'),
            };
          }
        }
        currentSection = { title: line, content: [] };
      } else if (currentSection) {
        currentSection.content.push(line);
      }
    }

    // 如果 offset 在最后一个 Section 中
    if (currentSection) {
      return {
        title: currentSection.title.replace(/^#{2,3}\s+/, ''),
        content: currentSection.content.join('\n'),
      };
    }

    return null;
  }

  private extractParagraphContext(
    range: { start: number; end: number },
    surroundingSentences: number
  ): string {
    // 提取选中文本前后的句子级上下文
    const before = this.document.slice(Math.max(0, range.start - 200), range.start);
    const after = this.document.slice(range.end, range.end + 200);

    // 简单地取前后各 200 字符作为"周围内容"
    return `...${before}|选中区域|${after}...`;
  }

  private getAdjacentSections(offset: number): Array<{ title: string; firstSentence: string }> {
    // 获取相邻 Section 的标题和首句
    const sections = this.parseSections();
    const currentIndex = sections.findIndex(
      s => offset >= s.start && offset <= s.end
    );

    const result: Array<{ title: string; firstSentence: string }> = [];

    if (currentIndex > 0) {
      const prev = sections[currentIndex - 1];
      result.push({
        title: prev.title,
        firstSentence: prev.firstSentence,
      });
    }

    if (currentIndex >= 0 && currentIndex < sections.length - 1) {
      const next = sections[currentIndex + 1];
      result.push({
        title: next.title,
        firstSentence: next.firstSentence,
      });
    }

    return result;
  }

  private parseSections(): Array<{
    title: string;
    start: number;
    end: number;
    firstSentence: string;
  }> {
    // 解析文档的所有 Section
    const lines = this.document.split('\n');
    const sections: Array<{
      title: string;
      start: number;
      end: number;
      firstSentence: string;
    }> = [];
    let currentStart = 0;
    let currentTitle = '';
    let contentStarted = false;
    let firstSentence = '';

    for (let i = 0; i < lines.length; i++) {
      const line = lines[i];
      if (/^#{2,3}\s/.test(line)) {
        if (currentTitle) {
          sections.push({
            title: currentTitle,
            start: currentStart,
            end: currentStart + lines.slice(0, i).join('\n').length - currentStart,
            firstSentence,
          });
        }
        currentTitle = line.replace(/^#{2,3}\s+/, '');
        currentStart = lines.slice(0, i).join('\n').length + line.length + 1;
        contentStarted = false;
        firstSentence = '';
      } else if (currentTitle && !contentStarted && line.trim()) {
        firstSentence = line.trim().slice(0, 80);
        contentStarted = true;
      }
    }

    // 最后一个 Section
    if (currentTitle) {
      sections.push({
        title: currentTitle,
        start: currentStart,
        end: this.document.length,
        firstSentence,
      });
    }

    return sections;
  }

  /**
   * 估计 Token 数量（粗略估算：~1 token ≈ 2 中文字符）
   */
  private estimateTokens(text: string): number {
    // 中文字符 ≈ 1.5 tokens/字
    const chineseChars = (text.match(/[\u4e00-\u9fff]/g) || []).length;
    const otherChars = text.length - chineseChars;
    return Math.ceil(chineseChars * 1.5 + otherChars * 0.25);
  }
}

export { ContextBuilder, CONTEXT_LEVELS, OPERATION_TO_CONTEXT_LEVEL };
```

## 三、缓存策略

### 3.1 三级缓存

```typescript
// 缓存管理器
class AICacheManager {
  // 缓存存储
  private exactCache = new Map<string, { result: string; timestamp: number }>();
  private fuzzyCache = new Map<string, { result: string; timestamp: number }>();
  private sessionCache: Array<{ prompt: string; result: string; timestamp: number }> = [];

  private readonly EXACT_TTL = 3600 * 1000;  // 1 小时
  private readonly FUZZY_TTL = 600 * 1000;    // 10 分钟
  private readonly MAX_SESSION_ENTRIES = 50;

  /**
   * 精确匹配缓存
   * Key: md5(完整 prompt)
   * 命中场景：用户对同一文本重复执行同一操作
   */
  getExact(prompt: string): string | null {
    const key = this.md5(prompt);
    const cached = this.exactCache.get(key);
    if (cached && Date.now() - cached.timestamp < this.EXACT_TTL) {
      return cached.result;
    }
    return null;
  }

  setExact(prompt: string, result: string): void {
    const key = this.md5(prompt);
    this.exactCache.set(key, { result, timestamp: Date.now() });
    // 限制缓存大小
    if (this.exactCache.size > 100) {
      const firstKey = this.exactCache.keys().next().value;
      if (firstKey) this.exactCache.delete(firstKey);
    }
  }

  /**
   * 模糊匹配缓存
   * Key: md5(操作类型 + 文本前100字)
   * 命中场景：类似内容的不同操作（如同一段落的不同润色请求）
   */
  getFuzzy(opType: string, textPreview: string): string | null {
    const key = this.md5(`${opType}:${textPreview.slice(0, 100)}`);
    const cached = this.fuzzyCache.get(key);
    if (cached && Date.now() - cached.timestamp < this.FUZZY_TTL) {
      return cached.result;
    }
    return null;
  }

  setFuzzy(opType: string, textPreview: string, result: string): void {
    const key = this.md5(`${opType}:${textPreview.slice(0, 100)}`);
    this.fuzzyCache.set(key, { result, timestamp: Date.now() });
  }

  /**
   * 会话内缓存
   * 用户在当前编辑会话内的所有 AI 请求
   */
  getSession(prompt: string): string | null {
    const entry = this.sessionCache.find(e => e.prompt === prompt);
    return entry?.result || null;
  }

  addSession(prompt: string, result: string): void {
    this.sessionCache.push({ prompt, result, timestamp: Date.now() });
    if (this.sessionCache.length > this.MAX_SESSION_ENTRIES) {
      this.sessionCache.shift();
    }
  }

  /**
   * 清空所有缓存（用户手动刷新或切换文档时调用）
   */
  clearAll(): void {
    this.exactCache.clear();
    this.fuzzyCache.clear();
    this.sessionCache = [];
  }

  private md5(input: string): string {
    // 简单哈希（生产环境建议使用真正的 MD5 或 crypto API）
    let hash = 0;
    for (let i = 0; i < input.length; i++) {
      const char = input.charCodeAt(i);
      hash = ((hash << 5) - hash) + char;
      hash |= 0;
    }
    return `hash-${Math.abs(hash).toString(16)}`;
  }
}

export const aiCacheManager = new AICacheManager();
```

## 四、渐进式加载

### 4.1 流式输出与预览即拒绝

```typescript
// 对于"扩充"等可能产生大量文本的操作
// 使用流式输出让用户可以在看到初步结果后立即决定是否继续

interface StreamingAIResult {
  stream: AsyncGenerator<string, void, unknown>;
  abort: () => void;
  abortController: AbortController;
}

async function* streamingAIGenerate(
  prompt: string,
  options: { signal?: AbortSignal }
): AsyncGenerator<string, void, unknown> {
  // 调用 DeepSeek API 的流式端点
  const response = await fetch('/api/ai/generate-stream', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      prompt,
      model: 'flash',
      stream: true,
    }),
    signal: options.signal,
  });

  if (!response.ok || !response.body) {
    throw new Error('AI 请求失败');
  }

  const reader = response.body.getReader();
  const decoder = new TextDecoder();

  try {
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      const chunk = decoder.decode(value, { stream: true });
      // 从 SSE 格式中提取内容
      const lines = chunk.split('\n');
      for (const line of lines) {
        if (line.startsWith('data: ')) {
          const data = line.slice(6);
          if (data === '[DONE]') return;
          try {
            const parsed = JSON.parse(data);
            yield parsed.content || '';
          } catch {
            // 非 JSON 数据，跳过
          }
        }
      }
    }
  } finally {
    reader.releaseLock();
  }
}

// 使用示例
const { stream, abort } = streamingAIGenerate(prompt);
for await (const chunk of stream) {
  // 逐字更新 UI
  updateResultDisplay(currentText + chunk);
}

// 用户点击"拒绝" → 立即中止流式，停止 Token 消耗
abort();
```

### 4.2 成本收益分析

| 场景 | 无流式 | 有流式 | 节省 |
|------|--------|--------|------|
| 用户满意全量结果 | 同需消耗全部 Token | 同需消耗全部 Token | 0% |
| 用户生成中途不满意关闭 | 消耗全部 Token | 消耗部分 Token | 30-70% |
| 用户预览即拒绝 | 消耗全部 Token | 仅消耗开头 Token | 80-95% |

> **结论**：流式输出在成本控制上最重要的价值不在于"加速"，而在于**给了用户一个低成本终止点**。

## 五、成本追踪与统计

### 5.1 操作级 Token 记录

Token 消耗记录在 `Operation.aiContext.tokensConsumed` 字段中（计划01定义），可供：

1. **历史面板展示**：每条 AI 操作显示消耗的 Token 数
2. **会话统计**：汇总当前编辑会话的 AI Token 总消耗
3. **API 审计**：对每天/每月的 API 调用成本进行分析

```typescript
// 会话级 Token 统计
class TokenUsageTracker {
  private operations: Array<{
    timestamp: number;
    operationType: string;
    contextLevel: string;
    tokensConsumed: number;
    model: string;
  }> = [];

  addRecord(op: Operation): void {
    if (op.payload.aiContext) {
      this.operations.push({
        timestamp: op.timestamp,
        operationType: OperationType[op.type],
        contextLevel: '',  // 可从 ContextBuilder 获取
        tokensConsumed: op.payload.aiContext.tokensConsumed,
        model: op.payload.aiContext.model,
      });
    }
  }

  getTotalTokens(): number {
    return this.operations.reduce((sum, r) => sum + r.tokensConsumed, 0);
  }

  getStats(): {
    totalTokens: number;
    totalCalls: number;
    avgTokensPerCall: number;
    byOperationType: Record<string, { count: number; tokens: number }>;
  } {
    const byType: Record<string, { count: number; tokens: number }> = {};
    for (const r of this.operations) {
      if (!byType[r.operationType]) byType[r.operationType] = { count: 0, tokens: 0 };
      byType[r.operationType].count++;
      byType[r.operationType].tokens += r.tokensConsumed;
    }

    return {
      totalTokens: this.getTotalTokens(),
      totalCalls: this.operations.length,
      avgTokensPerCall: this.operations.length > 0
        ? Math.round(this.getTotalTokens() / this.operations.length)
        : 0,
      byOperationType: byType,
    };
  }
}
```
