# ADR-002: 采用 shadcn/ui 作为 UI 组件系统

## 状态
已接受 (Accepted)

## 日期
2026-02-05

## 背景
项目早期 UI 样式分散，缺乏统一的设计语言，导致维护成本高，且难以保证视觉一致性。

## 决策
采用 **shadcn/ui** (基于 Radix UI + Tailwind CSS) 作为标准组件库。

## 理由 (Decision Drivers)
1.  **源码级复用**: 直接拷贝代码到项目中，拥有完全的控制权，不受第三方库黑盒限制。
2.  **无障碍支持 (A11y)**: Radix UI 底层保证了键盘导航和屏幕阅读器支持（符合 WCAG 2.1 AA）。
3.  **Tailwind 集成**: 与项目现有的 Tailwind CSS 架构完美融合，无缝定制主题。
4.  **轻量级**: 按需引入，无巨型 bundle 负担。

## 后果 (Consequences)
*   **正向**: 统一了按钮、输入框等核心交互元素的视觉与行为；提升了代码可维护性。
*   **负向**: 需要手动管理组件文件 (`components/ui/`)；需要配置 `utils.ts` (cn helper)。

## 验证
已实现 `Button` 组件并替换编辑器工具栏按钮。
