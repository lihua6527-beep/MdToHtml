# 风险控制与运维手册

## 1. 核心风险分析

### 1.1 AI 模型风险 (High)
- **风险点**: 端侧 50MB 蒸馏模型可能产生幻觉或理解偏差。
- **控制措施**:
  - **CHD 约束**: 通过 CHD 协议严格限制输入空间，降低模型自由度。
  - **客户端校验**: 引入 `ValidationPipeline`，在浏览器端进行语法与语义双重检查。
  - **人机回环**: 提供 "Form Mode" (表单模式) 作为兜底，当 AI 无法解析时降级为手动填写。

### 1.2 架构刚性风险 (Medium)
- **风险点**: CHD 三层结构 (Document-Section-Card) 可能无法覆盖所有非标准文档需求。
- **控制措施**:
  - **通用卡片**: 提供 "Generic Free Card" 允许自由文本，但需标注 "Unstructured"。
  - **AST 扩展**: 预留 `metadata` 字段用于未来协议升级。

### 1.3 浏览器兼容性 (Medium)
- **风险点**: WebAssembly (WASM) 模型加载失败或性能低下。
- **控制措施**:
  - **特性检测**: 启动前检测 WASM 支持情况。
  - **优雅降级**: 若不支持 WASM，自动切换至纯规则模式或提示用户升级浏览器。

## 2. 运维与监控

### 2.1 日志策略
- **前端日志**: 记录关键交互路径与报错，通过 `console.error` 输出（开发环境）。
- **迁移日志**: 维护 `migration_log.csv`，记录文档迁移状态。

### 2.2 应急响应
- **白屏/崩溃**: 立即回滚至上一版本 (`upload/history` 中提取)。
- **端口冲突**: 启动脚本内置端口扫描功能，自动避开占用端口。

## 3. 常见问题排查 (Troubleshooting)
- **Q: 预览页面 404?**
  - A: 检查 `前端/out` 目录是否生成，确认 `next.config.js` 中 `output: 'export'` 配置正确。
- **Q: 脚本执行失败?**
  - A: 确认 Python 环境已安装，且 `scripts/` 目录在 PATH 中或使用绝对路径调用。
