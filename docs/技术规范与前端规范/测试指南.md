# 测试指南 (Testing Guide) v1.1

## 1. 测试概览
本项目采用 **Jest** + **React Testing Library** 作为单元测试框架，确保核心逻辑（验证器、解析器、打包器）的稳定性。

### 版本信息
- **当前版本**: v1.1
- **更新日期**: 2026-02-21
- **更新内容**: 增加解析器 (CHD Parser) 与导出模块 (HtmlBundler) 的覆盖率说明。

## 2. 运行测试

### 常用命令
| 命令 | 说明 |
| :--- | :--- |
| `npm test` | 运行所有单元测试一次 |
| `npm run test:watch` | 监视模式，文件变动时自动重新运行相关测试 |
| `npm run test:ci` | CI 模式，生成覆盖率报告并退出 |

### 目录结构
测试文件置于 `src/lib/__tests__` 目录或与源文件同级（`*.test.ts`）。

```text
src/
  lib/
    __tests__/
      chdParser.test.ts   <-- 解析器测试
    export/
      HtmlBundler.test.tsx <-- 导出模块集成测试
    validator.test.ts     <-- 验证器测试
```

## 3. 测试覆盖范围 (Current Coverage)

### 3.1 核心解析层 (Parser Layer)
- **目标文件**: `src/lib/chdParser.ts`
- **测试文件**: `src/lib/__tests__/chdParser.test.ts`
- **覆盖场景**:
  - Section/Card 结构解析
  - 代码块 (Code Block) 提取
  - 目录树结构识别

### 3.2 导出引擎 (Export Engine)
- **目标文件**: `src/lib/export/HtmlBundler.tsx`
- **测试文件**: `src/lib/export/HtmlBundler.test.tsx`
- **覆盖场景**:
  - Markdown 到 HTML 的完整渲染流程
  - CSS 样式注入 (Injection)
  - 模板变量替换 (Template Hydration)

### 3.3 校验器 (Validator)
- **目标文件**: `src/lib/validator.ts`
- **测试文件**: `src/lib/validator.test.ts`
- **覆盖场景**:
  - CHD 协议合规性检查

## 4. 编写规范
1.  **文件名**: 必须以 `.test.ts` 或 `.test.tsx` 结尾。
2.  **Mocking**: 对于涉及 DOM API (如 `document.styleSheets`) 或外部组件 (如 `react-markdown`) 的测试，必须使用 `jest.mock` 进行模拟。
3.  **断言**: 推荐使用 `expect(value).toBe(...)` 或 `toContain(...)` 进行明确断言。
