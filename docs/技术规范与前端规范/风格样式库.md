# 风格样式库 (Style & Design System)

> 本文档定义了 MdToHtml 项目的全局设计令牌 (Design Tokens) 与多主题配色体系。

## 1. 核心设计原则

系统采用 **CSS 变量 + Tailwind CSS** 的双层架构：
- **语义化变量**: 在 `globals.css` 中定义 `--primary`, `--bg-page` 等语义变量。
- **Tailwind 映射**: 在 `tailwind.config.js` 中将变量映射为工具类 (e.g., `bg-primary` -> `var(--primary)`).
- **运行时切换**: 通过 `ThemeProvider` 修改根元素 `data-theme` 属性实现毫秒级切换。

## 2. 颜色变量定义 (Design Tokens)

| 变量名 | Tailwind 类 | 语义说明 |
| :--- | :--- | :--- |
| `--primary` | `bg-primary`, `text-primary` | **主色**: 品牌核心色，用于按钮、高亮标题、关键状态。 |
| `--secondary` | `bg-secondary` | **次色**: 辅助背景色，常用于卡片装饰、次级按钮。 |
| `--accent` | `bg-accent` | **强调色**: 极淡的装饰色，用于 hover 态或微弱背景。 |
| `--bg-page` | `bg-bg-page` | **页面背景**: 整个应用的底层背景色。 |
| `--bg-card` | `bg-bg-card` | **卡片背景**: 内容容器背景，通常为纯白。 |
| `--text-primary` | `text-text-primary` | **主要文本**: 标题、正文核心内容。 |
| `--text-secondary` | `text-text-secondary` | **次要文本**: 说明文字、元数据。 |
| `--text-muted` | `text-text-muted` | **弱化文本**: 占位符、非关键信息。 |
| `--border-soft` | `border-border-soft` | **柔和边框**: 分割线、卡片边框。 |
| `--border-highlight`| `border-border-highlight`| **高亮边框**: 聚焦态或选中态边框。 |
| `--ring` | `ring-ring` | **聚焦环**: 输入框聚焦或选中态的光晕颜色。 |

## 4. 开发指南

### 如何使用颜色
在 React 组件中，直接使用 Tailwind 的语义化类名：

```tsx
// ❌ 错误：硬编码颜色
<div className="bg-[#2C6CFF] text-white">...</div>

// ✅ 正确：使用语义变量
<div className="bg-primary text-primary-foreground">...</div>
```

### 如何添加新主题
1. 在 `src/lib/themes.ts` 中添加 `ThemeId` 和配置项。
2. 在 `src/app/globals.css` 中添加 `[data-theme="new-theme"]` 选择器。
3. 定义对应的 CSS 变量值。

### 自动反色处理
目前主要通过 `--primary-foreground` (通常为白色) 确保在主色背景上的可读性。对于深色背景模式（如未来的 Dark Mode），只需调整变量映射即可。
