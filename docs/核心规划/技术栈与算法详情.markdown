## 3. 核心算法 (Core Algorithms)

### 3.1 CHD 文档解析

```
Markdown 文本
    ↓ parseCHDBlocks() — 行级扫描 → [CHDBlock]
        ├── L0: YAML Frontmatter (title, subtitle, tags, ...)
        ├── L1: ## Section {layout, columns, section-color}
        └── L2: ### Card {card-style, icon, badge}
    ↓ gray-matter 提取 frontmatter
    ↓ parseAttributes() 提取 {key="val"} 属性
    ↓ CHDRenderer 组装渲染树
```

### 3.2 智能列数 (Smart Columns)

在 `Section.tsx` 中实现：
- 1-4 张卡片 → 列数 = 卡片数量
- 5+ 张卡片 → 强制 3 列（自动换行）
- Gallery 布局强制 3 列
- Stat-row 布局强制 4 列

### 3.3 属性渲染清洗

`Section.tsx` 中的兜底过滤：
```typescript
title.replace(/\{.*?\}/g, '')
```
确保即使解析层面遗漏，UI 层面也能过滤掉配置代码，防止元数据泄漏到最终界面。

### 3.4 幽灵卡片过滤 (Ghost Card Filtering)

在 `CHDRenderer.tsx` 中：
- 预清洗：移除仅含 `---`、空格或换行符的内容块
- 严格匹配：只有以 `###` 开头的节点才被视为有效卡片
- 尾部修剪：自动去除卡片内容末尾的 `---` 分隔符

### 3.5 图表颜色命名 (Chart Colors)

5 种图表配色应用于卡片颜色的 `chart-N` 属性：
- `chart-1` ~ `chart-5`，每个主题各自定义了 5 组色值（详见第 11 节风格颜色体系）

- **文件**: `src/hooks/useAutoSave.ts`

- **编辑页保存**: `InteractivePost.tsx` 中 5 秒防抖 → 静默保存 (无弹窗)

---

## 5. 缓存策略 (Cache Strategy)

- **容量**: Top 500 篇文档 (`DEFAULT_CAPACITY = 500`)
- **结构**: 单层内存缓存 + `.metadata_cache.json` 持久化
- **加载**: 启动时 `getAll()` O(1) 返回
- **同步**: 后台异步 `scanAndSync()` 遍历 `posts/` 目录
- **回收站**: `.trash/` 目录，超出容量时自动清理最旧文件

## 10. 设计原则 (Design Principles)

系统采用 **CSS 变量 + Tailwind CSS** 的双层架构：
- **语义化变量**: 在 `globals.css` 中定义 `--primary`, `--bg-page` 等语义变量。
- **Tailwind 映射**: 在 `tailwind.config.js` 中将变量映射为工具类 (e.g., `bg-primary` → `var(--primary)`)。
- **运行时切换**: 通过 `ThemeProvider` 修改根元素 `data-theme` 属性实现毫秒级切换。

### 颜色变量定义 (Design Tokens)

| 变量名 | Tailwind 类 | 语义说明 |
| :--- | :--- | :--- |
| `--primary` | `bg-primary`, `text-primary` | **主色**: 品牌核心色，用于按钮、高亮标题、关键状态 |
| `--secondary` | `bg-secondary` | **次色**: 辅助背景色，常用于卡片装饰、次级按钮 |
| `--accent` | `bg-accent` | **强调色**: 极淡的装饰色，用于 hover 态或微弱背景 |
| `--bg-page` | `bg-bg-page` | **页面背景**: 整个应用的底层背景色 |
| `--bg-card` | `bg-bg-card` | **卡片背景**: 内容容器背景，通常为纯白 |
| `--text-primary` | `text-text-primary` | **主要文本**: 标题、正文核心内容 |
| `--text-secondary` | `text-text-secondary` | **次要文本**: 说明文字、元数据 |
| `--text-muted` | `text-text-muted` | **弱化文本**: 占位符、非关键信息 |
| `--border` | `border-border` | **边框**: 分割线、卡片边框（shadcn 标准） |
| `--ring` | `ring-ring` | **聚焦环**: 输入框聚焦或选中态的光晕颜色 |

## 12. 开发指南 (Dev Guide)

### 如何使用颜色
在 React 组件中，直接使用 Tailwind 的语义化类名：

```tsx
// ❌ 错误：硬编码颜色
<div className="bg-[#2C6CFF] text-white">...</div>

// ✅ 正确：使用语义变量
<div className="bg-primary text-primary-foreground">...</div>
```

### 如何添加新主题
1. 在 `src/lib/themes.ts` 中添加 `ThemeId` 和配置项。
2. 在 `src/app/globals.css` 中添加 `[data-theme="new-theme"]` 选择器。
3. 定义对应的 CSS 变量值。
