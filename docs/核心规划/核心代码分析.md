## 核心代码分析

### 前端核心

1. **HomeClient.tsx**:
   - 主页面组件，负责展示文件列表和处理拖拽上传
   - 实现了拖拽上传功能，支持批量上传 Markdown 文件
   - 集成了文件列表组件和设置面板

2. **DocumentList.tsx**:
   - 文件管理组件，负责展示文件列表和处理文件操作
   - 支持文件排序、批量选择、批量删除等功能
   - 集成了回收站功能，支持文件的回收和恢复

3. **editor/page.tsx**:
   - 编辑器页面，包含代码编辑器和实时预览
   - 实现了 Markdown 编辑、实时预览、导出等功能
   - 集成了 CodeMirror 编辑器，支持 Markdown 语法

4. **CHD/CHDRenderer.tsx**:
   - CHD 渲染引擎，负责渲染 Markdown 中的 CHD 语法
   - 支持卡片式布局、主题切换等功能
   - 实现了智能布局逻辑，自动调整卡片布局

### 服务层

1. **FileService.ts**:
   - 文件操作服务，处理文件的增删改查
   - 实现了文件保存、删除、移动等功能
   - 集成了事务管理，确保文件操作的原子性

2. **TrashService.ts**:
   - 回收站服务，处理文件的回收和恢复
   - 实现了回收站文件的管理和清理

3. **ConfigService.ts**:
   - 配置管理服务，处理系统配置
   - 实现了配置的读取和更新

### 工具库

1. **posts.ts**:
   - 文件管理工具，处理文件读写和元数据
   - 实现了文件的读取、写入和元数据管理

2. **chdParser.ts**:
   - CHD 解析器，解析 Markdown 中的 CHD 语法
   - 实现了 CHD 语法的解析和处理

3. **path-manager.ts**:
   - 路径管理工具，处理文件路径
   - 实现了路径的管理和解析
