## 1. 快速入门

### 1.1 启动系统

**方式一：双击脚本启动（推荐）**

```
双击项目根目录的 start.bat
```

系统将自动安装依赖（首次）→ 启动开发服务器 → 打开浏览器。

**方式二：命令行启动**

```bash
cd MdToHtml
npm install    # 仅首次需要
npm run dev    # 启动开发服务器
```

然后在浏览器中访问 `http://localhost:3000`。

### 1.2 核心工作流

```
创建/导入文档 → 编辑内容 → 预览效果 → 导出 HTML
        ↑                        ↓
        └──────── AI 辅助生成 ←──┘
```

**首次使用建议**：
1. 创建一篇新文档，熟悉双栏编辑界面
2. 使用 `##` 和 `###` 组织文档结构
3. 点击预览面板查看渲染效果
4. 尝试导出为 HTML 文件

## 3. 文档管理

### 3.1 创建新文档

| 方式 | 操作 |
|------|------|
| 按钮 | 点击左侧面板的「新建文档」按钮 |
| 快捷键 | `Ctrl + N` |

新文档将以默认模板创建，包含基本的 CHD 结构。

### 3.2 导入文件

支持导入以下格式：

| 格式 | 处理方式 | 说明 |
|------|---------|------|
| `.md` | 直接导入 | 标准 Markdown 文件 |
| `.txt` | 转为 Markdown | 纯文本文件，自动包裹基础格式 |
| `.docx` | AI 转换 | 自动调用 AI 服务转换为 CHD 格式（需要网络） |

**操作步骤**：
1. 点击「导入文件」按钮
2. 选择文件（支持多选）
3. 系统自动将文件复制到 `posts/` 目录并加载

### 3.3 保存文档

| 方式 | 说明 |
|------|------|
| 自动保存 | 每 3 秒自动保存当前文档（可在设置中调整间隔） |
| 手动保存 | `Ctrl + S` 或点击工具栏保存按钮 |
| 保存提示 | 状态栏显示 `已保存 ✓` 表示保存成功 |

### 3.4 删除与恢复

**删除文档**：
1. 在文档列表中右键点击文档
2. 选择「删除」

> 删除的文档会移入回收站，不会永久删除

**从回收站恢复**：
1. 点击「回收站」进入回收站页面
2. 找到要恢复的文档
3. 点击「恢复」按钮

**永久删除**：
- 在回收站中选择「永久删除」将彻底删除文件

### 3.5 排序与筛选

| 操作 | 说明 |
|------|------|
| 按更新时间排序 | 默认，最近编辑的文档靠前 |
| 按创建时间排序 | 最古老的文档靠前 |
| 按名称排序 | 字母顺序 |
| 收藏 | 点击文档旁的星标，收藏的文档会出现在列表顶部 |
| 置顶 | 点击置顶按钮，文档固定在列表最上方 |

## 4. 编辑器使用

### 4.1 基本编辑

编辑器基于 CodeMirror 6，支持标准文本编辑操作：

- **光标准确定位**：点击任意位置定位光标
- **选择文本**：拖拽选择或 `Shift + 方向键`
- **复制/粘贴**：`Ctrl + C` / `Ctrl + V`
- **查找替换**：`Ctrl + F`（打开查找面板）

### 4.2 Markdown 语法支持

| 语法 | 效果 | 示例 |
|------|------|------|
| `**粗体**` | **粗体** | `**重要内容**` |
| `*斜体*` | *斜体* | `*强调*` |
| `` `行内代码` `` | `行内代码` | `` `code` `` |
| ``` ```代码块``` ``` | 代码块 | ` ```typescript ... ``` ` |
| `[链接](url)` | [链接](url) | `[Google](https://google.com)` |
| `![图片](url)` | 图片 | `![Logo](./logo.png)` |
| `$$ LaTeX $$` | 数学公式 | `$$ E=mc^2 $$` |
| `- 列表项` | 无序列表 | `- 第一项` |
| `1. 列表项` | 有序列表 | `1. 第一步` |
| `> 引用` | 引用块 | `> 这是一段引用` |
| `---` | 分隔线 | `---` |
| \`表格\` | GFM 表格 | `\| 列1 \| 列2 \|` |

### 4.3 撤销/重做

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 撤销 | `Ctrl + Z` | 回退上一步操作 |
| 重做 | `Ctrl + Shift + Z` | 恢复被撤销的操作 |

> 系统保存最近 50 步操作历史，关闭页面后重新打开仍可撤销。

## 5. CHD 协议写作

### 5.1 基础结构

CHD 协议文档由三层结构组成：

```markdown
---
title: 我的文档
author: 作者
date: 2026-07-12
---

## 第一章：背景介绍

### 卡片 1：核心概念

这是卡片的内容。

### 卡片 2：详细说明

更多详细内容。

## 第二章：技术实现

### 卡片 3：架构设计

这里描述架构。
```

### 5.2 卡片样式

CHD 支持四种卡片样式：

| 样式 | Markdown 写法 | 预览效果 |
|------|-------------|---------|
| **普通卡片** | `### 标题` | 白色背景，圆角阴影 |
| **高亮卡片** | `### 标题 [!highlight]` | 蓝色左侧边框，背景浅蓝 |
| **引用卡片** | 内容以 `>` 开头 | 灰色左侧引用线 |
| **代码卡片** | \`\`\` `语言` \`\`\` | 深色代码背景，行号 |

**示例**：

```markdown
### 高亮示例 [!highlight]
这是一个高亮卡片，适合放置重要结论或关键信息。

### 引用示例

> 这段内容会被渲染为引用卡片样式。
> 支持多行引用。

### 代码示例

```python
def hello():
    print("Hello, CHD!")
```
```

### 5.3 实时预览

编辑器右侧的预览面板会实时渲染 CHD 文档：
- 修改左侧源码 → 右侧预览自动更新
- 滚动同步：编辑器和预览面板支持双向滚动关联

## 6. AI 辅助生成

### 6.1 进入 AI 功能

点击顶部导航栏的「AI 生成」按钮，进入 AI 对话页面。

### 6.2 生成 CHD 文档

**方式一：从自然语言描述生成**

1. 在 AI 输入框中描述你想要的文档内容
2. 选择 Prompt 模板（通用/学术）
3. 选择模型（Flash/Pro）
4. 点击「生成」
5. 等待 AI 输出，结果以流式方式逐步显示
6. 确认满意后点击「保存」

**示例输入**：
```
请生成一份关于"机器学习基础"的笔记文档，
包含：监督学习、无监督学习、深度学习三个章节，
每章3张卡片。
```

**方式二：从文件转换**

1. 上传 `.txt` / `.md` / `.docx` 文件
2. 系统自动调用 AI 转换为 CHD 格式
3. 预览转换结果
4. 保存到文档库

### 6.3 Token 预算控制

AI 上下文管理分为三级：

| 等级 | Token 预算 | 适用场景 |
|------|-----------|---------|
| Minimal | 200-400 | 简短笔记、快速生成 |
| Medium | 800-1,500 | 中等长度文档 |
| Full | 2,000-5,000 | 长文档、复杂结构 |

> 注意：AI 功能需要网络连接和有效的 API Key。请在设置页面配置 DeepSeek API Key。

### 6.4 对比与保存

AI 生成结果支持：
- **预览**：查看生成内容的渲染效果
- **下载**：下载为 Markdown 文件
- **保存**：直接保存到文档库
- **对比**：与当前文档进行对比（Diff 视图）

## 7. HTML 导出

### 7.1 导出单个文档

1. 打开要导出的文档
2. 点击工具栏的「导出」按钮（或 `Ctrl + E`）
3. 选择导出主题（默认/暗黑）
4. 系统自动生成独立 HTML 文件
5. 导出完成后弹出保存对话框

**导出产物特点**：
- 单文件 HTML，所有 CSS 和资源内联
- 无需任何外部依赖，可直接在浏览器中打开
- 保留 CHD 卡片式布局和交互效果
- 支持打印和打印预览

### 7.2 导出设置

| 设置项 | 选项 | 说明 |
|-------|------|------|
| 主题 | 默认 / 暗黑 | 选择导出文档的配色方案 |
| 是否包含元数据 | 是 / 否 | 是否在 HTML 头部包含生成信息 |
| 代码高亮 | 是 / 否 | 代码块是否保留语法高亮 |

### 7.3 批量导出（开发中）

支持从文档列表中选择多篇文档，一键批量导出。

## 11. 常见问题

### 11.1 启动问题

**Q: 启动后浏览器没有自动打开？**

A: 手动在浏览器中访问 `http://localhost:3000`。如果无法访问，检查终端输出是否有端口冲突（系统会自动切换到其他端口）。

**Q: 提示 "Node.js 未找到"？**

A: 请从 https://nodejs.org/ 下载并安装 Node.js v18.17.0 或更高版本。

### 11.2 编辑问题

**Q: 编辑内容没有在预览中更新？**

A: 检查控制台是否有错误输出。常见原因：
- Markdown 语法错误导致解析失败（如未闭合的代码块）
- 内容为空时预览面板显示空白属于正常行为

**Q: 文档丢失了？**

A: 进入回收站查看。文档删除后不会永久丢失，可以从回收站恢复。

### 11.3 AI 功能问题

**Q: AI 生成失败？**

A: 检查以下可能原因：
1. 网络连接是否正常
2. API Key 是否已配置且有效
3. 输入的提示词是否为空

**Q: API Key 在哪里获取？**

A: 访问 https://platform.deepseek.com/ 注册并获取 API Key，然后在设置页面中配置。

### 11.4 导出问题

**Q: 导出的 HTML 文件无法打开？**

A: 直接双击 HTML 文件在浏览器中打开。如果使用 Edge/Chrome，请确保没有安全策略阻止本地文件。

**Q: 导出文件中的图片不显示？**

A: 导出的 HTML 为单文件，只包含内联资源。如果有外部图片链接，请确保图片可公开访问，或将图片转为 Base64 内联。

### 11.5 性能问题

**Q: 编辑大文档（>5000 行）时卡顿？**

A: 这是一个已知限制。建议：
1. 将大文档拆分为多个小文档
2. 关闭预览面板，仅编辑源码
3. 减少代码块和数学公式的数量

**Q: 启动速度慢？**
