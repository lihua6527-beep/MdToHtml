# 双模式编辑系统用户手册 (CHD Studio User Manual)

## 1. 系统概述 (System Overview)
**CHD Studio** 是一个专为结构化文档设计的交互式编辑系统，集成了 **Markdown 实时编辑** 与 **图形化渲染预览**。系统采用左右分栏布局，实现了所见即所得 (WYSIWYG) 的创作体验，特别适合构建基于 CHD 协议的复杂文档。

### 核心特性
- **双向同步 (Bidirectional Sync)**:
  - **滚动同步**: 滚动左侧编辑器，右侧预览自动跟随；反之亦然。
  - **点击定位**: 点击右侧预览卡片，左侧编辑器自动跳转至对应源码行。
- **实时渲染**: 毫秒级编译，输入即可见图形化结果。
- **智能辅助**: 内置斜杠命令 (`/`) 快速插入组件，实时语法校验。

## 2. 界面布局 (Interface Layout)

系统界面分为三个主要区域：

### 2.1 顶部导航栏
- **Logo**: 点击返回首页。
- **状态栏**: 显示当前文件路径及保存状态 (Saved/Saving...)。
- **工具栏**: 提供视图切换、导出 (Download) 等功能。

### 2.2 左侧：编辑器 (Editor)
- **功能**: 核心创作区域，支持标准 Markdown 语法。
- **特性**:
  - **行号显示**: 辅助定位。
  - **语法高亮**: 关键词着色。
  - **快捷命令**: 输入 `/` 唤出组件插入菜单。
  - **问题面板**: 底部实时显示语法错误与优化建议。

### 2.3 右侧：实时预览 (Live Preview)
- **功能**: 展示最终渲染效果。
- **特性**:
  - **真实渲染**: 1:1 还原最终产物样式。
  - **交互响应**: 支持卡片点击、图表交互。
  - **自适应布局**: 自动响应窗口大小调整。

## 3. 快速上手 (Quick Start)

### 3.1 基础编辑
1. **输入标题**: 使用 `#` (H1), `##` (H2), `###` (H3) 构建文档骨架。
2. **插入组件**:
   - 在空行输入 `/`，弹出菜单。
   - 使用 `↑/↓` 选择组件（如 `Card`, `Stat`, `Highlight`），按 `Enter` 插入。
3. **设置属性**:
   - 在标题后添加 `{key="value"}` 定义属性。
   - 例如: `### 核心指标 {card-style="stat"}`

### 3.2 文件操作
- **打开文件**: 将本地 `.md` 文件直接 **拖拽** 到编辑器区域即可打开。
- **保存文件**:
  - **自动保存**: 系统会实时保存内容到浏览器缓存 (LocalStorage)。
  - **导出**: 点击右上角 **Download** 按钮下载 `.md` 文件到本地。

### 3.3 高级交互
- **定位源码**: 在右侧预览区看到感兴趣的卡片时，**点击该卡片**，左侧编辑器会自动滚动并高亮对应的 Markdown 源码块。
- **同步浏览**: 随意滚动任意一侧，另一侧会自动匹配进度，保持上下文一致。

## 5. 常见问题 (FAQ)

**Q: 为什么右侧预览没有显示内容？**
A: 请检查左侧 Markdown 是否符合 CHD 规范。最常见的原因是缺少 `###` (L3 Card) 层级，或者 Frontmatter 格式错误。

**Q: 如何调整卡片宽度？**
A: 系统会根据文本内容自动计算宽度。如果需要强制调整，可以使用布局属性（高级功能，详见技术文档）。

**Q: 支持图片上传吗？**
A: 目前版本支持标准 Markdown 图片语法 `![alt](url)`，建议使用图床链接。本地图片上传功能将在后续版本推出。

**Q: 浏览器刷新后内容会丢失吗？**
A: 不会。系统内置自动保存机制，刷新页面后会恢复上次编辑的内容。但建议定期下载 `.md` 文件备份。
