# MdToHtml 系统分析文档

## 1. 系统概述

MdToHtml 是一个 Windows 本地专属的 Markdown 转静态 HTML 工具，旨在为知识工作者提供高质量的内容排版和发布解决方案。系统基于 Next.js 14 (SSG) 构建，裁剪了所有服务端动态特性，仅保留静态生成能力。

### 1.1 核心定位
- **Windows Only**: 仅支持 Windows 10/11 环境
- **Local Only**: 所有数据处理在本地完成，无云端依赖
- **No Concurrency**: 采用稳定顺序处理，不支持并发转换

### 1.2 核心理念
系统本质上是在回答一个问题：当AI能生成无限内容时，如何确保输出的品质与一致性？

答案是：**协议化输入、自动化评分、可视化调优、多态化输出**。

## 2. 前端UI分析

### 2.1 页面结构

#### 2.1.1 首页 (Home)
- **布局**: 左侧文档列表 + 右侧主内容区
- **主要组件**:
  - DocumentList: 文档列表，支持排序、筛选、批量操作
  - HomeClient: 主容器，处理拖拽上传功能
  - PathSettingsPanel: 路径设置面板

#### 2.1.2 编辑器页面 (Editor)
- **布局**: 顶部导航栏 + 内容编辑区 + 底部工具栏
- **主要组件**:
  - InteractivePost: 编辑器主容器
  - CHDRenderer: CHD 渲染引擎
  - BottomToolbar: 底部编辑工具栏
  - FloatingUndoRedo: 浮动撤销/重做按钮

#### 2.1.3 预览页面 (Preview)
- **布局**: 纯渲染视图
- **主要组件**:
  - CHDRenderer: 仅渲染模式

### 2.2 交互元素

#### 2.2.1 文档列表
- **拖拽交互**: 支持拖拽文档到回收站删除
- **右键菜单**: 提供删除选项
- **批量操作**: 支持多选、批量删除
- **排序功能**: 按导入时间、修改时间、最近访问排序
- **容量管理**: 显示存储容量使用情况

#### 2.2.2 编辑器
- **实时预览**: 编辑模式与预览模式切换
- **状态管理**: 文档状态（未完成/已完成）切换
- **文档类型**: 项目、论文、知识分享、其他文档
- **评分系统**: 实时显示文档评分和优化建议
- **导出功能**: 导出为静态 HTML
- **历史记录**: 支持撤销/重做操作

#### 2.2.3 CHD 渲染
- **智能布局**: 自动根据卡片数量调整列数
- **卡片操作**: 移动、删除、添加卡片
- **样式定制**: 主题切换、标签样式选择
- **属性编辑**: 编辑卡片和分区属性

## 3. 交互流程分析

### 3.1 文档管理流程

1. **文件上传**:
   - 拖拽 Markdown 文件到主内容区
   - 系统自动处理并添加到文档列表

2. **文档选择**:
   - 点击文档列表中的文档
   - 进入编辑器页面

3. **文档排序**:
   - 点击设置菜单中的排序选项
   - 选择排序方式（导入时间、修改时间、最近访问）

4. **文档删除**:
   - 右键点击文档，选择删除选项
   - 或拖拽文档到回收站图标
   - 文档移至回收站

5. **回收站操作**:
   - 点击回收站图标进入回收站页面
   - 可恢复或永久删除文档

### 3.2 编辑流程

1. **进入编辑模式**:
   - 点击编辑器页面的"编辑页面"按钮
   - 系统切换到编辑模式

2. **内容编辑**:
   - 直接编辑 Markdown 内容
   - 或使用可视化编辑器修改卡片内容

3. **属性调整**:
   - 选择卡片或分区
   - 使用底部工具栏调整属性

4. **状态更新**:
   - 点击"未完成"或"已完成"按钮
   - 系统更新文档状态

5. **保存操作**:
   - 自动保存（5秒防抖）
   - 或手动点击"保存修改"按钮

6. **导出操作**:
   - 点击"导出 HTML"按钮
   - 系统生成并下载静态 HTML 文件

### 3.3 系统设置流程

1. **路径设置**:
   - 点击设置菜单中的"文件路径"选项
   - 调整输入/输出目录路径

2. **容量设置**:
   - 点击设置菜单中的"存储容量"选项
   - 选择容量限制（20-500）

3. **主题设置**:
   - 在编辑器页面底部工具栏选择主题
   - 系统实时切换主题

## 4. 底层数据流转分析

### 4.1 数据存储

- **本地文件系统**: 存储 Markdown 源文件和生成的 HTML 文件
- **LocalStorage**: 存储用户偏好设置（排序方式、侧边栏状态等）
- **会话存储**: 存储编辑历史和操作记录

### 4.2 数据处理流程

1. **文件上传**:
   - 前端接收拖拽文件
   - 发送到后端 API (/api/upload)
   - 后端保存文件到输入目录
   - 前端刷新文档列表

2. **文档编辑**:
   - 前端修改内容
   - 实时更新状态
   - 防抖保存到后端
   - 后端更新文件内容

3. **文档删除**:
   - 前端发送删除请求
   - 后端将文件移至回收站
   - 前端刷新文档列表

4. **导出流程**:
   - 前端调用 HtmlBundler.bundle()
   - 生成 HTML 内容
   - 保存到输出目录
   - 触发下载

### 4.3 状态管理

- **编辑器状态**: 使用 useHistory 钩子管理编辑历史
- **UI 状态**: 使用 React useState 管理界面状态
- **持久化状态**: 使用 useLocalStorage 钩子持久化用户偏好
- **全局状态**: 使用 Context API 管理主题等全局状态

## 5. 消息传递机制

### 5.1 组件间通信

- **Props 传递**: 父组件向子组件传递数据和回调函数
- **Context API**: 全局状态共享（如主题）
- **自定义事件**: 如 'app-paths-updated' 事件

### 5.2 前后端通信

- **API 调用**: 使用 fetch 调用后端 API
- **文件操作**: 通过 API 进行文件的上传、保存、删除等操作
- **状态同步**: 后端操作完成后，前端刷新状态

### 5.3 服务层通信

- **FileService**: 处理文件操作
- **ConfigService**: 处理配置管理
- **TrashService**: 处理回收站操作

## 6. 缓存策略

### 6.1 前端缓存

- **SWR**: 用于数据缓存和自动更新
- **本地缓存**: 使用 LocalStorage 存储用户偏好
- **会话缓存**: 存储编辑历史和操作记录

### 6.2 渲染缓存

- **组件 memo**: 使用 React.memo 优化渲染性能
- **useMemo**: 缓存计算结果
- **useCallback**: 缓存回调函数

### 6.3 数据预加载

- **静态生成**: 使用 Next.js SSG 预生成页面
- **数据预取**: 预加载文档列表数据

## 7. 技术架构

### 7.1 前端技术栈

- **框架**: React 18 + Next.js 14 (SSG)
- **样式**: Tailwind CSS + Shadcn UI
- **编辑器**: CodeMirror 6
- **状态管理**: React Hooks + Context API
- **数据请求**: SWR
- **工具库**: clsx, gray-matter

### 7.2 后端技术栈

- **运行时**: Node.js
- **API**: Next.js API Routes
- **文件系统**: Node.js fs 模块
- **构建工具**: Windows Batch + PowerShell

### 7.3 数据流

```
File System (Input) -> AST Parsing -> React Rendering -> Static HTML (Output)
```

## 8. 系统优化点

### 8.1 性能优化

- **渲染性能**: 使用 React.memo 和 useMemo 减少不必要的渲染
- **网络请求**: 使用 SWR 缓存数据，减少重复请求
- **文件操作**: 优化文件读写操作，避免阻塞主线程
- **批量处理**: 支持批量文件操作，提高效率

### 8.2 用户体验优化

- **实时反馈**: 操作后立即显示反馈，如保存成功提示
- **错误处理**: 友好的错误提示和处理机制
- **加载状态**: 显示加载动画，提高用户感知
- **键盘快捷键**: 支持常用操作的键盘快捷键

### 8.3 功能优化

- **智能布局**: 自动调整卡片布局，提高可读性
- **评分系统**: 实时评分和优化建议，提高文档质量
- **主题系统**: 支持多种主题，满足不同用户偏好
- **导出功能**: 优化导出流程，支持多种格式

## 9. 总结

MdToHtml 是一个功能强大的本地 Markdown 转 HTML 工具，通过协议化输入、自动化评分、可视化调优和多态化输出，为知识工作者提供了高质量的内容排版解决方案。系统采用现代前端技术栈，具有良好的用户体验和性能表现。

### 9.1 核心优势

- **本地处理**: 所有数据在本地处理，保证数据安全
- **所见即所得**: 实时预览编辑效果
- **智能布局**: 自动优化文档布局
- **评分系统**: 提供文档质量评估和优化建议
- **多主题支持**: 满足不同用户偏好

### 9.2 应用场景

- **知识管理**: 整理和发布个人知识
- **内容创作**: 创作和排版文章、博客
- **文档分享**: 生成静态网页分享给他人
- **项目文档**: 管理项目文档和说明

### 9.3 发展潜力

- **AI 集成**: 结合 AI 技术，提供智能内容生成和优化
- **多平台支持**: 扩展到其他操作系统
- **协作功能**: 添加协作编辑功能
- **更多输出格式**: 支持更多输出格式，如 PDF、EPUB 等

通过不断优化和扩展，MdToHtml 有潜力成为知识工作者的必备工具，帮助他们更高效地创建和管理内容。
