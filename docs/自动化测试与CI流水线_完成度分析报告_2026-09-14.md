## 二、流水线资产清单（逐项核对）

### 2.1 CI 工作流

| 文件 | Job | 步骤序列 | 触发条件 | 超时 | 产物 |
|------|-----|----------|----------|:----:|------|
| `.github/workflows/ci.yml` | `build`（Build & Test） | checkout → setup-node@20 → `npm ci` → `typecheck` → `lint:strict` → `test:ci` → `build` | `push: [master]`（`paths-ignore: docs/**, **.md`） | 20 min | `next-build`（`.next/`） |
| 同上 | `e2e`（needs: build） | checkout → setup-node@20 → `npm ci` → `playwright install --with-deps chromium` → `test:e2e` | 同上 | 20 min | `playwright-report/`（always）、`test-results/`（failure） |
| `.github/workflows/pr-check.yml` | `quality`（Code Quality） | checkout → setup-node@20 → `npm ci` → `typecheck` → `lint:strict` → `test:ci` | `pull_request: [master]`（同 paths-ignore） | 15 min | `coverage/`（always） |

两个工作流均已启用 `concurrency`（同分支连续推送取消上一次运行）、`working-directory: MdToHtml`、npm 缓存（`cache-dependency-path: MdToHtml/package-lock.json`）。

> ✅ 已修正的历史问题：`branches: [main]`→`[master]`、`node-version 18`→`20`、E2E job 由 `continue-on-error: true` 升级为**硬门禁**（依据 `plans/测试工程/00_CI全绿计划书_2026-09-14.md` §8.1）。
> ⚠️ 仍存在的前置缺口：**`git remote -v` 为空**，且当前分支为 `feat/exe-package-ready` —— 两个工作流都不可能在 GitHub 上被触发（见 §5 G1）。

### 2.2 测试配置

| 文件 | 关键设置 | 作用 |
|------|----------|------|
| `MdToHtml/jest.config.js` | `next/jest`；`jest-environment-jsdom`；`moduleNameMapper: ^@/(.*)$ → src/$1` | 单元/组件测试 |
| 同上 | `testMatch: src/**/{__tests__,*.test,*.spec}.{ts,tsx}` + `testPathIgnorePatterns: /node_modules/, /e2e/, /.next/` | **Jest 只管单测**，3 个 Playwright spec 不再被误收 |
| 同上 | `collectCoverageFrom: src/**/*.{ts,tsx}`（排除 `.d.ts` 与测试文件） | 覆盖率按**全量 src** 统计，杜绝分母虚高 |
| 同上 | `coverageThreshold.global: 19 / 14 / 13 / 20` | 防回退门禁（标定规则写在配置注释中） |
| `MdToHtml/jest.setup.ts` | `@testing-library/jest-dom` + `TextEncoder/Decoder` polyfill + Toast mock | 测试环境底座 |
| `MdToHtml/playwright.config.ts` | `testDir: ./e2e`、`fullyParallel: false`、CI `retries: 2 / workers: 1`、`forbidOnly: !!process.env.CI` | E2E 运行策略 |
| 同上 | `webServer: { command: 'npm run dev', reuseExistingServer: false, env: { MDTOHTML_CONFIG: 'config.e2e.json' } }` | **数据隔离 + 强制自拉起服务器**（防误连开发者手动启动的真实环境） |
| `MdToHtml/config.e2e.json` | `paths.input/output/data/trash` → `.e2e-tmp/*` | 隔离目录定义 |
| `MdToHtml/.eslintrc.json` | `extends: next/core-web-vitals` | 配合 `--max-warnings 0` 做零容忍门禁 |
| 根 `.gitignore` | `coverage/`、`.e2e-tmp/`、`test-results/`、`playwright-report/`、`**/__pycache__/`、`**/*.pyc` | 阻断可再生产物入库 |

```powershell
cd MdToHtml
```

### 7.2 分项命令与观察点

| 目的 | 命令 | 观察点 |
|------|------|--------|
| 单元测试（不统计覆盖率） | `npx jest --ci` | `Test Suites: 25 passed` / `Tests: 213 passed` |

| E2E（含报告） | `npx playwright test` → `npm run test:e2e:report` | 7 passed；报告目录 `playwright-report/` |
