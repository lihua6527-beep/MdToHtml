# P0_交互-文件IO升级计划

## 1. 背景与目标
当前文件路径配置依赖手动修改代码或配置文件，操作繁琐且不直观。为了提升用户体验并适配桌面端使用场景，需实现“默认配置+灵活交互”的文件 I/O 机制。

**核心目标**：
1.  **开箱即用**：无需配置，软件启动即自动识别安装目录下的输入/输出文件夹。
2.  **灵活交互**：支持拖拽文件引入，支持 Web 标准的浏览器下载。
3.  **可配置化**：通过外部配置文件支持路径自定义。

## 2. 需求详情

### 2.1 配置文件与默认路径 (Configuration & Defaults)
- **配置文件**: 引入 `config.json` (或 `.env` 映射)，位于程序运行根目录。
- **默认输入路径**: 默认为 `<安装目录>/input`。
- **默认输出路径**: 默认为 `<安装目录>/output`。
- **目录结构**:
  ```text
  MdToHtml/
  ├── MdToHtml.exe      # 主程序
  ├── config.json       # 配置文件 (可选)
  ├── input/            # 默认存放 Markdown 源码
  └── output/           # 默认存放生成的 HTML
  ```
- **初始化行为**: 系统启动时，后端服务应自动检查并创建这两个文件夹（如果不存在），并扫描 `input` 目录构建初始文件列表。

### 2.2 输入交互 (Input Interaction)
- **自动扫描**: 启动时自动加载默认输入路径下的所有 `.md` 文件到左侧文件列表。
- **拖拽支持**: 用户可将外部 Markdown 文件或文件夹直接拖入编辑器区域。
  - *行为*: 拖入的文件将被添加到当前会话的文件列表中（可视作临时引入），不强制移动文件到 `input` 目录，除非用户执行“另存为”操作。
- **手动选择**: 保留“打开文件夹”按钮，允许用户通过系统对话框选择其他目录。

### 2.3 输出交互 (Output Interaction)
- **本地保存 (Save)**:
  - 点击“保存”时，默认将当前编辑的 HTML 内容写入 `<安装目录>/output` 文件夹。
  - 文件名与输入文件名保持一致（或增加时间戳版本控制）。
- **浏览器下载 (Export/Download)**:
  - 点击“导出”或“下载”时，挂载到浏览器的下载队列。
  - 使用浏览器的默认下载路径（通常为 `Downloads` 文件夹）。
  - 此功能确保在纯 Web 环境或不想污染安装目录时的可用性。

## 3. 技术方案

### 3.1 路径解析层 (Path Resolution)
- **环境感知**:
  - **开发环境**: 使用 `process.cwd()` 定位项目根目录。
  - **生产环境 (Electron)**: 使用 `path.dirname(process.execPath)` 定位 `.exe` 所在目录。
- **配置优先**: 启动时读取 `config.json`，若存在 `inputPath`/`outputPath` 配置则优先使用，否则回退到默认逻辑。

### 3.2 混合文件系统策略
- **后端服务 (Electron/Node)**: 负责直接读写 `input` 和 `output` 目录。
- **前端交互**:
  - 拖拽文件通过 HTML5 Drag and Drop API 读取 `File` 对象。
  - 浏览器下载通过 `<a>` 标签的 `download` 属性或 `Blob` 对象 URL 触发。

### 3.3 状态管理更新
- `defaultPaths`: 存储服务端返回的默认输入/输出路径信息。
- `fileList`: 也就是当前的工作区文件列表，来源包含“默认目录扫描”和“拖拽引入”。

## 4. 实施步骤
1.  **路径适配器开发**: 实现 `PathManager`，支持解析 `config.json` 和计算安装目录路径。
2.  **后端扫描逻辑**: 编写 API 接口，启动时返回 `input` 目录下的文件索引。
3.  **前端文件流整合**: 修改 `InteractivePost` 或侧边栏，使其能同时显示后端扫描的文件和前端拖拽的文件。
4.  **双模式导出实现**: 区分“保存到 Output 目录” (API 调用) 和 “下载到本地” (浏览器行为) 的 UI 入口。
5.  **配置读取**: 实现简单的 JSON 配置文件读取逻辑。

## 5. 风险与注意
- **权限问题**: 若软件安装在 `C:\Program Files` 等受保护目录，直接读写 `input/output` 可能需要管理员权限。
  - *应对*: 推荐用户使用“便携版”模式（解压即用），或在检测到无权限时回退到用户文档目录 (`Documents/MdToHtml/input`)。
