# P1_功能-单文件导出完善计划

## 1. 背景
基于 `单文件导出方案与编辑期一体化分析.md`，目前已完成部分组件开发，需进一步完善资源内联与下载流程。

## 2. 现有进度
- [x] **HtmlBundler 组件**: `src/lib/export/HtmlBundler.tsx` 已存在。
- [x] **CssExtractor 工具**: `src/lib/export/CssExtractor.ts` 已存在。
- [x] **模板引擎**: `src/lib/export/template.ts` 已存在。

## 3. 剩余任务
### 3.1 资源内联 (Asset Inlining)
- **CSS 内联**: 确保 `CssExtractor` 能正确提取 Shadcn/UI 及 Tailwind 生成的样式。
- **图片内联**: 遍历 DOM 中的 `<img>` 标签，将 `src` 转换为 Base64 (注意：需处理跨域和本地文件访问权限)。
- **JS 内联**: 注入核心交互脚本（如必要的 Hydration 脚本或纯 Vanilla JS 交互逻辑）。

### 3.2 打包与下载
- **Blob 生成**: 完善 `HtmlBundler` 的 `bundle()` 方法，生成最终 HTML 字符串。
- **下载触发**: 实现 `downloadBlob(content, filename)` 工具函数。

### 3.3 验证
- **预览**: 在新标签页打开生成的 Blob URL 进行预览。
- **离线测试**: 断网状态下打开下载的 HTML 文件，验证样式和图片是否正常显示。

## 4. 实施计划
1.  **代码审计**: 检查 `CssExtractor.ts` 的提取逻辑，确保无遗漏。
2.  **图片处理**: 在 `HtmlBundler` 中增加 `processImages(html)` 步骤，使用 Canvas 或 Fetch API 获取图片数据转 Base64。
3.  **集成测试**: 在编辑器中添加“导出 HTML”按钮，联调全流程。
