# 项目计划书 (Project Plan) - 卡片形态与布局革新

> **版本**: 1.0.0
> **日期**: 2026-02-17
> **分支**: `feature/card-shape-layout`
> **作者**: Trae AI & User

## 1. 需求概述 (Overview)
当前 CHD (Card-based Hybrid Document) 系统以“矩形 + 网格”为主，视觉表现力单调。为了实现更接近“艺术化排版”或“PPT 风格”的自由度，本计划旨在引入**卡片形态 (Shape)** 与 **自由布局 (Layout)** 两个全新的维度。
目标是无需修改后端解析逻辑，仅通过前端增强渲染引擎 (`CHDRenderer`) 和样式系统，支持多边形卡片、悬浮叠加、环形分布等高级视觉效果。

## 2. 功能范围 (Scope)
### 2.1 包含内容 (In-Scope)
- [ ] **样式原子化**: 将 `card_shape_prototype.html` 中的 CSS 移植到全局样式表。
- [ ] **卡片形态支持**: `Card` 组件支持 `shape` 属性 (circle, pill, cut, arrow)。
- [ ] **布局引擎升级**: `Section` 组件支持 `layout-mode` 属性 (grid, hub, carousel, overlap)。
- [ ] **交互逻辑增强**: 实现环形布局的动态计算与 3D 轮播的交互控制。
- [ ] **平滑过渡**: 确保旧版文档渲染不受影响（向下兼容）。

### 2.2 不包含内容 (Out-of-Scope)
- [ ] 后端解析器的大规模重构（依赖现有属性透传机制）。
- [ ] 可视化编辑器的拖拽布局功能（仅实现渲染层支持）。

## 3. 技术方案 (Technical Approach)
### 3.1 架构设计
- **样式层**: 在 `globals.css` 中引入 Shape Utilities (`.shape-cut`, `.clip-arrow` 等) 和 Layout Utilities (`.overlap-container`).
- **组件层**:
    - `Card.tsx`: 新增 `shape` prop 解析，映射到对应 CSS 类。
    - `Section.tsx`: 新增 `layout-mode` prop 解析，根据模式选择子布局组件。
    - **新增子组件**:
        - `HubLayout.tsx`: 负责中心+卫星的绝对定位计算。
        - `CarouselLayout.tsx`: 负责 3D 变换样式计算。

### 3.2 关键算法/逻辑
- **Hub Layout**: 使用三角函数 (`cos`, `sin`) 根据子元素数量 $N$ 计算每个卫星卡片的 $(x, y)$ 坐标。
- **Carousel Layout**: 计算每个卡片的 `rotateY` 和 `translateZ` 值，形成 3D 环。

### 3.3 依赖库变更
- 无新增依赖，仅使用 `lucide-react` 图标库和 `tailwind-merge`。

## 5. 风险评估 (Risk Assessment)
- **风险 1**: 复杂布局在移动端表现不佳。
    - **应对**: 对 `hub` 和 `carousel` 布局在移动端自动回退为 `flex-col` 堆叠模式。
- **风险 2**: 样式冲突影响现有卡片。
    - **应对**: 使用特定前缀或 CSS Module 隔离新布局样式，仅在 `layout-mode` 激活时应用。
