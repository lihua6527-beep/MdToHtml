# 实施计划书 (Implementation Plan) - 卡片形态革新

> **版本**: 1.1.0
> **日期**: 2026-02-24
> **分支**: `feature/card-shape`
> **作者**: Trae AI & User
> **来源**: 基于 `卡片.txt` 可行性分析合并

## 1. 需求概述 (Overview)
当前 CHD (Card-based Hybrid Document) 系统以“矩形”为主，视觉表现力单调。为了实现更接近“艺术化排版”或“PPT 风格”的自由度，本计划旨在引入**卡片形态 (Shape)** 维度。

**核心理念**: 将“模块”的“样式”独立出来，通过前端渲染引擎的增强，极大丰富视觉表达力。

## 2. 功能范围 (Scope)

### 2.1 样式家族 (Style Families) - 扩展
| 家族 | 描述 | 技术方案 | 状态 |
| :--- | :--- | :--- | :--- |
| **矩形系 (Rect)** | 基础圆角、直角。 | `border-radius` | 现有 |
| **切角系 (Matrix)** | 赛博朋克风格切角。 | `clip-path: polygon(...)` | **新增** |
| **圆形系 (Circle)** | 正圆、椭圆。 | `border-radius: 50%` | **新增** |
| **箭头系 (Arrow)** | 具有指向性的卡片。 | `clip-path` + 伪元素 | **新增** |
| **有机系 (Organic)** | 不规则流体形状。 | SVG / `border-radius` 复杂参数 | *P2 (暂缓)* |

## 3. 技术方案 (Technical Approach)

### 3.1 架构升级
```text
当前: [解析] -> [IR] -> [渲染(Rect)]
升级: [解析] -> [IR] -> [样式池] -> [渲染]
```

### 3.2 关键实现
1.  **样式池 (Style Pool)**: 在 `globals.css` 中定义原子类 (e.g., `.shape-matrix-sm`, `.shape-arrow-right`)。
2.  **参数透传**: 利用 Markdown 扩展属性 `::card shape="matrix"::` 进行控制。

## 4. 任务分解 (Task Breakdown)

### Phase 1: 样式原子化 (Style Atomization) - 2 Days
- [ ] **S-01**: 移植 `卡片.txt` 中定义的 CSS Clip-path 样式到 Tailwind 插件或 `globals.css`。
- [ ] **S-02**: 更新 `Card` 组件，支持 `variant` 属性映射到新样式。

### Phase 2: 集成与验证 (Integration) - 1 Day
- [ ] **I-01**: 创建 showcase 文档，展示所有形态组合。
- [ ] **I-02**: 移动端适配测试。

## 5. 风险评估
- **内容溢出**: 切角或圆形卡片可能裁剪内容。 -> *对策*: 为特殊形状卡片强制增加 `padding`。
