# 卡片形态革新计划书 (v2.3)

## 1. 核心理念：平等构建与形态自由

- **平等构建 (Equality)**: 现有的“矩形卡片”不再是系统的唯一形态，而是被抽象为基础选项 (`rectangle`)，与未来的新形态（如 `cut` 等）处于同等地位。
- **形态自由 (Shape Freedom)**: 用户可以自由选择卡片形态，不再受限于单一的矩形外观。
- **兜底回退 (Graceful Fallback)**: 系统需具备强大的容错能力。在解析失败、属性缺失或浏览器不支持时，必须自动无缝回退到 `rectangle` 形态。
- **非移动端优先 (Desktop First)**: 本次革新专注于桌面端/宽屏体验。

## 2. 抽象定义 (Abstraction)

### 2.1 卡片形态 (Shape System)

> **属性位置**: 定义在 **三级标题 (H3)** 上 (e.g., `### Title {shape="cut"}`)。

基于 `card_shape_prototype.html` 原型，将卡片的外观封装为 `Shape` 概念。

| 形态名称 | 标识符 (id) | 描述 | 适用场景 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **矩形 (默认)** | `rectangle` | 标准圆角矩形，当前系统的默认形态。 | 通用内容展示 | **兜底形态** |
| **切角形** | `cut` | 具有科技感的切角多边形 (Clip-path)。 | 强调、科技风格 | 原型类名 `.shape-cut` |
| **箭头形** | `arrow` | 首端缩进、尾端突出的指向性形态。 | 流程步骤、时间线 | 原型类名 `.clip-arrow-card` |
| **圆形** | `circle` | 正圆形容器，强制内容居中。 | 图标、徽章、关键数字 | 原型类名 `.shape-circle` |
| **破格悬浮** | `floating` | 矩形卡片 + 右上角悬浮标签 (Badge)。 | 强调核心指标、促销 | 原型类名 `.float-badge` |

## 3. 技术实现路径

### 3.1 接口重构

- **Card Props**: `shape: 'rectangle' | 'cut' | 'arrow' | 'circle' | 'floating'`

### 3.2 样式架构 (CSS Architecture)

- **Shape Utilities**: 
  - 实现 `.shape-cut`, `.clip-arrow-card`, `.shape-circle`。
  - 实现 `.float-badge` (用于 `floating` 形态)。

### 3.3 兜底机制 (Fallback Mechanism)

- **JavaScript 层**:
  - 遇到未知 `shape` -> 回退为 `rectangle`。
- **CSS 层**:
  - 确保所有自定义形状在 CSS 加载失败或容器尺寸不足时，回退到标准的块级流式布局。
