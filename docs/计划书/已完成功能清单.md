    - **启动脚本优化**: 修复 `start.bat` 重复打开浏览器窗口的问题，确保单实例启动。
    - **UI 细节打磨**: 修复底部工具栏分割线双线问题，统一视觉风格。
- [x] **逻辑与状态管理 (Logic & State)**:
    - **状态锁定**: 简化文档状态为 `incomplete` / `completed`。
    - **持久化交互**: 状态切换按钮常驻显示，点击即自动保存并更新 Frontmatter，无需进入编辑模式。
    - [x] **逻辑修正**: 移除了“已完成”状态下编辑自动重置为“未完成”的逻辑，确保状态锁定。
    - [x] **性能架构升级 (Performance Architecture)**:
    - **元数据缓存 (SYS-02)**: 引入 `MetadataCacheManager`，实现 O(1) 复杂度的文档列表加载，解决启动慢问题。
    - **Top 500 限制 (SYS-03)**: 默认缓存最近 500 个文档，超出部分自动归档，保证内存与性能稳定。
    - **状态一致性**: 通过缓存层收束状态管理，彻底修复了“已完成”文档状态回退的 Bug。
    - **乐观更新**: 状态切换按钮引入 Optimistic UI 与 Loading 动画，消除操作延迟感。
