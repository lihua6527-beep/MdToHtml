# 已完成功能清单

## 2026-02-26
- [x] **CHD 评分系统重构 (Scoring System Refactoring)**:
    - **混合评分模型 (Hybrid Model)**: 实施 "静态基准(90) + 动态增量(15) - 严重惩罚" 的评分算法。
        - **基准分**: 基于内容结构、原子性、样式丰富度计算，满分限制为 90 分，留出人工优化空间。
        - **过程分**: 引入 "编辑即增值" 理念，通过 `history.jsonl` 记录，每次有效编辑 +3 分，鼓励人工打磨。
    - **健全性优化 (Robustness)**:
        - **Date 字段解绑**: 移除 Frontmatter 中 `date` 字段的强制检查，符合最新 CHD 协议。
        - **评分兜底**: 即使文档解析失败或内容为空，评分系统仍能返回错误详情与低分，避免界面崩溃，提供明确的错误指引。
    - **前端集成**: 在编辑器顶部评分栏实时展示 "基准分" 与 "过程分"，雷达图支持显示维度详情。
- [x] **文档列表增强 (Document List Enhancements)**:

    - **交互响应修复**: 修复了点击工具栏不触发页面刷新的 Bug，通过重构数据流确保 React 状态与 Markdown 属性实时同步。
    - **保存逻辑修正**: 区分手动保存（关闭编辑器）与自动保存（保持编辑状态），修复输入中断问题。

- [x] **逻辑与状态管理 (Logic & State)**:
    - **状态锁定**: 简化文档状态为 `incomplete` / `completed`。

    - **智能容量监控**: 实现 500 文档上限监控，顶部新增容量进度条 (CapacityProgressBar)，支持 20/50/100/200/500 多档位设置。
    - **自动清理策略**: 当文档数量超限时，自动识别并移出最旧文档至回收站，确保系统轻量化运行。
    - **恢复体验优化**: 恢复操作增加 0.5s 动画延迟，防止 UI 闪烁并确保文件系统索引稳定。
    - **[FIX] 恢复逻辑增强**: 修复了 Windows 下文件系统 Tunneling 导致恢复文件未置顶的问题；修复了列表未及时刷新的 Bug。
- [x] **系统深度审计与重构 (System Audit & Refactoring)**:
    - **架构解耦 (Decoupling)**: 针对 `MarkdownEditor.tsx` 进行“关注点分离”重构，代码量减少 60%+。
        - **数据层**: 抽离 `src/data/editor-defaults.ts` (静态数据) 和 `src/config/editor-menu.ts` (菜单配置)。

        - **样式隔离**: 在 `Section.tsx` 增加强制正则清洗，解决标题显示 `{key=value}` 属性泄漏问题。
