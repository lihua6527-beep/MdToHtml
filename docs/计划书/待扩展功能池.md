## 详细说明 (Details)

### 1. 撤回/重做 (Undo/Redo)
- **目标**: 提供可靠的编辑历史管理，防止误操作。
- **核心机制**: 
  - **快照 (Snapshot)**: 监听卡片内容变化，生成状态快照。
  - **持久化 (Persistence)**: 将操作历史实时写入临时 JSON 文件，确保意外关闭后可恢复（可选）或作为缓冲区。
  - **交互**: 快捷键支持 + 工具栏按钮。
- **状态**: 已完成 (2026-02-23)

### 2. 前端编辑器升级
- **目标**: 提升编辑效率，减少 Markdown 语法记忆负担。
- **特性**:
  - **所见即所得 (WYSIWYG) 增强**: 点击预览区域的卡片即可直接编辑内容。
  - **实时同步**: 编辑时的变化毫秒级同步到预览。
  - **辅助工具**: 插入卡片、调整颜色的快捷菜单。

### 3. 卡片形态与布局抽象
- **目标**: 解决当前 `Card` 组件逻辑耦合过重的问题。
- **方案**: 引入 `CardRegistry` 和 `LayoutEngine`，使新样式的添加只需注册配置，无需修改核心渲染器。

### 4. 新增卡片样式
- **目标**: 增强文档的表现力。
- **待实现样式**:
  - **多边形卡片**: 非矩形边界。
  - **悬浮卡片**: 鼠标 Hover 时浮起/放大。
  - **环形布局**: 卡片呈环状排列。
