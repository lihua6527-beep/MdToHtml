## 详细说明 (Details)

### 1. 拖拽交互与性能优化 (UI-05)
- **目标**: 提升卡片排序体验，解决 Grid 布局下的拖拽难题。
- **特性**:
  - **长按拖拽**: 500ms-800ms 长按触发，避免误触。
  - **渲染暂停**: 拖拽期间暂停 Markdown 解析与 React 重绘，确保 60fps 流畅度。
  - **交互锁**: 防止并发修改导致状态冲突。

### 2. 卡片样式与布局引擎升级 (UI-06)
- **目标**: 解锁 CHD 协议的高级视觉能力，打破矩形卡片与标准 Grid 的限制。
- **参考文档**: 
  - [卡片样式升级](./卡片样式升级/)
  - [卡片布局升级(暂缓)](./卡片布局升级(暂缓)/)
- **任务**:
  - **样式适配**: 引入多边形、玻璃态、悬浮等高级卡片样式。
  - **布局引擎**: 升级 Grid 系统，支持更复杂的布局结构。
  - **兼容性**: 确保新样式与现有 CHD 协议 (v2.3) 的兼容与回退机制。

### 3. 所见即所得编辑器 (ED-07)
- **目标**: 彻底解决 Markdown 源码编辑与渲染割裂的问题。
- **详情**: 请参阅同目录下的 [Markdown编辑器革新计划.md](./Markdown编辑器革新计划.md)。

### 4. 新增卡片样式 (UI-04-B)
- **状态**: 锁定 (Locked v1.6)
- **说明**: 根据 CHD v1.6 协议，目前仅允许矩形卡片与 Grid 布局，复杂样式暂停开发。

### 5. AI 功能集成 (AI-01)
- **状态**: 推迟 (Deferred to Phase 2)
- **说明**: 待核心编辑器稳定后启动。

### 6. CHD协议文档路径管理 (CONFIG-01)
- **状态**: 已完成 (Completed)
- **说明**: 允许用户自定义CHD协议文档的存储路径，同时保证文档名固定为"CHD协议.md"。
- **特性**:
  - 在设置面板中添加CHD协议文档路径配置选项
  - 支持自定义CHD协议文档的存储路径
  - 系统会自动使用配置的路径读取CHD协议文档
  - 如果配置的路径不存在，系统会尝试使用默认路径
  - 在设置界面中添加CHD协议预览功能，方便用户查看和复制协议内容
