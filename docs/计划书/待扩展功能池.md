## 详细说明 (Details)

### 1. 拖拽交互与性能优化 (UI-05)
- **目标**: 提升卡片排序体验，解决 Grid 布局下的拖拽难题。
- **特性**:
  - **长按拖拽**: 500ms-800ms 长按触发，避免误触。
  - **渲染暂停**: 拖拽期间暂停 Markdown 解析与 React 重绘，确保 60fps 流畅度。
  - **交互锁**: 防止并发修改导致状态冲突。

### 2. 系统配置与路径管理 (SYS-01)
- **目标**: 解除硬编码路径限制，提供标准化的输入输出路径选择与管理功能。
- **详情**: 详见 [系统配置与路径管理方案.md](./系统配置与路径管理方案.md)。

### 3. 容量管理与自动清理 (SYS-04)
- **目标**: 提供容量可视化与超限清理策略，确保系统长期运行健康。
- **详情**: 详见 [容量管理与自动清理方案.md](./容量管理与自动清理方案.md)。

### 4. 所见即所得编辑器 (ED-07)
- **目标**: 彻底解决 Markdown 源码编辑与渲染割裂的问题。
- **详情**: 请参阅同目录下的 [Markdown编辑器革新计划.md](./Markdown编辑器革新计划.md)。

### 5. 新增卡片样式 (UI-04-B)
- **状态**: 锁定 (Locked v1.6)
- **说明**: 根据 CHD v1.6 协议，目前仅允许矩形卡片与 Grid 布局，复杂样式暂停开发。

### 6. AI 功能集成 (AI-01)
- **状态**: 推迟 (Deferred to Phase 2)
- **说明**: 待核心编辑器稳定后启动。
