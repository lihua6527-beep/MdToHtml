# 前端实时编辑器设计方案 (Frontend Real-time Editor Design)

## 1. 需求分析与可行性评估

### 1.1 核心需求
用户希望构建一个实时交互的前端界面，布局如下：
- **左侧**: 用于文档编辑、纠错、修改。
- **右侧**: 实时渲染预览。
- **核心交互**: 双向滚动同步、点击定位、实时校验。

### 1.2 可行性分析 (Feasibility)
**结论：高度可行，且已完成 V1.0 核心功能交付。**

- **技术栈支持**: Next.js + React 18 完美支持组件动态渲染。
- **架构契合**: `CHDRenderer` 已成功解耦，支持从 State 注入 Markdown 内容。
- **价值提升**: 实时预览极大降低了 CHD 协议的学习门槛。

## 2. 界面布局设计 (UI Layout Design)

### 2.1 V1.0 已实现布局 (Implemented Layout)
采用 **左右分栏 (Split View)** 模式：

```
+---------------------+-------------------------+
|      Editor (50%)   |      Preview (50%)      |
|---------------------|-------------------------|
|  [Toolbar]          |  [Preview Header]       |
|  - File Info        |  - Live Status          |
|  - Actions          |                         |
|                     |                         |
|  # Markdown         |  +-------------------+  |
|                     |  |  (Rendered UI)    |  |
|  ## Section         |  |      v1.0         |  |
|                     |  |    Section        |  |
|  ### Card 1         |  | [ Card 1 ]        |  |
|  Content...         |  |                   |  |
|                     |  +-------------------+  |
|  [Problems Panel]   |                         |
+---------------------+-------------------------+
```

### 2.2 区域功能定义

#### 左侧：Markdown 编辑器
- **组件**: `MarkdownEditor.tsx` (基于 HTML TextArea + Custom Enhancements)。
- **特性**:
  - **受控模式**: 通过 `value`/`onChange` 与父组件通信。
  - **命令系统**: 支持 `/` 唤出组件菜单。
  - **行级映射**: 实时计算光标所在行，并通过 `onCursorChange` 上报。
  - **暴露接口**: 通过 `useImperativeHandle` 暴露 `scrollToLine` 方法，支持外部驱动滚动。

#### 右侧：实时渲染器
- **组件**: `CHDRenderer.tsx`。
- **特性**:
  - **Memoization**: 使用 `useMemo` 缓存解析结果，优化性能。
  - **交互增强**: 卡片组件支持 `onClick` 事件，回传所在行号。
  - **视觉反馈**: 接收 `activeLine` 属性，自动高亮当前编辑的卡片。

## 3. 核心交互逻辑 (Core Interaction Logic)

### 3.1 双向滚动同步 (Bidirectional Scroll Sync)

#### Editor -> Preview
- **算法**: 百分比映射 (Percentage-based)。
- **逻辑**: `Preview.scrollTop = (Editor.scrollTop / Editor.maxScroll) * Preview.maxScroll`。
- **触发**: 监听 Editor 的 `onScroll` 事件。

#### Preview -> Editor (Click-to-Locate)
- **算法**: 行号精确定位 (Line-based)。
- **逻辑**: 用户点击 Preview 卡片 -> 获取 `startLine` -> 调用 `Editor.scrollToLine(startLine)`。
- **实现**: 使用 `forwardRef` 穿透组件边界，直接操作 TextArea DOM。

### 3.2 实时校验 (Real-time Validation)
- **引擎**: `src/lib/validator.ts`。
- **规则**:
  - 检查孤立的 L3 卡片 (Orphaned Cards)。
  - 检查属性语法 (Attribute Syntax)。
  - 检查标题层级 (Header Hierarchy)。
- **展示**: 编辑器底部 "Problems" 面板实时显示错误与警告。
