# 设计系统规范 (Design System)

## 1. 色彩系统 (Color System)
本项目采用**莫兰迪配色 (Morandi Colors)**，使用 CSS HSL 变量定义，支持动态主题切换。

### 1.1 核心色板
```css
:root {
  /* 主色调 - 沉稳的蓝灰色 */
  --primary: 210 20% 40%;
  --primary-light: 210 30% 90%;
  
  /* 辅助色 - 柔和的陶土色 */
  --accent: 15 30% 60%;
  
  /* 背景色 - 暖灰 */
  --background: 40 10% 98%;
  --surface: 0 0% 100%;
  
  /* 文本色 */
  --text-main: 210 10% 20%;
  --text-secondary: 210 10% 40%;
}
```

## 2. 排版系统 (Typography)
### 2.1 字体栈
- **中文字体**: `PingFang SC`, `Microsoft YaHei`, `sans-serif`
- **英文字体**: `Inter`, `Segoe UI`, `Roboto`, `sans-serif`
- **代码字体**: `Fira Code`, `Consolas`, `monospace`

### 2.2 字号阶梯
- **H1**: 2.5rem (40px) - 页面主标题
- **H2**: 2.0rem (32px) - 章节标题
- **H3**: 1.5rem (24px) - 卡片标题
- **Body**: 1.0rem (16px) - 正文阅读

## 3. 组件规范 (Component Tokens)
### 3.1 卡片 (Card)
- **圆角**: `border-radius: 12px`
- **阴影**: `box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1)`
- **内边距**: `padding: 24px`

### 3.2 按钮 (Button)
- **垂直居中**: 必须使用 Flexbox 布局
  ```css
  .btn {
    display: flex;
    align-items: center;
    justify-content: center;
    height: 40px;
  }
  ```
- **交互**: Hover 时亮度提升 5% (`filter: brightness(1.05)`)

## 4. 布局系统
- **栅格**: 12 列栅格系统
- **间距**: 8px 倍数原则 (8, 16, 24, 32, 48, 64)
