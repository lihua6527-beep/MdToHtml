# 卡片形态与布局革新计划书 (v2.3)

## 1. 核心理念：平等构建与兜底回退

- **平等构建 (Equality)**: 现有的“矩形卡片”和“并列布局”不再是系统的唯一形态，而是被抽象为基础选项 (`rectangle` 和 `parallel`)，与未来的新形态（如 `cut`, `hub` 等）处于同等地位。
- **布局约束形态 (Layout Constraints)**: 不同的布局模式对卡片形态有不同的约束。仅 **并列布局 (Parallel)** 支持自由选择所有卡片形态；其他布局（如 Hub, Ring, Timeline）为确保视觉一致性，将强制使用特定的卡片形态。
- **兜底回退 (Graceful Fallback)**: 系统需具备强大的容错能力。在解析失败、属性缺失、浏览器不支持或脚本错误的“最差情况”下，必须自动无缝回退到 `rectangle` + `parallel` 组合。
- **非移动端优先 (Desktop First)**: 本次革新专注于桌面端/宽屏体验。

## 2. 抽象定义 (Abstraction)

### 2.1 卡片形态 (Shape System)

> **属性位置**: 定义在 **三级标题 (H3)** 上 (e.g., `### Title {shape="cut"}`)。

基于 `card_shape_prototype.html` 原型，将卡片的外观封装为 `Shape` 概念。

| 形态名称 | 标识符 (id) | 描述 | 适用场景 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **矩形 (默认)** | `rectangle` | 标准圆角矩形，当前系统的默认形态。 | 通用内容展示 | **兜底形态** |
| **切角形** | `cut` | 具有科技感的切角多边形 (Clip-path)。 | 强调、科技风格 | 原型类名 `.shape-cut` |
| **箭头形** | `arrow` | 首端缩进、尾端突出的指向性形态。 | 流程步骤、时间线 | 原型类名 `.clip-arrow-card` |
| **圆形** | `circle` | 正圆形容器，强制内容居中。 | 图标、徽章、关键数字 | 原型类名 `.shape-circle` |
| **破格悬浮** | `floating` | 矩形卡片 + 右上角悬浮标签 (Badge)。 | 强调核心指标、促销 | 原型类名 `.float-badge` |

### 2.2 布局模式 (Layout System)

> **属性位置**: 定义在 **二级标题 (H2)** 上 (e.g., `## Section {layout="hub"}`)。
> **作用范围**: 决定该 H2 下属的所有 H3 卡片的排列方式及形态约束。

基于 `card_shape_prototype.html` 原型，将卡片的排列方式封装为 `LayoutMode` 概念。

| 布局名称 | 标识符 (id) | 描述 | 形态约束 (Constraint) | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **并列 (默认)** | `parallel` | 基于 12 列网格的流式排布。 | **自由选择 (Any)** <br> (支持所有 Shape) | **兜底布局** |
| **动态环形** | `hub` | "卫星系统"，中心为核心主题，周围环绕子卡片。 | **固定 (Fixed)** <br> (强制为圆形/卫星样式) | H3 内容为卫星节点 |
| **箭头环形** | `ring` | 箭头形态的卡片首尾相接，形成闭环流程。 | **固定 (Fixed)** <br> (强制为箭头扇区) | H3 内容为步骤节点 |
| **交错轴线** | `timeline` | 轴线优先，节点顺序排列于中轴线，内容上下交错。 | **固定 (Fixed)** <br> (强制为时间轴节点) | H3 内容为时间节点 |

## 3. 技术实现路径

### 3.1 接口重构与约束逻辑

- **Card Props**: `shape: 'rectangle' | 'cut' | 'arrow' | 'circle' | 'floating'`
- **Section Props**: `layoutMode: 'parallel' | 'hub' | 'ring' | 'timeline'`
- **约束矩阵 (Constraint Matrix)**:
  ```typescript
  // 伪代码逻辑
  function resolveShape(layoutMode, userShape) {
    if (layoutMode === 'parallel') {
      return userShape || 'rectangle'; // 自由选择
    }
    // 其他布局强制覆盖 Shape
    if (layoutMode === 'hub') return 'satellite'; // 内部专用形态
    if (layoutMode === 'ring') return 'arrow-segment'; // 内部专用形态
    if (layoutMode === 'timeline') return 'timeline-node'; // 内部专用形态
    
    return 'rectangle';
  }
  ```

### 3.2 样式架构 (CSS Architecture)

- **Shape Utilities**: 
  - 实现 `.shape-cut`, `.clip-arrow-card`, `.shape-circle`。
  - 实现 `.float-badge` (用于 `floating` 形态)。
- **Layout Patterns**:
  - **Hub**: 绝对定位计算 (top/left 50%) + transform 偏移。
  - **Ring**: SVG 路径或高级 CSS 变换。
  - **Timeline**: Flex/Grid 布局配合 `nth-child` 选择器实现上下交错。

### 3.3 兜底机制 (Fallback Mechanism)

- **JavaScript 层**:
  - 遇到未知 `layoutMode` -> 回退为 `parallel`。
  - 遇到未知 `shape` (在 parallel 模式下) -> 回退为 `rectangle`。
- **CSS 层**:
  - 确保所有自定义形状和布局在 CSS 加载失败或容器尺寸不足时，回退到标准的块级流式布局。
