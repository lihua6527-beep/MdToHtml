# 卡片形态与布局革新执行清单

本文档旨在明确“卡片形态”与“布局模式”的实现位置、约束规则及属性定义的具体层级。

## 1. 核心改动位置与层级

| 概念 (Concept) | 属性 (Prop) | 定义位置 (Definition Scope) | 作用对象 (Target) | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **布局模式 (Layout)** | `layout="{mode}"` | **二级标题 (H2)** | 该 H2 下的所有 H3 卡片 | 决定子卡片的排列方式及**强制样式**。 |
| **卡片形态 (Shape)** | `shape="{type}"` | **三级标题 (H3)** | 当前 H3 卡片本身 | 定义单个卡片的视觉外观（仅在允许的布局中生效）。 |

### 示例代码结构

```markdown
## 核心特性 {layout="parallel"}
<!-- 这里的 layout="parallel" 决定了下方的卡片将以网格并列排布 -->

### 极速渲染 {shape="cut"}
<!-- 这里的 shape="cut" 决定了这个卡片是切角形态 -->
采用 Rust 编写的核心引擎...

### 智能纠错 {shape="floating"}
<!-- 这里的 shape="floating" 决定了这个卡片带有悬浮标签 -->
自动识别 Markdown 语法错误...
```

## 2. 布局与形态约束矩阵 (Constraint Matrix)

**核心规则**：只有 `parallel` 布局允许自由选择 `shape`。其他布局为保证复杂的视觉结构（如环形、时间轴），必须强制覆盖子卡片的形态。

| 布局模式 (H2 Layout) | 允许的卡片形态 (H3 Shape) | 行为说明 |
| :--- | :--- | :--- |
| **并列 (Parallel)** | **全部 (Any)** <br> (`rectangle`, `cut`, `arrow`, `circle`, `floating`) | **自由模式**。卡片按照定义的 `shape` 渲染。未定义则默认为 `rectangle`。 |
| **动态环形 (Hub)** | <span style="color:red">**不可选 (Fixed)**</span> <br> (强制为 `satellite`) | **强制模式**。无论 H3 定义什么 `shape`，都会被忽略，强制渲染为“卫星节点”样式（通常是圆形或图标）。 |
| **箭头环形 (Ring)** | <span style="color:red">**不可选 (Fixed)**</span> <br> (强制为 `arrow-segment`) | **强制模式**。强制渲染为“箭头扇区”样式，以拼接成闭环。 |
| **交错轴线 (Timeline)** | <span style="color:red">**不可选 (Fixed)**</span> <br> (强制为 `timeline-node`) | **强制模式**。强制渲染为“时间轴节点”样式，以适应中轴线排布。 |

### 3.2 代码实现逻辑 (Implementation Logic)

#### A. 解析器层 (Parser)
1.  **提取 H2 属性**: 解析 `## Title {layout="..."}`，将 `layout` 存入 Section 对象。
2.  **提取 H3 属性**: 解析 `### Title {shape="..."}`，将 `shape` 存入 Card 对象。

#### B. 渲染层 (Renderer - React Component)
1.  **Section 组件**:
    - 读取 `layout` 属性。
    - 如果 `layout === 'hub' | 'ring' | 'timeline'`，则向子组件传递一个特殊的标识（或直接使用专门的子组件渲染器），**忽略**子组件原本的 `shape` 属性。
    - 如果 `layout === 'parallel'` (默认)，则按常规 Grid 渲染，并允许子组件读取自己的 `shape` 属性。

2.  **Card 组件**:
    - 接收 `shape` 属性。
    - 根据 `shape` 渲染对应的 CSS 类名 (e.g., `.shape-cut`, `.float-badge`)。
    - **破格悬浮 (Floating)** 实现：
      - 渲染标准卡片结构。
      - 额外渲染一个绝对定位的 `.float-badge` 元素（内容可来源于 H3 的元数据或约定）。
