# 编辑器风格分析与重构指南 (v1.0)

## 1. 核心设计语言 (Design Language)

基于 `globals.css`, `Card.tsx`, `Section.tsx` 的代码分析，当前编辑器采用 **"Clean & Soft"** (洁净与柔和) 的设计风格。

### 1.1 色彩系统 (Color System)
*   **基调**: 大量使用白色 (`bg-white` / `bg-bg-card`) 与极淡的灰色/蓝色 (`bg-bg-page`)。
*   **卡片颜色**: 严禁使用高饱和度背景。所有彩色卡片均采用 **透明度叠加** 模式：
    *   `chart-1`: `bg-chart-1/10 border-chart-1/20`
    *   `chart-2`: `bg-chart-2/10 border-chart-2/20`
*   **边框**: 默认使用 `border-border-soft` (极浅灰)，Hover 时加深为 `border-primary/50`。
*   **状态色**:
    *   **Primary (主色)**: `text-primary` (深蓝/黑), `bg-primary` (按钮激活)。
    *   **Active (激活)**: `ring-2 ring-primary ring-offset-2`。
    *   **Selected (选中)**: `ring-2 ring-secondary ring-offset-2`。

### 1.2 几何与阴影 (Geometry & Depth)
*   **圆角 (Radius)**:
    *   卡片: `rounded-card` (0.75rem / 12px)。
    *   面板: `rounded-xl` (12px)。
    *   按钮: `rounded-md` (6px) 或 `rounded-full` (选项)。
*   **阴影 (Shadow)**:
    *   默认: `shadow-sm`。
    *   Hover: `hover:shadow-card` (Card), `hover:shadow-md` (Panel)。

### 1.3 交互动效 (Motion)
*   **卡片 Hover**: `transform scale-[1.02]` (仅 Active 非 Selected), `transition-all duration-300`。
*   **面板进场**: `animate-in slide-in-from-top-2`。

## 2. 组件原子规范 (Component Atoms)

### 2.1 工具栏按钮 (Toolbar Button)
*   **尺寸**: `w-8 h-8` (32px x 32px)。
*   **结构**: Flex center (`flex items-center justify-center`)。
*   **状态**:
    *   **Default**: `bg-bg-card border border-border-soft text-text-secondary`。
    *   **Hover**: `hover:text-primary hover:border-primary/50 hover:bg-primary/5`。
    *   **Active**: `bg-primary text-white border-primary`。
*   **图标**: Lucide Icons, size 16px or 18px。

### 2.2 设置面板 / 上下文菜单 (Context Panel)
*   **容器**: `p-4 bg-bg-card border border-border-soft rounded-xl shadow-sm`。
*   **内部间距**: `gap-4` (行间距), `gap-2` (元素间距)。
*   **标签**: `text-sm text-text-secondary` (左侧 Label), `text-xs text-text-muted` (辅助 Label)。
*   **选项按钮**:
    *   文本类: `px-2 py-1 text-xs bg-bg-page border border-border-soft rounded`。
    *   颜色类: `w-6 h-6 rounded-full border`。

### 2.3 卡片 (Card)
*   **容器**: `bg-white shadow-sm border border-border-soft`。
*   **内容**:
    *   Title: `text-2xl font-bold tracking-tight` (Default)。
    *   Content: `text-base text-text-secondary`。

## 3. 重构预览图的具体要求 (Action Items)

为生成的 `context_aware_editor_preview.html` 必须严格遵循以下规则：

1.  **移除** 所有深色背景或高饱和度色块。
2.  **引入** Lucide 图标库（通过 CDN）。
3.  **复刻** `Section.tsx` 中的 "Settings Panel" 作为新的 "Context Menu"：
    *   使用白色背景、圆角边框、微阴影。
    *   内部使用 32px 的图标按钮或小胶囊按钮。
4.  **模拟** 真实的选中效果：
    *   使用 `ring-2 ring-primary ring-offset-2` 替代简单的边框变色。
5.  **布局一致性**:
    *   Section Header 左侧是标题，右侧是 32px 的图标按钮组。

此文档将作为后续 UI 开发的唯一真理来源。
