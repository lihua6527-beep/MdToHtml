## 二、详细设计

### 2.1 需求 1：删除评分系统

**现状**：`NavigationHeader.tsx` 第 78-82 行引用了 `ScoreIndicator` 组件，`InteractivePost.tsx` 中有 `scoreResult`、`showScoreDetails` 状态和相关逻辑。

**修改方案**：
- `NavigationHeader.tsx`：删除 `<ScoreIndicator>` 组件的导入和渲染
- `InteractivePost.tsx`：删除 `scoreResult`、`showScoreDetails`、`setShowScoreDetails` 相关状态和传入 NavigationHeader 的 props
- `ScoreIndicator.tsx`：文件保留不动（可能其他地方引用），但不再在 NavigationHeader 中使用

### 2.2 需求 2：删除绿色连接圆点

**现状**：`AIArea.tsx` 第 190-193 行显示了一个绿色圆点和"已连接"文字。

```tsx
<span className="flex items-center gap-1">
  <span className="w-1.5 h-1.5 bg-green-500 rounded-full inline-block" />
  <span className="text-[10px] text-green-600 hidden sm:inline">已连接</span>
</span>
```

**修改方案**：
- 删除上述 `<span>` 块

### 2.3 需求 3：右键菜单 — 收藏 + 置顶 + 简化删除

**现状**：`DocumentList.tsx` 中的右键菜单有三个选项（仅删除源文件、删除源文件与输出），缺少收藏和置顶功能。

**修改方案**：

#### 3-a. 数据结构扩展
在 `types/file-system.ts` 的 `FileItem` 类型中新增字段：
```ts
export interface FileItem {
  slug: string;
  mtime: number;
  birthtime?: number;
  status?: 'active' | 'deleted' | 'archived' | 'pending' | 'incomplete' | 'modified' | 'done' | 'completed';
  title?: string;
  tags?: string[];
  excerpt?: string;
  // === 新增 ===
  isPinned?: boolean;     // 是否置顶
  isFavorited?: boolean;  // 是否收藏
  pinOrder?: number;      // 置顶排序（最后置顶的数值最大）
  // ===========
}
```

#### 3-b. 存储方式
使用 `localStorage` 存储置顶和收藏状态，键名：
- `pinned_docs`: `Record<string, number>` (slug → pinOrder)
- `favorited_docs`: `string[]` (slugs)

#### 3-c. 文档排序逻辑
在 `DocumentList.tsx` 的排序 `useMemo` 中：
1. 先按 `isPinned` 筛选，所有置顶文档排在最前面
2. 置顶文档按 `pinOrder` 降序（最后置顶的排最上面）
3. 非置顶文档按原有排序规则

#### 3-d. 右键菜单重构
`DocumentList.tsx` 中右键菜单从 3 个按钮改为 3 个按钮：
1. ⭐ 收藏 / 取消收藏（根据当前状态显示"收藏"或"取消收藏"）
2. 📌 置顶 / 取消置顶（根据当前状态显示）
3. 🗑️ 删除（进入回收站）

删除原"仅删除源文件"和"删除源文件与输出"两个独立选项，合并为一个"删除"。

#### 3-e. DocumentItem 显示
- 被收藏的文档在标题旁显示小黄星 ⭐
- 被置顶的文档在标题旁显示置顶图标 📌

### 2.4 需求 4：删除 ✕ 按钮

**现状**：`AIArea.tsx` 第 194 行有 `✕` 按钮：
```tsx
{onClose && <button onClick={handleExit} className="text-text-muted hover:text-text-primary text-sm px-1" title="关闭">✕</button>}
```

**修改方案**：删除此行。

该按钮位于"经典模式"按钮左侧，用户认为它多余（经典模式和在线模式之间不需要这个关闭按钮）。

### 2.5 需求 5：切换经典模式按钮更显眼

**现状**：`AIArea.tsx` 第 195 行的"经典模式"按钮样式不够突出：
```tsx
{onClose && <button onClick={onClose} className="flex items-center gap-1 px-2 py-1 text-[11px] font-medium text-indigo-600 bg-indigo-50 rounded-md hover:bg-indigo-100 transition-colors" title="经典模式 - 拖拽上传 Markdown">📄 经典模式</button>}
```

**修改方案**：加大字体、加深背景色、添加图标动画或更明显的主色调。
```tsx
// 修改后
{onClose && (
  <button
    onClick={onClose}
    className="flex items-center gap-1.5 px-3 py-1.5 text-xs font-bold text-indigo-700 bg-indigo-100 rounded-lg hover:bg-indigo-200 hover:shadow-sm transition-all border border-indigo-200"
    title="经典模式 - 拖拽上传 Markdown"
  >
    📄 经典模式
  </button>
)}
```

### 2.6 需求 6：左右两侧背景色统一

**现状**：左侧文档列表背景为 `bg-bg-card`（白色），右侧主内容区为 `bg-bg-page`（浅色），当主题不同时两侧色调不一致。

**修改方案**：
- `HomeClient.tsx`：主容器 `bg-bg-page` 保持不变
- 左侧 `DocumentList` 容器当前使用 `bg-bg-card`，改为与右侧一致：
  - `DocumentList.tsx` 第 360 行：`bg-bg-card` → `bg-transparent`（继承父容器）
  - 或者统一设置为 `bg-bg-page`
- 确保左右两侧使用相同的背景色变量

### 2.7 需求 7：右侧字体和布局舒展

**现状**：
- `AIArea.tsx` 中字体偏小（`text-[11px]`、`text-[10px]`）
- 布局紧凑，元素之间的间距较小
- 右侧内容区 `p-8` 在宽屏下合适，但内部元素间缺乏呼吸感

**修改方案**：
- 增大 AIArea 顶部状态栏字体：`text-[11px]` → `text-xs`
- 增大模型选择下拉框内边距
- 增加各区域间的间距（`gap-2` → `gap-3`、`mb-3` → `mb-4`）
- 保持现有功能不变，仅调整 padding/margin/font-size
- 注意不要过度留白

### 2.8 需求 8：定期清理孤儿 HTML 文件

**现状**：编译生成的 HTML 输出文件在文档被删除后不会自动清理，长期积累可能导致内存泄漏（磁盘占用）。

**修改方案**：
- 新建 `services/CleanupService.ts`
- 实现逻辑：
  1. 每次应用启动时运行一次清理
  2. 扫描输出目录中的所有 `.html` 文件
  3. 获取当前文档列表中的所有 slug
  4. 如果 `.html` 文件名对应的 slug 不在文档列表中，则删除
  5. 同时配置一个定时器（如每 30 分钟检查一次）

- 在 `HomeClient.tsx` 的 `useEffect` 中初始化清理服务
