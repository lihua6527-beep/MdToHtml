# Plan 06: 编辑器内 AI 内联辅助编辑

> **简要说明**：在编辑器中增加 AI 内联辅助编辑能力，让用户选中文本后可执行"润色""扩充""转卡片""总结"等操作。复用现有的 `AIService` 和 `PromptEngine` 基础设施，新增 UI 交互层和特定 Prompt 模板。与首页"文件级"AI 转换形成互补，覆盖"编辑过程中"的 AI 辅助场景。

---

## 1. 现状分析

### 1.1 当前 AI 能力的分布

| 位置 | 功能 | 交互方式 | 局限 |
|------|------|---------|------|
| 首页 AIArea | 文件 → CHD 转换 | 选择文件 → 生成 → 保存 | 只能处理完整文件，不能编辑已有内容 |
| 首页 AIArea | 更换风格 | 点击按钮 | 重新生成全部，无法局部修改 |

**缺失场景**：用户在编辑器中已经写了一段文字，希望 AI 帮助：
- 润色语言表达
- 将一段自由文本转为 CHD 卡片格式
- 基于当前内容继续扩充
- 总结当前 Section 的主要内容

### 1.2 可复用的基础设施

| 资源 | 文件 | 状态 |
|------|------|------|
| DeepSeek API 调用 | `services/ai/AIService.ts` | ✅ 有退避重试和错误处理 |
| Prompt 模板引擎 | `services/ai/PromptEngine.ts` | ✅ 已有默认/学术双模板 |
| API Key 管理 | `lib/env-hot-loader.ts` | ✅ 零 I/O 热加载 |
| CodeMirror 编辑器实例 | `components/Editor/CodeMirrorEditor.tsx` | ✅ 已有 `getSelection()` API |
| 文本插入能力 | `editor/page.tsx` 的 `insertMarkdown()` | ✅ 已有 |

## 2. 设计方案

### 2.1 总体方案

```
用户在编辑器中选中一段文本
    ↓
弹出 AI 辅助浮层（4 种操作可选）
    │
    ├── 「润色」 → 改进语法和表达
    ├── 「扩充」 → 基于选中文本展开论述
    ├── 「转卡片」 → 转为 CHD 卡片格式（### Card {card-style="..."}）
    └── 「总结」 → 为选中的 Section 生成摘要
    ↓
调用 AIService.generate() + 特定 Prompt
    ↓
结果以"建议替换"的 diff 形式展示
    ↓
用户确认 → 替换原文 | 拒绝 → 关闭浮层
```

### 2.2 UI 设计

#### 触发方式：选中文本后浮现操作按钮


### 2.3 核心交互流程

```typescript
// 编辑器页面新增状态
const [aiInlineState, setAIInlineState] = useState<{
  visible: boolean;
  selectedText: string;
  position: { top: number; left: number };
}>({ visible: false, selectedText: '', position: { top: 0, left: 0 } });
const [aiResult, setAIResult] = useState<{
  visible: boolean;
  original: string;
  suggested: string;
  action: AIActionType;
}>({ visible: false, original: '', suggested: '', action: 'polish' });

// 监听编辑器选中事件
const handleSelectionChange = useCallback((selection: string, rect: DOMRect) => {
  if (selection && selection.length > 10) { // 至少 10 个字符才触发
    setAIInlineState({
      visible: true,
      selectedText: selection,
      position: { top: rect.top - 50, left: rect.left }
    });
  } else {
    setAIInlineState({ visible: false, selectedText: '', position: { top: 0, left: 0 } });
  }
}, []);

// 执行 AI 操作
const handleAIAction = async (action: AIActionType) => {
  setAIInlineState({ ...aiInlineState, visible: false });
  
  // 构建 Prompt
  const promptTemplates: Record<AIActionType, string> = {
    polish: `请润色以下文本，改进语法和表达，保持原意不变：\n\n${aiInlineState.selectedText}`,
    expand: `请基于以下内容展开论述，增加细节和例证，保持文风一致：\n\n${aiInlineState.selectedText}`,
    'to-card': `请将以下文本转换为 CHD 卡片格式，使用 ### Card {card-style="normal"} 标记：\n\n${aiInlineState.selectedText}`,
    summarize: `请为以下内容生成一段简洁的摘要（50字以内）：\n\n${aiInlineState.selectedText}`,
  };
  
  try {
    const response = await AIService.generate({
      prompt: promptTemplates[action],
      model: 'flash', // 快速模型，实时性优先
      systemPrompt: '你是一个文档编辑助手，直接返回处理后的文本，不要添加额外解释。'
    });
    
    setAIResult({
      visible: true,
      original: aiInlineState.selectedText,
      suggested: response.content,
      action,
    });
  } catch (err) {
    console.error('AI inline action failed:', err);
    // 简单提示，不阻塞编辑
    alert('AI 辅助请求失败，请检查 API Key 和网络连接。');
  }
};

// 接受建议
const handleAcceptSuggestion = () => {
  // 替换编辑器中的选中文本
  if (editorRef.current) {
    editorRef.current.replaceSelection(aiResult.suggested);
  }
  setAIResult({ ...aiResult, visible: false });
};
```

### 2.4 Prompt 模板详细设计

#### 润色（Polish）

```
你是一个中文文档润色助手。请对以下文本进行润色：
1. 修正语法错误和不当用词
2. 改善句式结构，使表达更流畅
3. 保持原文风格和语气
4. 不改变原意，不增加新内容
5. 直接返回润色后的文本，不要添加任何解释

文本内容：
{selectedText}
```

#### 扩充（Expand）

```
你是一个文档写作助手。请基于以下文本内容进行扩充：
1. 增加相关的解释、例证或细节
2. 保持文风一致
3. 扩充后篇幅约为原文的 2-3 倍
4. 保持逻辑连贯
5. 直接返回扩充后的文本，不要添加任何解释

原文内容：
{selectedText}
```

#### 转卡片（To Card）

```
你是一个 CHD 格式转换助手。请将以下自由文本转换为 CHD 卡片格式：
1. 每张卡片使用 ### Card {card-style="normal|highlight"} 标记
2. 将内容合理分拆为多张卡片
3. 关键观点使用 highlight 样式
4. 保持原有的技术准确性
5. 直接返回转换后的 Markdown，不要添加任何解释

文本内容：
{selectedText}
```

#### 总结（Summarize）

```
你是一个文档摘要助手。请为以下内容生成摘要：
1. 摘要不超过 50 字
2. 提取核心观点
3. 使用简洁的陈述句
4. 直接返回摘要文本，不要添加任何解释

文本内容：
{selectedText}
```

### 2.6 安全与异常处理

| 场景 | 处理方式 |
|------|---------|
| 未配置 API Key | 浮动工具栏显示"请先配置 API Key"提示，所有操作不可点击 |
| AI 请求超时 | 显示"请求超时，请重试"，不影响编辑器内容 |
| AI 返回空内容 | 显示"AI 未返回有效内容，请重试" |
| 网络断开 | 检测到网络错误时，显示"网络连接异常，请检查网络" |
| 选中文本过长 | 设定 2000 字符上限，超出时自动截断并提示"仅处理前 2000 字符" |

### 2.7 与首页 AI 功能的职责划分

| 场景 | 首页 AI (AIArea) | 编辑器内 AI (本计划) |
|------|-----------------|---------------------|
| 输入 | 完整文件（.txt/.md/.docx） | 选中的文本片段 |
| 输出 | 完整 CHD 文档 + 保存到 posts | 替换选中区域 |
| 模板 | 文件级 Prompt A/B | 段落级 Prompt（4 种操作） |
| 生成后 | 预览/下载/保存/对比 | 建议替换/拒绝 |
| 定位 | 批量转换、文档生成 | 编辑过程中的辅助写作 |

两者互补，不冲突。

## 6. 未来扩展

- **实时建议模式**：不等待用户选中，在输入停顿 3 秒后自动建议下一句
- **自定义 Prompt**：允许用户输入自己的 Prompt 模板
- **多次迭代**：对 AI 结果不满意时，可以继续对话调整
- **批注模式**：AI 建议以批注形式显示在右侧，而非立即替换
