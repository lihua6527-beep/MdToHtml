## 一、功能一：系统设置中的 API 密钥管理面板

### 1.1 现状

当前 `SettingsPanel.tsx` 中已有 `settingsType='ai'` 面板，但：
- API Key 输入框是 **disabled** 的，仅展示占位文字"已配置（不可在此修改）"
- 提示文字写的是"请在项目根目录的 .env.local 文件中设置"
- 没有引导用户如何获取 API Key
- 没有说明 API Key 的保密策略

### 1.2 目标

将 AI 设置面板完善为**完整的 API 密钥管理入口**，包含：

#### ① API Key 输入与保存

支持用户直接在设置面板中输入 API Key 并保存到 `.env.local`（通过后端 API 写入），流程如下：

```
用户打开设置 → AI 配置面板
    ↓
输入 API Key（明文显示，但用密码输入框保护）
    ↓
点击「保存配置」
    ↓  POST /api/ai/config/save
服务端写入 .env.local
    ↓
重新加载环境变量
    ↓
显示「✅ 配置已保存」
```

**需要新增的 API**：

```typescript
// POST /api/ai/config/save
// 请求体: { apiKey: string }
// 响应: { success: boolean }
// 
// 实现方式：
// 1. 接收前端传来的 API Key
// 2. 写入服务端 .env.local 文件
// 3. 返回成功状态
```

> ⚠️ **安全考虑**：.env.local 中的 API Key 仅在服务端 API Route 中使用，不会暴露到前端。前端传 Key 到 `/api/ai/config/save` 后，服务端写入文件，后续调用不再需要前端传 Key。

#### ② API 密钥获取引导

在 API Key 输入框下方，增加一个完整的引导区域：

```
┌─────────────────────────────────────────────┐
│  🔑 如何获取 DeepSeek API Key               │
│                                              │
│  ① 访问 DeepSeek 开放平台                    │
│     🔗 https://platform.deepseek.com/        │
│                                              │
│  ② 注册/登录账号                             │
│                                              │
│  ③ 进入「API Keys」页面 →「创建 API Key」    │
│                                              │
│  ④ 复制密钥（以 sk- 开头）粘贴到上方输入框    │
│                                              │
│  [🌐 前往 DeepSeek 开放平台]                  │
└─────────────────────────────────────────────┘
```

- 链接按钮：`<a href="https://platform.deepseek.com/" target="_blank">`，点击在新标签页打开
- 步骤说明使用清晰的编号列表

#### ③ 保密策略提示

在面板底部增加一个醒目的保密提示区域：

```
┌─────────────────────────────────────────────┐
│  🔒 安全说明                                 │
│                                              │
│  ✅ 加密传输：API Key 通过 HTTPS 加密传输      │
│  ✅ 服务端存储：仅保存在 .env.local，不暴露    │
│  ✅ 前端不可读：浏览器无法直接获取 Key         │
│  ❌ 不要分享：请勿将 Key 分享给他人            │
│  ❌ 不要提交：.env.local 已加入 .gitignore     │
│                                              │
│  如有泄露，请立即在 DeepSeek 平台吊销 Key      │
└─────────────────────────────────────────────┘
```

### 1.3 需要修改的文件

| 文件 | 修改类型 | 说明 |
|------|----------|------|
| `src/components/SettingsPanel.tsx` | 修改 | 替换 AI 面板为完整版（启用输入框+引导+保密说明） |
| `src/app/api/ai/config/save/route.ts` | 新增 | 接收 API Key 并写入 .env.local |

### 1.4 需要注意的边界情况

- .env.local 中已有 `PORT=3001` 行，写入时需要**追加**而非覆盖
- 如果写入失败，需提示用户手动配置并给出 .env.local 路径
- 保存后需让 `process.env.DEEPSEEK_API_KEY` 生效（可能需要重启服务，或通过 `dotenv` 重新加载）

## 三、功能三：删除 AI 页面中的齿轮设置图标

### 3.1 现状

`AIArea.tsx` 顶部状态栏右侧有 ⚙️ 齿轮按钮：

```tsx
{onOpenSettings && (
  <button onClick={onOpenSettings} title="AI 设置">⚙️</button>
)}
```

该按钮调用 `onOpenSettings` → 打开 `SettingsPanel` 的 `'ai'` 类型。

### 3.2 目标

**删除**这个齿轮按钮。AI 配置统一归入**系统设置的侧边栏**（从左侧 DocumentList 底部的「设置」按钮进入）。

#### 原因

| 理由 | 说明 |
|------|------|
| 功能重复 | 左侧系统设置已可打开 SettingsPanel |
| 交互统一 | 所有配置都在同一个设置面板中管理 |
| 减少视觉噪音 | AI 页面顶部已有关闭按钮，不应再有设置入口 |

#### 用户路径变化

```
改动前：
  AI 页面顶部 ⚙️ → 设置面板（AI 配置）

改动后：
  左侧「设置」按钮 → 设置面板 → 切换 AI 选项卡 → AI 配置
```

### 3.3 需要修改的文件

| 文件 | 修改类型 | 说明 |
|------|----------|------|
| `src/components/AI/AIArea.tsx` | 修改 | 移除齿轮按钮，保留关闭按钮 |
| `src/components/HomeClient.tsx` | 无需修改 | 已有完整的 SettingsPanel 调用，settingsType 已支持 'ai' |

## 六、风险与注意

| 风险 | 说明 | 缓解 |
|------|------|------|
| .env.local 写入权限 | 运行 npm run dev 的用户可能无权限写 .env.local | 提供降级方案：提示手动编辑 |
| API Key 保存后需重启 | `process.env` 在 Node.js 运行中无法热更新 | 每次请求时从 .env.local 重新读取，或提示重启 |
| 用户误解"经典模式" | 用户可能不理解经典模式和 AI 模式的区别 | 按钮文字明确：「📄 经典模式 - 拖拽上传 Markdown」 |
