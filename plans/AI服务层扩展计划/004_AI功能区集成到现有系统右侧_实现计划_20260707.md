## 一、变更摘要 (Change Summary)

### 1.1 架构决策变更

| 维度 | 计划 003（原方案） | v4.0（本方案） |
|------|-------------------|----------------|
| **页面路由** | 独立页面 `/ai-input` | **集成在首页 `/` 右侧**（取代原有的欢迎页/拖拽区） |
| **AI 配置** | 独立的 AISettingsDialog | **整合进现有 SettingsPanel**，作为新增 `'ai'` 类型 |
| **模型选择器** | 在 AI 页面顶部 | **保留在 AI 区域顶部**（Flash/Pro 下拉，值传到 `/api/ai/generate`） |
| **渲染预览** | 页面底部内嵌预览区（CHDRenderer） | **❌ 删除** → 改为「🔗 新页面渲染」按钮（跳转 `/preview`） + 「⬇️ 下载 HTML」按钮（调用 `/api/save-export`） |
| **每个结果项操作** | 3个：渲染预览/下载HTML/删除 | **3个按钮**：🔗 新页面跳转渲染 + ⬇️ 下载独立HTML + ✕ 删除 |
| **HTML 导出方案** | 新增 `/api/ai/export` 端点 | **复用现有 `/api/save-export`** 端点，前端 POST Markdown，服务端生成 HTML |
| **退出确认** | 独立 AISaveDialog | **保留**（AI 区域内有临时文件时才触发） |
| **导航入口** | 首页新增 AI 按钮 | **不需要**（AI 功能直接可见在右侧） |
| **需要修改的文件** | `src/app/page.tsx` 添加链接 | **修改 `src/components/HomeClient.tsx`** 增加 AI 模式切换 |

### 1.2 为什么这样做？

1. **用户操作流更流畅**：左侧选文档 → 右侧直接可使用 AI 转换，无需跳转页面
2. **UI 一致性**：AI 功能作为右侧面板的一部分，与编辑器、预览的交互模式一致
3. **减少心智负担**：用户不需要理解「这是一个新页面」，只需要知道「右侧多了个功能」
4. **代码侵入最小化**：仅修改 `HomeClient.tsx` 的右侧渲染内容，左侧 `DocumentList` 不动

### 5.3 「🔗 新页面渲染」的实现方式

```typescript
/** 点击 🔗 按钮：跳转到独立预览页面 */
function handleOpenPreview(fileId: string): void {
  const file = TempFileManager.getTemp(fileId);
  if (!file) return;
  
  // 将 Markdown 内容编码后通过 URL 传递
  const encoded = encodeURIComponent(file.content);
  // 或：先保存到 localStorage，再打开新页面
  localStorage.setItem('ai_preview_content', file.content);
  // 新窗口打开预览页面
  window.open(`/preview?file=${encodeURIComponent(file.fileName)}`, '_blank');
}
```

> 注意：与现有 `/preview/page.tsx` 的 `loadFromStorage` 模式一致，使用 localStorage 传递内容。

### 5.4 「⬇️ 下载 HTML」的实现方式

```typescript
/** 点击 ⬇️ 按钮：生成独立 HTML 并下载 */
async function handleDownload(fileId: string): Promise<void> {
  const file = TempFileManager.getTemp(fileId);
  if (!file) return;

  // 调用后端 /api/save-export 生成并保存 HTML
  const response = await fetch('/api/save-export', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      filename: file.fileName.replace('.md', '.html'),
      content: file.content,  // 原始 Markdown
      metadata: {
        id: file.fileName.replace('.md', ''),
        type: 'document',
        title: file.sourceFileName,
        date: new Date().toISOString().slice(0, 10),
        tags: [],
        chdVersion: '2.4',
        htmlFile: `${file.fileName.replace('.md', '.html')}`
      }
    })
  });

  if (response.ok) {
    // 服务端已通过 save-export 保存 HTML 到输出目录
    // 前端触发浏览器下载
    triggerBrowserDownload(content, file.fileName.replace('.md', '.html'));
  }
}
```
