## 一、核心交互流程

```
选中文本 ≥ 10 字符
    ↓
弹出浮动工具栏（4种操作 + 输入框）
    ↓
用户选择操作类型 + 可选输入 ≤20 字指令
    ↓
调用 AI（传上下文 + 操作类型 + 指令）
    ↓
AI 返回建议 → 显示"建议替换"对比弹窗
    ↓
用户确认 → 替换原文 + 自动生成 Operation 推入撤销引擎
用户拒绝 → 关闭，原文不变
```

## 三、简短指令功能

### 3.1 为什么加这个

四个固定按钮（润色/扩充/转卡片/总结）覆盖了基本需求，但用户的效果预期往往更具体：

```
"润色" → 用户可能想的是"让语气更正式"
"扩充" → 用户可能想的是"加个实际案例"
"总结" → 用户可能想的是"缩成三句话"
```

与其让用户猜"AI 会不会按我想的来"，不如允许用户输入一个简短的指令。

### 3.2 ≤20 字限制的原因

| 原因 | 说明 |
|------|------|
| **成本** | 每多输入一个字 ≈ AI 多处理几 token，有限制就可控 |
| **聚焦** | 20 字足够表达意图（"口语一点"4个字就够了），再多说明用户自己还没想清楚 |
| **速度** | 输入框限制字数 → 用户快速决定 → 不拖慢整体流程 |

### 3.3 指令融入 Prompt

```javascript
// 基础 prompt 结构
function buildPrompt(operationType, selectedText, userInstruction) {
  const templates = {
    polish: '请润色以下文本，改进语法和表达，保持原意不变',
    expand: '请基于以下内容展开论述，增加细节和例证，篇幅约原文2-3倍',
    'to-card': '请将以下文本转换为CHD卡片格式',
    summarize: '请为以下内容生成一段简洁的摘要，50字以内',
  };

  let prompt = templates[operationType];
  
  // 如果有简短指令，追加到 prompt 中
  if (userInstruction && userInstruction.trim()) {
    prompt += `，特别注意以下要求：${userInstruction.trim()}`;
  }

  return prompt + `\n\n${selectedText}`;
}

// 示例：
// 无指令：  "请润色以下文本..."
// 有指令：  "请润色以下文本...，特别注意以下要求：口语一点"
```

## 四、与操作引擎的集成

### 4.1 确认替换时生成 Operation

```typescript
function handleAcceptSuggestion(original, suggested, actionType, userInstruction) {
  // 1. 替换编辑器中的选中文本
  editor.replaceSelection(suggested);

  // 2. 生成 Operation 推入撤销引擎
  const op = OperationBuilder.aiOperation(
    mapActionType(actionType),   // AI_POLISH / AI_EXPAND 等
    selectionStart,
    selectionEnd,
    original,
    suggested,
    {
      model: 'flash',
      promptType: actionType,
      tokensConsumed: response.tokens,
      userInstruction: userInstruction || '',  // 记录指令
    }
  );

  pushOperation(op);
}
```

### 4.2 撤销 AI 操作

用户按 Ctrl+Z 时，撤销引擎执行 `invert()`，用 `payload.before`（原文）替换 `payload.after`（AI 处理后内容）。效果等同于回到 AI 操作前的状态。
