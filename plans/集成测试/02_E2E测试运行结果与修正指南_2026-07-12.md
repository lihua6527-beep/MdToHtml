### 步骤 2：检查三个关键选择器

在浏览器中打开 `http://localhost:3000`，按 F12 打开开发者工具，查看：

**① 新建文档按钮**
```html
<!-- 找到页面上"新建"或"新建文档"对应的按钮 -->
<!-- 例如可能是： -->
<button>新建</button>
<!-- 或 -->
<a href="/editor">新建文档</a>
```

**② 文档列表容器**
```html
<!-- 找到文档列表的容器 -->
<!-- 例如可能是： -->
<div class="doc-list">...</div>
```

**③ 搜索输入框**
```html
<!-- 找到搜索框 -->
<!-- 例如可能是： -->
<input placeholder="搜索文档...">
```

### 步骤 3：把找到的正确选择器代入

用以下模板替换测试文件中的选择器：

#### 编辑工作流 (`e2e/editor-workflow.spec.ts`)

```typescript
// 替换第 8 行：
// 原来的: await page.waitForSelector('text=新建文档');
// 改成你实际页面上的按钮，例如：
await page.waitForSelector('text=新建'); // 或 'a[href="/editor"]'

// 替换第 11 行：
// 原来的: await page.click('text=新建文档');
await page.click('text=新建'); // 或 'a[href="/editor"]'
```

#### 文件管理 (`e2e/file-management.spec.ts`)

```typescript
// 替换第 36 行：
// 原来的: await page.waitForSelector('.document-list-item');
// 改成实际 CSS 类名，例如：
await page.waitForSelector('.doc-item'); // 或 '.doc-list > *'
```

#### 搜索测试 (`e2e/search-and-export.spec.ts`)

```typescript
// 替换第 17 行：
// 原来的: searchInput = input[type="search"]...
// 改成实际的搜索框选择器
const searchInput = page.locator('[placeholder="搜索"]');
```
