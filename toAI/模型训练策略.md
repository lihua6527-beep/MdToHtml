# 模型训练策略 (Model Training Strategy)

> 整合自 `模型训练分析.txt`

## 1. 核心策略：数据驱动的“人工修正 -> 模型训练”闭环

目前的计划是将项目中最有价值的部分（人工修正环节）转化为高质量训练数据，驱动系统智能化。

### 1.1 为什么这是金科玉律
1.  **数据来源可靠**: 大模型生成的 CHD 文档结构基本可用，人工修正成本低，且修正后的数据是“黄金标准”。
2.  **目标明确**: 修正后的文档直接提供训练任务（拆分判断、原子化拆分、语义标注）。
3.  **闭环验证**: 小模型模仿人类修正，确保输出质量稳定。

## 2. 具体操作步骤

| 步骤 | 操作 | 产出物 | 用途 |
| :--- | :--- | :--- | :--- |
| **1. 生成与修正** | 用大模型生成，人工修正 | 结构完美、语义准确的CHD文档 | 总数据集 |
| **2. 数据切片** | 提取子任务 (拆分/不拆分, 标签分类) | 训练集 (文本-标签对) | 各小模型训练 |
| **3. 模型训练** | 训练专用小模型 | 模型权重文件 | 集成 |
| **4. 集成测试** | 接入工作流测试 | 增强版 AST | 验证准确率 |

## 3. 标准化修正建议
*   **固定标签集**: 预定义 `concept`, `example`, `advantage`, `step` 等标签。
*   **记录原因**: 备注修正理由（如“枚举过多需拆分”），作为未来特征。

## 4. 小模型的工作范围
小模型**不处理不规范文本**，而是对“半成品AST”进行深度加工：
1.  **语义分类**: 判断卡片类型。
2.  **关系理解**: 判断并列/递进关系。
3.  **重要性标注**: 识别核心论点。
4.  **布局推荐**: 推荐 Grid/Stack/Featured 布局。
