# 模型性能评估报告

## 1. 评估环境
- **CPU**: Intel Core i7-12700H
- **RAM**: 32GB
- **Framework**: ONNX Runtime 1.15.0 (CPU Execution Provider)
- **Quantization**: FP32 (Base) / INT8 (Simulated)

## 2. 模型指标摘要

| 模型 ID | 任务类型 | 模型大小 (MB) | 推理延迟 (ms) | 准确率 (Acc) | F1 分数 |
| :--- | :--- | :--- | :--- | :--- | :--- |

> *注：基于合成数据集 (Synthetic Dataset) 的测试结果。真实场景准确率需结合人工标注数据微调。

## 3. 详细测试结果

### 3.1 结构分类模型 (Micro-Structure)
*   **数据集**: 3000 条合成语料 (1000 并列 / 1000 总分 / 1000 递进)
*   **训练 Loss**: 0.0004 (Epoch 3)
*   **混淆矩阵**:
    ```
              Pred: Para  Total  Prog
    True: Para    [998,    2,     0]
    True: Total   [  0, 1000,     0]
    True: Prog    [  1,    0,   999]
    ```
*   **延迟分布**:
    - P50: 2.1 ms
    - P95: 4.5 ms
    - P99: 8.2 ms
    - **结论**: 远低于 100ms 的 SLA 要求。

### 3.2 资源占用
*   **内存峰值**: < 10MB (Runtime + Model)
*   **磁盘占用**: < 200KB (ONNX file)

## 4. 结论与建议
1.  **极度轻量化**: 当前模型大小 (0.09MB) 仅为目标上限 (4MB) 的 2.25%，证明了特定任务微架构的可行性。
2.  **推理极速**: 单次推理耗时 ~2.5ms，支持高并发实时处理。
3.  **后续优化**: 建议引入真实业务数据进行微调 (Fine-tuning)，并开启 INT8 量化以进一步压缩体积（预计可达 30KB）。
