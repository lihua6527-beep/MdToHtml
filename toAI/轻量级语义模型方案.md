# 轻量级小模型语义分析训练方案

## 1. 方案概述
本方案旨在构建一套基于轻量级神经网络的语义分析工作流，用于识别文本的逻辑结构（并列、总分、递进）。核心目标是在严格的体积限制（<4MB/模型）下，实现高精度的结构识别，并支持毫秒级推理。

## 2. 模型架构设计 (Micro-Architecture)

为了满足 2-4MB 的体积限制，我们放弃通用大模型（如 BERT），采用 **"特定任务微架构" (Task-Specific Micro-Architecture)**。

### 2.1 核心组件
*   **Tokenizer**: 字符级 (Char-level) + 高频词 (Top-K Words) 混合编码，词表大小控制在 3000-5000 以内。
*   **Embedding**: 64维稠密向量 (3000 * 64 * 4B ≈ 0.75MB)。
*   **Encoder**: 
    *   **BiLSTM variant**: 双向 LSTM (Hidden=64, Layers=2) + Self-Attention 机制。
    *   **TextCNN variant**: 多尺寸卷积核 (2,3,4) + MaxPooling。
*   **Quantization**: 全链路支持 ONNX 动态量化 (INT8)，体积可进一步压缩 4x。

### 2.2 模型矩阵
根据任务复杂度，规划 3 个专用小模型：

| 模型名称 | 任务定义 | 架构选型 | 预估大小 (INT8) |
| :--- | :--- | :--- | :--- |
| **Micro-Splitter** | **语义拆分**：识别语义单元边界 (Sequence Labeling) | BiLSTM-CRF | ~1.5 MB |
| **Micro-Structure** | **结构分类**：判断文本段落的整体逻辑 (Cls: Parallel/Total/Prog) | TextCNN + Attention | ~1.2 MB |
| **Micro-Relation** | **关系判断**：判断相邻单元的逻辑递进性 (Binary Cls) | Siamese BiLSTM | ~1.8 MB |

## 3. 训练方案

### 3.1 数据集构建 (Data Engineering)
由于缺乏标注数据，初期采用 **"规则合成 + 少量人工"** 策略：
*   **并列式 (Parallel)**: 随机抽取同类属性句子拼接，使用 "此外"、"另外"、"同时" 等连接词增强。
*   **总分式 (Total-Part)**: "总述句" + 多个 "分述句"，使用 "首先...其次..." 模板。
*   **递进式 (Progressive)**: 具有因果/时间/程度递进关系的句子对。

### 3.2 特征工程
*   **Positional Encoding**: 相对位置编码，强化结构感。
*   **Structural Markers**: 显式注入连接词特征 (Connective Words Embedding)。

### 3.3 训练策略
*   **Loss Function**: Focal Loss (解决样本不均衡)。
*   **Optimizer**: AdamW + OneCycleLR。
*   **Regularization**: Dropout (0.3) + Weight Decay。

## 4. 工作流集成 (Inference Pipeline)

采用三级流水线设计：

```mermaid
graph LR
    Input[输入文本] --> Stage1(Micro-Splitter)
    Stage1 --> |语义单元| Stage2(Micro-Structure)
    Stage2 --> |结构类型| Stage3(Micro-Relation)
    Stage3 --> Output[结构化语义树]
```

*   **Stage 1: Split**: 将长文本切分为独立的语义单元（句子/短语）。
*   **Stage 2: Classify**: 宏观判断这些单元组成的段落是什么结构。
*   **Stage 3: Verify**: 微观分析单元间的逻辑紧密度，剔除离群点。

## 5. 交付标准
*   **模型文件**: `.onnx` 格式，单文件 < 4MB。
*   **性能指标**: CPU (i5/i7) 单次推理 < 50ms。
*   **接口**: Python Class `SemanticPipeline`。
